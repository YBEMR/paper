# 71号：并发代价与调度决策影响的条件论证

日期：2026-09-27。承接[69号候选一](69_基于模型假设的新切入点检索.md)，仅作来源复核、条件推导和对照设计。没有修改程序、冻结数值、运行仿真或取得新测量；RK3588保持备查，61—68号主线及历史结果保留。

## 1．结论与证据等级

**本轮落入状态2：存在条件性决策影响，尚缺匹配的并发功率及节点注热证据。** 公共基准去重之后，活动功率残差若依赖重叠安排，仍可改变时序偏好；跨配置的修正差超过原可实现能量差时，才可能改变配置选择。残差也可能只改变预测、打破并列，或者完全不改变决策。

本轮补实四个边界：

1. 固定模式、固定活动时长时，可加模型对并发／错开通常本来并列。残差打破这种并列，不是推翻原唯一最优配置。
2. 两条时间表换序，不等于全系统最优配置改变；配置内仍须允许合法重排与等待。
3. 一条安排因修正超温，只能否定该安排，不能否定整套模式配置。
4. 若能量开始依赖时序，旧“配置已有一条安全见证即可停止该配置搜索”的依据也须重审；这说明接口要改，不证明需要新算法。

匹配pair表与已有联合规划是必须保留的直接替代。目前没有证据认定其不足，不建议更换主线或同时推进驻留／转换候选。

## 3．共同计量契约

### 3.1 输入与固定条件

完整安排记为σ=(m,s)，包含模式及启动时刻；i的活动区间为Iᵢ(σ)，长度dᵢ(σ)。固定工作量、Stage依赖、合法资源、频率域、到达、期限与窗口[0,W]。只比较完整完成的安排，尾段仍计费。启动域必须预先声明，不能将网格结果外推连续域。

| 符号 | 含义／单位 | 本轮限定 |
|---|---|---|
| P₀ | 同一系统边界的常数公共基准，W | 与方案无关；不包含额外重复的Stage基准 |
| qᵢ(mᵢ) | solo活动增量参考功率，W | 由匹配边界定义；本轮基础版本假设非负、活动内恒定 |
| dᵢ(σ) | 相同工作量在该安排下的活动时长，s | 允许争用依赖，但两规划模型必须使用同一响应 |
| κσ(t) | 相对于基准去重模型的系统功率残差，W | 可正可负；不是预设物理定律 |
| Δ(σ) | 残差能量∫κσ(t)dt，J | 无配套数据，不填数值或“文献范围” |
| p⁰σ(t)、δpσ(t) | 基础节点注热及其修正，W向量 | 与系统功率口径不同，须另有节点边界依据 |

两方共有同一时长响应，并不意味着所有候选都拥有相同持续时间。若时长随重叠变化，必须由同一进度／争用规则或相容profile产生，不能先任填起止再根据重叠改时长、却不更新依赖和期限。本轮第一层符号例子固定时长以隔离功率作用；时长变化只作单列边界分析。

在此契约下：

\[
P_{\rm add}(\sigma,t)=P_0+\sum_iq_i(m_i)\mathbf1_{I_i(\sigma)}(t),
\qquad P_{\rm pair}(\sigma,t)=P_{\rm add}(\sigma,t)+\kappa_\sigma(t),\tag{1}
\]
\[
E_{\rm add}(\sigma)=P_0W+\sum_iq_i(m_i)d_i(\sigma),\qquad
E_{\rm pair}(\sigma)=E_{\rm add}(\sigma)+\Delta(\sigma).\tag{2}
\]

须检查总功率非负、节点总注热非负、solo与pair边界一致，主机工作或共享部件不能重复计入。实测残差还可能混入基准漂移、温度、频率、测量窗口或Stage粒度误差；只有这些受控后，才可归因于所声明的并发活动交互。

### 3.2 公共基准修正不能与非加性混同

令活动区间并集长度为u(σ)。一个**用于说明重复计费的抽象诊断式**是

\[
E_{\rm diag}=\sum_i(P_0+q_i)d_i+P_0(W-u)
=E_{\rm add}+P_0\Big(\sum_i d_i-u\Big).\tag{3}
\]

最后一项只是重叠期间重复携带的公共基准；两Stage情况下等于P₀乘重叠时长。去掉它可改变安排评价，却不需要κ≠0。若原口径仅累加solo能量而完全不计空闲，差值则为P₀(Σdᵢ−W)，不能一概说总量必然高估。

式(3)不是BIDENT原公式：该论文计量窗口及pair计价细节不能未经核对替换成本研究固定窗口。已读正文没有提供本题所需idle分解，不能给作者推算重复量或误差方向。只有基准问题时，应降为计量适配。

## 4．CPU阶段与NPU阶段的符号例子

选两个可跨设备同时执行的阶段c、n，可属于不同请求；若存在c→n依赖，不得让它们重叠。其余阶段保持同样输入与合法后继，所有安排仍需满足完整请求期限。

第一层固定两阶段模式与时长，记重叠长度为ℓσ。采用显式条件假设：只有二者共同活动时产生常数残差k，即κσ(t)=k·1_{I_c∩I_n}(t)。该假设不来自实际测量，不覆盖任意相位或三个以上共同活动阶段。

令σ∥有ℓ>0的重叠，σ→错开且ℓ=0，则

\[
E_{\rm add}(\sigma_\parallel)=E_{\rm add}(\sigma_\rightarrow),\qquad
E_{\rm pair}(\sigma_\parallel)-E_{\rm pair}(\sigma_\rightarrow)=k\ell.\tag{4}
\]

| 条件 | 可以推出 | 不能推出 |
|---|---|---|
| 两安排共同可行，k>0 | 错开相对更省能；原时序并列被打破 | 原唯一最优配置被推翻；必有系统最优能量改善 |
| 两安排共同可行，k<0且功率相容 | 并发相对更省能 | 所有并发都省能，或峰温必降低 |
| k=0或重叠相同 | 残差不改变两者排序 | 参数没有影响温度或其他候选 |
| 紧期限不允许错开 | 错开不是合法替代 | 可以靠删除并发直接得到安全节能解 |

若允许已知争用改变时长，则同模式的差变为

\[
E_{\rm pair}(\sigma_\parallel)-E_{\rm pair}(\sigma_\rightarrow)
=\sum_{i\in\{c,n\}}q_i[d_i(\sigma_\parallel)-d_i(\sigma_\rightarrow)]+k\ell.\tag{5}
\]

仅在其余活动能量相同且残差确实只来自该pair时可这样写。前一项可能单独决定排序，属于已有争用关系；比较功率模型时不能让一方遗漏它。本轮不构造慢化倍数或功率数字。

## 5．从候选换序到系统决策的严格条件

### 5.1 两个共同可行安排

对满足两套热评价及共同资源／期限条件的σ₁、σ₂，设g=E_add(σ₂)−E_add(σ₁)>0。由式(2)直接得到：

\[
E_{\rm pair}(\sigma_1)>E_{\rm pair}(\sigma_2)
\iff \Delta(\sigma_1)-\Delta(\sigma_2)>g.\tag{6}
\]

等号产生并列，小于g则原优劣保持。证明仅为作差：新差为−g+Δ₁−Δ₂。它适用于同配置不同安排或跨配置安排，但只证明这两个候选的关系，不能冒充全域最优结论。

**不变条件：** 若全域可行集合不变且Δ为公共常数，整个最优集合不变；即使最优值数值平移，也没有决策损失。若有独立依据保证|Δ(σ)|≤ε，原唯一最优与其余所有候选的差严格大于2ε，则仍唯一最优。相等仅不能保证唯一性；没有误差依据时不得自定ε。这一条件在热可行域改变时不能直接套用。

### 5.2 完整最优集合与配置选择

分别令F_add、F_pair为共同非热合法域经两套注热评价后保留的集合；令O_add、O_pair为对应最优安排集合，M_add、M_pair为它们投影到完整模式组合后的集合。以下最优集合讨论以最优值可取得为前提；将来若采用有限网格域，该前提自然满足。

必须区分：O发生变化但M不变；M仅缩小；M存在交集但不相等；M交集为空；以及修正后整体不可行。只看一条返回解的CPU标签或并列选择，不能判配置翻转。对称单元换标签不计能效收益。

一个足以证明**原唯一最优安排失效**的条件是：原最优σ*在F_pair内，而存在另一个也在F_pair内的σ′满足式(6)。这仍不保证必须换配置，因为σ*所属配置可能有更好的重排。

对配置m，应比较

\[
V_{\rm pair}(m)=\inf_{s:(m,s)\in F_{\rm pair}}E_{\rm pair}(m,s),\tag{7}
\]

空集取+∞。若固定m时原活动时长不随s改变，可记E_add(m)=e_m；对两个都保留热安全时序的配置a、b，定义δ*_m=inf_{s∈S_pair(m)}Δ(m,s)，则

\[
V_{\rm pair}(a)-V_{\rm pair}(b)=e_a-e_b+\delta^*_a-\delta^*_b.\tag{8}
\]

e_a<e_b时，δ*_a−δ*_b>e_b−e_a才使这两个配置的**最佳可实现能量**换序。欲证明全系统必须离开原最优配置集合，须进一步证明某个外部配置的值严格小于原集合内所有配置的值，或证明原集合全部无热安全续接且外部有安全解。当前没有这种配套数据／完整排除证据。

若d依赖s，必须直接用式(7)，不能将e_m当常数。若只比较两条预选代表而不给配置重新安排机会，会人为夸大修正的价值。

## 6．热可行性：功率残差还需要节点依据

两套评价使用相同入口θ₀、环境、窗口、上限和被动RC：C为正对角，G为对称被动导热矩阵、非对角非正且有环境散热保证稳定。H(v)=exp(−C⁻¹Gv)C⁻¹逐元非负。固定同一安排、同一时长后：

\[
\theta_{\rm pair}(t)=\theta_{\rm add}(t)+
\delta\theta(t),\qquad
\delta\theta(t)=\int_0^t H(t-u)\delta p_\sigma(u)\,du.\tag{9}
\]

κ是系统计量残差，δp是节点热源残差。只有在明确将边界内电功率按对应节点计作注热、边界外功率另列的抽象契约下，才可写κ=1ᵀδp+δP_ext。不能由一个package标量唯一反推出两节点分量，更不能默认残差全部注入CPU。模型外部热源若会影响节点，也不能继续声称在热边界之外。

对基础安排的逐时刻热裕量r_n(t)=T_n^max−T_add,n(t)，若它原本全程安全，则：

\[
\exists n,t:\ \delta\theta_n(t)>r_n(t)
\quad\Longleftrightarrow\quad
\text{修正后该完整安排存在超温}.\tag{10}
\]

若对所有n,t均有δθ_n(t)≤r_n(t)，则保留数学上的热可行性；数值实现还应沿用安全／违规／未分辨及误差包络，不能把阈值相等当作已认证安全。

这给出了原安排失效的精确条件，**但没有否定该配置其他时序**。若要说系统仍可运行，另须找到满足全部期限、资源和热约束的替代；没有替代时应保留未决或整体不可行，而不是报告节能。

| 条件 | 结论及边界 |
|---|---|
| 同一时间轴、入口相同且δp逐点非负 | 正性推出温度逐点不降低；仍须越过裕量才能说失效 |
| δp逐点非正且总注热非负 | 该安排温度不升，原安全安排保留；不证明候选全域能量排序不变 |
| 有节点残差上界δp≤b，且∫H b≤r全程成立 | 给出该安排保留安全的充分条件；b须有独立依据 |
| κ积分更低，但节点位置、持续时间或重叠不同 | 无法比较全过程峰温；不能用总能量替代式(9) |
| 所有候选都有同样能量修正 | 能量排序不变；不同节点／时序仍可能改变热可行域 |
| 只有package功率或能量 | 只得系统能量条件，热结论保持待验证 |

对第4节的矩形重叠例子，若另声明δp=r·1_overlap，则δθ=∫overlap H(t−u)r du。r≥0只给升温方向，是否超限仍取决于入口、时刻及裕量；k不能单独确定r。没有新增RC数值、初温点或曲线。

## 8．简单替代能处理到哪里

| 条件 | 足够的直接方法 | 对旧结构的影响 |
|---|---|---|
| 只有公共基准重复 | 统一边界后去重 | 常规计量适配；若活动时长固定，仍可用E(m) |
| 时长与增量可加均固定，残差为0或配置内固定常数 | 模式表＋原联合规划 | 配置内能量仍固定，安全见证关闭原则可以保留 |
| pair残差由已知模式、重叠区间唯一确定，时长规则相容 | pair查表＋已有联合规划／有限域完整评价 | 可表达；目标含重叠代价，不是简单把常数塞进独立Stage列 |
| 仅需纠正并发慢化且已有模型覆盖 | 保留HaX类争用与重规划能力 | 不将其收益归给新增功率残差 |
| profile不覆盖相位、多重并发或隐藏状态 | 先标模型未定义／数据不足 | 不自动添加状态或称现有方法失效 |

若同配置内Δ或d随时序改变，问题应写为min_{m,s}E(m,s)，或外层比较式(7)的配置值；**“配置能量＋安全时序是否存在”不再直接给目标值**。一条安全见证只给该配置上界，另一时序可能更省能。原61号分解仍在原假设下成立；本轮没有回写或撤销旧证明。

下界也须适配。设对全部合法续接都有qᵢ(mᵢ)dᵢ(σ)≥ℓᵢ，且Δ(σ)≥K_min，则

\[
L=P_0W+\sum_i\ell_i+K_{\min}\le E_{\rm pair}(\sigma).\tag{11}
\]

若时长项仍满足旧独立最小值界且残差非负，旧下界仍可保留。若残差可负，旧下界不自动有效：在原独立最小模式共同可实现且残差为负的条件例子中，能量就可低于旧L₀。需要有据的K_min或其他保守界；不能把负残差忽略并继续用U=L₀宣称最优。只有总系统功率非负时，零能量是宽松下界，未必足以支持求解比较。

这些是目标、覆盖与证据接口的变化，尚不是实测瓶颈或算法贡献。原MILP固定Stage能量列、no_repair配置关闭及界管理均未实现此扩展；不能直接运行旧程序并称已验证pair模型。

## 9．一项公平模型对照：仅设计，不执行

**主张H71：** 在同工作量、同已知时长响应和合法域下，基准已去重的可加功率规划，相比pair功率规划，是否在共同pair评价中出现可行性损失或有效能量损失？

| 项目 | 冻结规则的要求 |
|---|---|
| 改变因素 | 仅规划功率刻画：add采用κ=0及其基础注热；pair采用声明的κ与相容δp。热网络、入口、上限均相同，节点输入差属于同一功率修正 |
| 共同输入 | 任务、模式支持、频率、时长／争用规则、依赖、资源、期限、窗口、启动域、信息及求解覆盖一致 |
| 数据等级 | pair共同评价可来自匹配公开数据或明确L3假设；后者不称真值或实测验证。缺δp时只能设计能量子结论，不填热结论 |
| 主要基线 | 基准去重后的add；原solo口径只作诊断，不用来制造弱对照 |
| 共同回放 | 保持输出的模式与起点，不暗中修复、换模式或补后缀。两方已有相同时长规则，不能将迟到归因于功率公式 |
| 记录 | 完成情况、各请求完成时刻、系统能量、完整配置／最优集合、连续逐节点峰温、热状态、预测偏差及原因 |
| 并列 | 比较集合；若多个add最优代表回放结果不同，报告范围，不挑最差者作默认，也不挑最好者掩盖风险；集合未完整则明确覆盖缺口 |
| 求解要求 | 同动作空间、信息与预定预算；精确小域或证据充分的界用于隔离模型影响。启发式／覆盖差异不归为模型不足 |

输出分四类：①预测不同但安排／配置和共同能量无损失；②安排集合改变但仍有共同最优解；③add输出在pair下不安全／不可行；④两方共同可行但add选择具有已证能量损失。第三类不参与有效节能排名；第四类须有精确参考、解析界或足以证明差距的证据。只有已知安全见证但求解未找到，不足以把原因归给功率模型。

在本轮“时长响应相同、回放不修复”的隔离定义下，单独修正功率不会改变同一时间表的完成时刻或资源合法性；新增不可行应来自热约束。若出现新的期限违规，先检查是否偷偷改变了时长、加入热节流或进行了修复，不能直接算作本功率对照的模型效果。

无收益条件必须包含：κ=0；共同常数且热域不变；修正差不足；原并列与修正后并列；期限迫使相同安排；pair表＋通用联合规划已经足够。允许整体不可行、参数未定义、数值未分辨及搜索未决。没有任何一类被要求必须出现，也不为凑齐结果选数值。
