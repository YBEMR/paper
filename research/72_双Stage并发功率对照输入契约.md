# 72号：双Stage并发功率对照的输入契约

日期：2026-09-28。承接[71号条件论证](71_并发代价与调度决策影响的条件论证.md)，落实用户选择的两个独立Stage。本轮只有定义、代数核对和纸面验收，没有数值输入、程序修改、搜索或热仿真，也没有扩展检索。

## 1．结论与验证范围

**契约在以下假设下自洽，可以进入后续L3参数冻结；目前还不是可运行实例，也没有回答H71。** 必须补齐模式表、pair节点功率、期限／窗口／网格及热参数，不能从旧实验自动继承。

研究对象为一个CPU阶段A与一个NPU阶段B，各自代表一个单阶段请求。二者无依赖，均在0到达。A在同一个固定CPU执行单元上选择L/H频率模式，B采用唯一固定NPU模式。两个执行资源互不重叠，允许合法等待、完全或部分并发；本对象没有多个CPU阶段，因而不研究共享频率域竞争。

每Stage完整执行一次，不可抢占、迁移或执行中改频。时长由模式固定，不随并发、温度或相对启动偏移改变。额外交接／切换开销为零，空闲状态不动态休眠；不加入热节流。该对象隔离**功率刻画对CPU频率与重叠时序选择的影响**，不验证多核分配、CPU/NPU替代映射、四Stage链或实际设备收益。

这里的固定时长与恒定pair功率是研究假设，不是BIDENT测量规律。[69号原文记录](evidence_69/bident_hax_notes.md)及71号提供问题入口，不能提供本对象的配套数值。61—68号主线与70号备查状态均保持不变。

## 2．字段级输入契约

以下字段名只用于明确未来数据含义，不创建JSON、代码接口或占位数值文件。内部统一采用s、W、J；温度以°C输入，温差以K解释。每个待赋值参数附`unit`、`evidence_type`、`source_locator`和`assumption_scope`；推导字段注明输入依赖，不与原始值重复独立赋值。

### 2.1 任务、模式与时域

| 字段 | 符号／单位 | 约束及用途 |
|---|---|---|
| task_id、resource | A→CPU；B→NPU | 固定，不允许设备替代；不是Band模型文件身份 |
| release_A、release_B | 0，s | 结构上固定为0，不是实测到达分布 |
| cpu_modes | m∈{L,H}；频率单位Hz | 恰好两项，频率分别f_L、f_H，满足0<f_L<f_H |
| duration_A[m] | d_A(m)，s | 正且有限，执行中不变；不由频率比或算子数自动生成 |
| increment_A[m] | Q_A(m)，W | 非负且有限；solo活动增量，不能填写CPU整机功率 |
| duration_B、increment_B | d_B，s；Q_B，W | 正时长、非负活动增量；NPU无调频变量 |
| deadline_A、deadline_B | D_A、D_B，s | 0<D_A,D_B≤W，绝对期限；不冒称真实硬期限 |
| start_grid | h，s | 正且有限，仅约束启动，不取整时长、结束或期限 |
| window | W，s | 正且有限、方法间相同，不按实际完成时间缩短 |

L/H表示频率高低，不预设Q_A(L)d_A(L)与Q_A(H)d_A(H)的顺序；也不在尚无响应依据时强制采用1/f时长公式。如果后续用函数产生模式表，函数及展开值必须一致且分别标明依据。

所有非热合法安排由三元组σ=(m,k_A,k_B)唯一表示：

\[
s_A=k_Ah,\quad s_B=k_Bh,\quad k_A,k_B\in\mathbb Z_{\ge0},
\qquad e_A=s_A+d_A(m)\le D_A,\quad e_B=s_B+d_B\le D_B.\tag{1}
\]

执行区间取半开区间I_A=[s_A,e_A)、I_B=[s_B,e_B)，无同设备互斥或任务间先后约束。有限合法域记为Ω；给定m，合法起点数分别为

\[
N_A(m)=\max\{0,\lfloor(D_A-d_A(m))/h\rfloor+1\},\quad
N_B=\max\{0,\lfloor(D_B-d_B)/h\rfloor+1\},
\quad |\Omega|=\sum_{m\in\{L,H\}}N_A(m)N_B.\tag{2}
\]

这是数学格点计数，未来实现不得靠随意浮点取整处理边界。某模式没有起点是该模式无热不可行；Ω为空是实例无热不可行，二者都不是输入格式错误。结束恰好等于期限合法；一Stage结束、另一Stage同刻启动的重叠长度为零。

| 字段 | 符号／单位 | 约束及属性 |
|---|---|---|

| external_power | b_X，W | 非负恒定，计系统能量，位于声明热边界外 |
| pair_cpu_total[m] | J_C(m)，W | 并发期间CPU节点**总功率**，非负；不是额外增量 |
| pair_npu_total[m] | J_N(m)，W | 并发期间NPU节点**总功率**，非负；与CPU模式m配对 |
| heat_capacity | C_C、C_N，J/K | 严格正且有限 |
| conductance_env | g_C、g_N，W/K | 严格正且有限，连接环境 |
| conductance_coupling | g，W/K | 非负且有限，节点间导热对称 |
| ambient、initial | T_a、T_C(0)、T_N(0)，°C | 有限，所有规划与共同回放相同 |
| temperature_limit | T_C^max、T_N^max，°C | 有限、高于环境；入口已超限时记录热不可行，不暗中降温 |

pair表必须包含L、H两行。缺行表示模型未定义，不能回退到“无残差”，也不能当作合法模式不支持。两行NPU节点功率可以不同，但不意味着B的频率或时长改变；这里只表示声明的共同活动状态。

首版L3语义：J_C(m)、J_N(m)在I_A∩I_B内恒定，与重叠起点、长度、Stage进度及温度无关；重叠结束立即切回相应solo状态，无额外转换脉冲。这是无历史记忆的分段功率假设。一个整段pair平均功率实测值不能自动支持它；将来若采用实测表，须重新核对其相位适用范围。

所有性能及热数值尚缺。可选择明确的L3输入，但“原文存在并发近似”不使任意数值成为文献参数。旧53号窗口、RC、功率、时间／能量整数单位均不自动继承，也不将RK3588的多个核心引入本契约。

## 3．四种状态与能量一致性

定义P₀=b_C+b_N+b_X，并由原始pair节点总功率推导

\[
r_C(m)=J_C(m)-[b_C+Q_A(m)],\quad
r_N(m)=J_N(m)-[b_N+Q_B],\quad
\kappa_m=r_C(m)+r_N(m).\tag{3}
\]

r_C、r_N、κ均为派生值。禁止独立给κ赋值后按任意比例拆给节点；也禁止在J_C、J_N上再次加idle或solo增量。

| 活动状态 | pair的CPU注热 | pair的NPU注热 | pair系统功率 | add系统功率 |
|---|---:|---:|---:|---:|
| 全空闲 | b_C | b_N | P₀ | P₀ |
| 仅A运行 | b_C+Q_A(m) | b_N | P₀+Q_A(m) | 同左 |
| 仅B运行 | b_C | b_N+Q_B | P₀+Q_B | 同左 |
| A、B共同运行 | J_C(m) | J_N(m) | J_C(m)+J_N(m)+b_X | P₀+Q_A(m)+Q_B |

add在并发态的两节点注热分别为b_C+Q_A(m)、b_N+Q_B。表中每个状态的系统功率均等于两节点注热之和加b_X；这是一致的L3边界约定，不是对任何真实封装能量路径的标定。边界外功率不产生pair修正，也不再隐含影响节点温度。

重叠长度为

\[
\ell(\sigma)=\max\{0,\min(e_A,e_B)-\max(s_A,s_B)\}.\tag{4}
\]

并发、仅CPU、仅NPU、全空闲四类状态累计时长分别为ℓ、d_A−ℓ、d_B−ℓ、W−d_A−d_B+ℓ。对Ω内安排均非负，总和为W。按表积分：

\[
\begin{aligned}
E_{\rm pair}(\sigma)
={}&P_0(W-d_A-d_B+\ell)+(P_0+Q_A)(d_A-\ell)\\
&+(P_0+Q_B)(d_B-\ell)+(P_0+Q_A+Q_B+\kappa_m)\ell\\
={}&P_0W+Q_A(m)d_A(m)+Q_Bd_B+\kappa_m\ell.
\end{aligned}\tag{5}
\]

相应E_add=P₀W+Q_A(m)d_A(m)+Q_Bd_B。未来须独立按事件段积分与式(5)双算；这里只作代数核对。基准计满W，包括尚未启动、阶段间空闲及完成后尾段。

允许正、零、负残差，但四种状态的实际功率、节点注热均须非负。基准是计量分解中的公共参考，不额外断言并发总功率必须高于该参考；若后续选择这种更强物理约束，须在冻结输入时显式增加，不能暗中裁剪负残差。

固定m下，任意两个合法安排满足

\[
E_{\rm pair}(\sigma_1)-E_{\rm pair}(\sigma_2)
=\kappa_m[\ell(\sigma_1)-\ell(\sigma_2)].\tag{6}
\]

κ>0偏好较小重叠，κ<0偏好较大重叠，仅指能量方向；不保证相应安排满足期限或热约束。κ=0时同模式能量与时序无关，但若r_C=−r_N≠0，节点温度仍可能改变。只有两个节点残差均为零时，两种评价对同一时间表的能量与温度都一致。

## 4．完整连续热评价

采用CPU、NPU两节点模型，定义θ=T−T_a：

\[
C=\operatorname{diag}(C_C,C_N),\quad
G=\begin{bmatrix}g_C+g&-g\\-g&g_N+g\end{bmatrix},\qquad
C\dot\theta=-G\theta+p(t).\tag{7}
\]

由g_C,g_N>0及g≥0，对非零z有zᵀGz=g_Cz_C²+g_Nz_N²+g(z_C−z_N)²>0，故G正定；C正定，系统稳定且保持被动导热结构。b_X不进入p(t)。不填热时间常数，也不按稳态热阻补造热容。

事件集合为{0,s_A,s_B,e_A,e_B,W}去重排序。段内使用对应状态恒定注热，状态连续传播；同时起止不制造额外脉冲。全窗口温度约束为T_n(t)≤T_n^max，n∈{C,N}、t∈[0,W]，包含入口、所有端点、内部极值和空闲尾段。耦合节点的局部峰值不能只在Stage结束时检查，提前完成也不保证尾段安全。不保证W之后或重复运行的热安全。

未来评价器必须输出逐节点峰温及其计算误差包络。记判定带β_T≥0：峰温上界低于上限减β_T才记安全；任一峰温下界高于上限加β_T才记违规；其余未分辨。判定带不是运算误差界，ODE或细采样交叉检查也不能替代包络依据。本轮不选择β_T或实现峰值算法。

旧64号认证热包装限定其冻结对称RC；本契约尚未选定RC，不能宣称旧函数已经支持全部合法参数。未来只有参数及误差保证匹配时才复用，否则先补评价器核查。

## 5．共同规划、回放与结果字段

### 5.1 同域完整参照

H71在本对象中的问题是：add功率规划是否相对于pair功率规划，在共同pair评价下产生安全性或有效能量损失？两方分别在相同Ω上评价完整窗口温度，最小化各自的系统能量；唯一区别是表中并发状态的节点功率。

未来采用有限域完整枚举作为小规模共同参照，覆盖L/H及各自全部合法起点。不能仅比较同时启动与完全串行，不能只保留最早安排，也不能找到一个模式的安全见证就关闭其余时序。该选择用于隔离模型影响，不是新算法。

未来两方须使用相同预先声明的预算、数值规则和可用信息，各自承担候选生成及评价成本；预算数值和案例数量留到下一轮冻结。本轮不承诺枚举一定完成。无热输入非法、Ω为空、热域为空、预算中断、数值未分辨和完整覆盖分开登记。

令F_add、F_pair为各模型全域热可行集合，O_add、O_pair为其最优安排集合，M_add、M_pair为最优CPU模式集合。未来程序若有未分辨或覆盖未完成，只能报告已证部分及未决信息，不把当前最好方案称完整最优集合。

### 5.2 原样共同回放与并列处理

对O_add全部成员及pair输出，使用pair节点功率重新评价，保持原m、s_A、s_B，不补等待、不改频率、不修复。两方时长完全一致，因此同一时间表完成时刻与非热合法性不变；若回放后新出现期限违规，先归查实现或混入的额外机制。

| 结果组 | 必需字段及语义 |
|---|---|
| 完整安排 | m、k_A、k_B、s_A、s_B、e_A、e_B、d_A、d_B、ℓ；以三元组为身份，不合并不同等待 |
| 能量 | E_plan、E_pair_replay、状态积分值、公式值及差；单位J，非法／未完成结果不排名 |
| 热评价 | 规划／回放逐节点峰温包络、峰值时刻信息、终端温度与安全／违规／未分辨 |
| 最优证据 | 已证最优值、O及M、集合完整标志；当前安全上界与可信下界分列，没有依据不填伪界 |
| 覆盖状态 | 总合法候选数、已评价数、未分辨数、预算状态；各数值方法需要的计时在后续实施时保存 |
| 差异原因 | 仅能量预测变化、时序并列打破、CPU模式集合变化、热域变化、有效能量损失或证据不足 |

对O_add在pair下回放，分别给出安全／违规／未分辨成员数或已知范围；只在安全子集上给能量最小值、最大值及模式集合。不得挑最差并列解作默认基线，也不得挑最好解而不披露其他解的热风险。没有安全成员时能量排名记“不适用”，不记零能量。

若O_pair已完整可知，则O_add∩O_pair非空说明存在add最优选择在共同评价下无损；并不保证任意并列选择均安全最优。若交集为空，也须继续区分：add成员全部违规、仍安全但能量较高、或证据未决。共同安全的add成员相对已证pair最优值的差距才能叫有效能量损失；仅有两个返回代表不同不能证明这一点。

CPU模式集合相同但起点不同，不记模式翻转；模式集合仅缩小、仍有交集、完全不相交分别记录。该对象根本没有CPU单元映射或NPU频率选择，禁止由结果外推这些收益。

### 5.3 下界与配置关闭的边界

旧独立阶段下界L₀=P₀W+min_m[Q_A(m)d_A(m)]+Q_Bd_B在所有κ_m≥0时仍有效，但不保证可实现。若存在负κ_m，则未经补证不能作为pair问题的可信界，不能据U=L₀停止并宣称最优。完整枚举即使不用强下界也能定义精确参照；不为此增加新的界算法。

当κ_m≠0且该模式有多个可行重叠长度时，一个安全见证一般只给上界。无论残差为正还是负，都不能仅因该模式已安全而停止寻找更低能量安排；即使κ_m=0可以证明值不再改善，本轮若要求完整最优安排集合，仍不能遗漏该模式的其他并列成员。原61—68号的关闭规则只在原适用条件和输出目标下成立。

## 6．纸面验收

下表是代数与语义检查，不是新实验结果；没有为各行选择案例或参数。

| 条件 | 应得到的结论／处理 |
|---|---|
| ℓ=0 | pair项消失，两方对该安排的整条功率与热轨迹一致 |
| 两模式均有r_C=r_N=0 | 两模型对全部Ω一致；相同求解覆盖下最优集合一致 |
| κ=0但节点残差异号 | 能量相同，热结果不能认定相同 |
| 固定模式、重叠变化 | 能量差严格满足式(6)，不混入争用时长变化 |
| κ>0而期限强制重叠 | 不能用不存在的串行安排作为节能替代；须检查Ω内合法起点 |
| κ<0 | 节点总功率仍须非负；旧L₀和首安全见证关闭不能直接复用 |
| e_A=s_B | 半开区间无重叠，无额外pair脉冲；温度连续 |
| 非整数结束／期限边界 | 启动仍落网格，时长和结束不取整；e=D合法 |
| 完成后CPU已停但NPU仍升温 | 必须评价耦合响应及尾段，不只检查执行端点 |
| 输入不满足正热容／被动导热，或pair缺行 | 输入契约失败／模型未定义；不记调度无解 |
| Ω为空 | 无热不可行；不归因于pair功率或温度 |
| 全部Ω在某模型下明确热违规 | 该模型网格热不可行；不外推连续起点 |
| 有未分辨安排或覆盖中断 | 保留未决，不能证明全域无解或最优集合完整 |
| add有安全与违规并列解 | 完整披露回放集合及安全能量范围，不选择性报告 |

四态时长相加为W、功率表积分等于式(5)、节点注热加边界外功率等于系统功率，三项代数核对均成立。RC条件给出稳定性依据，有限启动域可明确枚举，契约内部没有重复空闲计费或未声明的残差拆分。

## 7．缺口、可写结论与唯一下一步
