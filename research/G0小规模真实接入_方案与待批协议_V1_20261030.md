## 3. 下一次限定实现范围与模拟验收

拟新增真实接线目录`research/chapter3_g0_real_entry/`，包括backend、session、numeric_transport及worker/runner；仅为拟改文件，**本轮未创建**。允许对现G0的method、receipts、local_model新增严格区分人工/真实的接缝，保留32项人工回归。旧`chapter3_experiments`、物理参数、正式输入和历史结果保持不变；不新加部署搜索、邻域、初始化次数或调参。

会话方案明确为：同次最多一个新MATLAB进程，会话根寿命不变；新隔离适配受控继承启动段，将ready等待限制在当前phase/slot。启动到期而未ready时，清理并停止，保留S0，不跨阶段继续等待或重新启动。已经ready的会话，每次请求用当前有效remaining及原生MaxTime上限；阶段切换只在空闲可核时继续。

模拟验收须实测接线后的代码，而不是只检查本轮算术oracle：

1. 原common只读；config默认400ms不能覆盖实际230ms；参考表、旧SAFE、独立HEFT结果及跨调用缓存隔离。
2. 同根自费HEFT、准确D0/S0；初始化占满150秒的有/无SAFE分支。
3. 真实构模入口的依赖接线由假Model/系数替代；原数值后缀、显式构模开关及预消元范围保持。
4. 会话root寿命、首slot与第二阶段请求截止分别验证；启动到期、未结请求、清理失败及无重启。
5. x0拒收、严格违规反馈、原矩阵/增广矩阵矛盾、正常scope到期与真实数值异常同时发生；先保存已形成证据，不补做预算外接纳。
6. 全场景完整U、零权场景、迟聚/迟回、已有SAFE保留，独立post的SAFE/违规/未决分类及进程端到端计时。

真实构模开关明确继承既有C数值设置，不能误用人工函数默认值：fix_late_options、aggregate_opp_locks、relax_auxiliary_integrality、strengthen_energy_lower_bounds、prefilter_deadlines均为true；cumulative_precedence=false；G0每阶段preeliminate_closed_anchors=true。阶段一原矩阵，阶段二原C选择性精确行增广/原前缀复核，CutMaxIterations=10，局部反馈最多50轮，原生容差不变。全部转换/复核计入根预算。

## 4. 待批最小真实预算

| 项目 | 提案上限 |
|---|---:|
| G0独立方法调用 | **1次×300秒**，初始化、选块、构模、MATLAB启动、转换、求解和内部评价全计 |
| 独立事后复核 | 正常完整SAFE最多**1次×60秒**，包含新进程启动、导入、核对及评价 |
| 方法完整进程 | 480秒，另列ST_process，不把超出方法根截止的清理当求解时间 |
| 整批日历 | 720秒，未用时间不转为额外研究调用 |
| 重试/续跑/换输入/延长 | 均为0 |

一次方法最多访问4个局部场景块，可能有多轮原生反馈请求，全部受同一个300秒根限制；不是4个免费300秒。无完整SAFE不做post，技术/数值/清理异常按停止规则归档。正常截止仍保留此前完整SAFE，但最后未决不能补U。

资源门沿用原接入：物理可用≥2GiB、提交余量≥4GiB、磁盘≥2GiB、无已有MATLAB、非AppContainer。**本轮没有实际检查或宣称宿主已满足资源门。** 运行前核当前环境及最终源码，不能用旧检查代替。

先完成限定接线及模拟后，才绑定最终运行源码hash、单次入口、批准文件和一次消费记录。当前[plan.json](chapter3_g0_entry_preparation/results/proposal01/plan.json)仅冻结输入/预算提案，execution_authorized=false、runtime_source_freeze=PENDING，不能当作可执行批准。

## 5. 验收如何判断

| 实际结果 | 允许结论 |
|---|---|
| 仅初始化完整SAFE，未进入局部原生求解 | SAFE保留有效；局部接入未完成，不能算整条G0通过 |
| 局部模型完成、至少一次原生求解、x0/返回状态处理及完整评价链正常 | 相应真实接入环节通过；无新整数候选/无改善如实记录 |
| 找到局部SAFE并完整聚合、post通过 | 新U的完整接纳链通过；不据一次接入宣称算法优越 |
| 无SAFE或热评价未决 | 未取得证据，不判原问题无解 |
| 真数值/接口/清理故障或post语义冲突 | 保存此前SAFE和冲突证据，停止，不补跑或免费修复 |

若两个阶段未都实际进入，则分别登记，不把“至少一个局部块进入”写成全部两阶段已验证。阶段收益以同次S0/S1/最终U分开，首整数候选与初始化候选也分开。
