# A2-M1：启动偏移的热感知增量价值

**本轮不支持进入 A2 专门算法开发。** 名义模型的收益主要由共享资源争用与主机忙时能耗解释，温度信息没有改变最佳动作。参数扫描出现两组微小冷热排序变化，数值复核确认其不是积分噪声，但样本内收益上界仅 0.0011303%，留出状态无收益，周期运行也未优于该序列的最佳固定动作。这个结果限定于当前模型及有限候选，不能证明真实异构平台没有热感知机会。

## 1. 研究问题与参数依据

固定任务映射、工作量与标称执行性能，只改变两个任务的相对启动时刻，考察温度信息是否降低**同一评价窗口内的系统输入能量**。主实验实际频率保持不变；热降频作为独立次级组，此时只固定请求频率，实际频率允许由热保护改变。二者的主张不能混用。

选用 Xavier GPU/DLA 作为平台参照。A、B 是两个独立输入的 GoogLeNet 0–9 层组工作包，分别固定在 GPU、DLA，各重复 1,000 次。来源表给单次 0.45/0.75 ms，模型将其汇总为 0.45/0.75 s 独占服务需求。**不是两次完整网络推理，也没有重建原 TensorRT 引擎、驱动或真实频点**；聚合工作包忽略重复调用间隙和逐层争用变化。FP16精度条件固定，不另行声称模型精度实测。该合法层组映射和时长来自 [HaX-CoNN，Table 2，作者 PDF 第4页](https://arxiv.org/abs/2308.05869)。

## 2. 统一电热模型与公平比较

两个任务分别追踪剩余工作；热模型用共享结温 Tj 和板温 Tp。令并发时慢化为 s，独占时 s=1；归一化实际频率为 f：

```text
任务进度速率 = f / s
Pdyn = Σ(活跃任务 Pi) × f^α × [ρ + (1−ρ)/s]，α=1
L(Tj) = L45 × exp[β(Tj−45)]
Cj·dTj/dt = Pdyn + L(Tj) + Phost − (Tj−Tp)/Rjp
Cp·dTp/dt = (Tj−Tp)/Rjp + (Pbase−Pexternal) − (Tp−Tamb)/Rpa
E = ∫[Pdyn + L(Tj) + Pbase + Phost]dt + 2·Elaunch
```

ρ=0 时，固定频率下纯停顿不会凭空增加有效运算动态能量；ρ>0 时，停顿仍耗电。Phost 从首个任务释放到两个任务均完成计费，包含有待执行任务的间隙。启动能量在真实启动事件计入并注入结节点。底座与漏电在整个窗口持续计费，完成后的空闲不截掉。漏电不随设备电源门控改变，未引入额外关机收益。

九个候选为：同时启动 C；A先启动、B延迟A独占时长25%/50%/75%的 A25/A50/A75；反向 B25/B50/B75；首任务**实际完成后**启动次任务的 S_AB/S_BA。所有偏移在比较前固定，不根据温度重新定义绝对时间。“最佳”“oracle”均限这九个动作，不是连续时域全局最优。

主窗口 H=1.5 s，两任务期限 D=1.5 s。主组实际频率 f=1，要求结峰温≤86°C、板峰温≤80°C；次级降频组在86/84°C回滞下令 f=0.75/1，安全上限91.5°C。模型未表示空间热点、电压表、逐层回退或真实内存控制器，不能凭此认证硬件热安全。

五种初态来自本模型空闲平衡和总输入10/15/20/25 W前序负载平衡。必须满足非负前序计算功率、板温和固定频率代理温限。名义 Tj 为 **28.324、35.65、42.40、49.15、55.90°C**，对应 Tp 为28.037、32.65、36.90、41.15、45.40°C。这是功率受控前序负载下的**模型可达平衡极限**，不是已观测的自然预热过程；还缺实际预热任务和稳定时间的测量。比较同一初态时前序能量相同，故不计入当前窗口；跨温度不直接拿总能耗差当调度收益。

积分采用最大1 ms步长的RK4，并在启动、完成时刻拆步；降频判断在步边界进行。完整能耗仅指上述**已明确模型边界**，不是墙插实测；监测与决策额外成本另作盈亏平衡分析。

## 4. 结果与机制解释

### 4.1 名义模型：普通争用足以解释排序

下面为整个1.5 s窗口输入能量，单位J。完整九候选表及动态、漏电、底座、主机分解在 `single_window.csv`。

| 初始Tj | C完全并发 | A50部分错开 | S_AB | S_BA最佳 |
|---:|---:|---:|---:|---:|
| 28.324°C | 14.801089 | 14.755276 | 14.709430 | 14.708861 |
| 35.650°C | 14.888699 | 14.842779 | 14.796837 | 14.796146 |
| 42.400°C | 14.976961 | 14.930931 | 14.884891 | 14.884071 |
| 49.150°C | 15.073142 | 15.026988 | 14.980840 | 14.979872 |
| 55.900°C | 15.177969 | 15.131677 | 15.085409 | 15.084273 |

温度提高能耗，但最佳动作不变。留出状态固定、阈值、九候选理想选择均为14.88800914 J；热信息增量为0。拟合阈值退化为恒选S_BA，不构成有效温度控制。

关闭温度反馈、保留常数漏电时，可直接推导 a≤b 的并发与串行能量差：

```text
E_C − E_serial = a × [ρ(s−1)(PA+PB) + h(s−2)]
```

其中a=0.45 s、b=0.75 s，h为主机忙时功率。第一项是重叠停顿的额外动态能量，第二项是完成时间变化的主机能量。名义代入得 **0.09 J**，与数值消融一致，而且与初温无关。冷态完整模型差为0.092228 J，仅余约0.002228 J是热轨迹导致的漏电差；不能把全部节能归于热感知。

| 冷态消融 | 并发C能量 | 串行S_BA能量 | 最佳关系 |
|---|---:|---:|---|
| 无争用、常数漏电 | 14.550100 | 15.000100 | 并发 |
| 无争用、温度漏电 | 14.258101 | 14.708861 | 并发 |
| 有争用、常数漏电 | 15.090100 | 15.000100 | 串行 |
| 有争用、温度漏电 | 14.801089 | 14.708861 | 串行 |

关闭温度反馈是令β=0并保留L45，因此常数漏电在低于45°C时可能高于温度模型；不要把消融前后绝对能量下降本身解释为节能策略收益。应看各组内的排序和增量。

### 4.2 参数扫描：两个微小反例，不能作为成功

62组有效参数中：**0组达到严格反转判据，2组最佳动作随初态变化，60组不变**。所有单窗候选在各自组内均满足模型可行性条件。

| 参数ID | 五初态最佳动作 | 五状态九候选oracle比共同固定增益 | 留出oracle增益 | 留出阈值增益 |
|---|---|---:|---:|---:|
| lhs_42 | C / B25 / B25 / B25 / B25 | 0.001130334% | 0 | −0.002158949% |
| lhs_43 | C / B25 / B25 / B25 / B25 | 0.000042769% | 0 | 0 |

这里的oracle是假设知道每个离散初态的全部候选结果的模型上界，不是已实现调度器；五状态平均采用等权，未假定真实到达分布。lhs_42的C−B25在冷、最温初态为−1.049178/+15.428861 mJ，lhs_43为−0.038247/+1.737821 mJ。冷热差跨零，但冷端优势很小；最佳共同固定B25已经几乎吃掉全部收益。

两组追加漏电消融后，各初态最佳动作分别恒为C、B25，支持“**在这个模型里**，温度相关漏电能扰动近乎并列的动作排序”的解释。没有争用或频率随初态变化；微小反转属于热轨迹与非热代价接近抵消的结果。两组全部5初态×9动作从1 ms缩至0.25 ms，最大能量差4.72×10⁻¹² J，远小于上述差值。因此它不是该积分精度造成的，但**数值可分辨不等于硬件可测或模型可信**。

所有62组的留出oracle增益最大为0，阈值最大为0；lhs_42阈值选择在一个留出点上失配，比固定策略平均多耗约399 μJ。样本内最大理想收益折合约210 μJ/工作包，仅来自一个冷点，不能当部署预算。对留出结果添加0/10/100/1000 μJ的每次额外监测与决策成本后，没有正净收益；结果见 `overhead_sensitivity.csv`。这些成本只是敏感性假设，无实测误差条。

### 4.3 热降频：正式样本未激活

正式单窗最高结温85.2340°C，低于86°C代理门限；全部周期运行的降频活跃时长也为0。启用/关闭降频的数值相同，只说明**当前条件没有激活该机制**，不是降频对调度无影响。

另以Tj=87°C、Tp=70°C作程序边界单元检查，控制器活跃13 ms，完成时间从0.885变为0.88825 s。该初态不属于冻结实验入组规则，结果只验证程序分支可执行，**不作为机制实验证据，不计入反转或收益统计**。没有为了触发降频修改正式参数。

### 4.4 周期热积累：能耗偏差存在，策略增益未出现

名义周期1.5 s连续240次，实际携带末态温度：

| 策略 | 240周期总能量J | 末20周期平均J | 动作切换 |
|---|---:|---:|---:|
| C | 3570.922429 | 14.884431 | 0 |
| S_AB | 3548.777133 | 14.792114 | 0 |
| S_BA | 3548.767942 | 14.792114 | 0 |
| 简单阈值 | 3548.767942 | 14.792114 | 0 |
| 每周期九候选即时枚举 | 3548.767942 | 14.792114 | 0 |

每周期无成本重置到冷态的诊断值为3530.126721 J，比真实携带温度少计18.641221 J，约0.525%。这个差说明不应重置温度评估长期能耗，**不等于热自适应策略能省下这部分能量**。重置模型不是可部署的免费冷却动作。

周期1.25和2 s的名义最佳固定动作仍为S_BA，阈值和即时枚举相同。预定16组参数的周期测试中，阈值未胜过同序列事后最佳固定策略，最大相对劣化约0.00177664%。两组结果后诊断lhs_42/43在240周期内都恒选C，与该序列最佳固定C相同。它们从冷态开始的周期轨迹未跨阈值，说明单窗多初态排序变化未自动成为持续负载收益。

周期比较只枚举九个固定动作、已拟合阈值，名义另有即时枚举，**没有求多周期全局动作序列最优**，因此不声称任何可能的自适应序列都无价值。名义周期末相邻温差≤6.24×10⁻⁷°C；扫描子集最大约0.001755°C，仍有残余收敛，报告为有限240周期结果，不冒称精确稳态。

### 4.5 尾窗与工作粒度

H延至3/15/90 s而期限保持1.5 s时，冷热端最佳仍为S_BA。K缩至1或10且期限与评价窗口等比例缩放时，冷热端最佳也未变。K之间工作量不同，只能比较**同K内**动作；50 μJ启动成本仍保留，K=1时其相对影响更大。未用截去空闲尾部或改变窗口来制造收益。

## 5. 数值验证、局限与研究决策

七项模型验证覆盖：无争用/无忙时/常数漏电的能量不变式，解析重叠进度与动态能量，串行事件时刻，独立矩阵指数RC解，热守恒，能量分项求和，移除热反馈后携带/重置温度的能量一致性。RC状态最大误差3.79×10⁻⁹°C；正式矩阵最大热守恒残差2.57×10⁻¹¹ J；步长复核未出现可行性翻转。**这些是计算验证，不是物理标定或测量精度。**

本轮回答了：在明确且固定的简化模型中，偏移能影响总能耗；普通争用即可改变并发/串行排序；热漏电能改变少量近并列动作，但已测试的温度信息没有可用增量；热积累需要保留，却未产生已验证的自适应收益。尚未回答：真实设备的系数与空间热点、活跃热降频、真实前序工作与到达分布、切换/监测成本、连续偏移和全局周期序列的价值。
