## 强对照与归因

- 扩展域的六个方法共享相同部署解码器、合法性判定、物理回放和频率范围。初始部署均含 A、C 及按种子从其余原代表无放回抽取的六项。Kim 和 GA 再从全扩展域均匀抽取，分别补齐至 24 和 32 个体。GA 按其原机制随机初始化频率；Kim 与协同算法以原 SetFreq 初始化。原域和扩展域的协同法完全共享八个起点。初始化对旧域有偏好，后续新解均在搜索中取得。
- Kim-Adapt+SAFE 沿用场景 SetFreq、Lexicase、交叉/变异与代理排序。上限 64 代，95 s 后转入连续热回退，按排序检查至首个 SAFE、池尽或 116 s，不设回退条数上限。Thermal-GA 沿用全窗热排序、锦标赛、精英及变异/交叉，上限 96 代。
- 协同算法每次从已经物理回放的状态提议切点、物理重绑、跨网 DLA 名额转让或交换以及场景 DVFS，最多 32 轮、每轮接纳 6 个新状态。最多 200 个不同策略进行完整物理评价。有限预算下的搜索质量和实际用时均保留。轮数先到即停，120 s 为共同上限，实际计算量可不同。[算法与消融伪代码](mechanism.md)
- 四组 25°C 采用原 81 域已证最优能耗。若扩展域出现更低的 SAFE 见证，则新域最优能耗至少下降两者之差。给出的新域数值是可行上界。27.5°C 的历史四部署结果只作该子域参照。30°C 沿用预定场景。热工况的旧域同算法对照用于比较预算内的搜索结果。
- 节能按同工况同种子、双方 SAFE 计算，每对为 `100 × (对照能耗 − 完整算法能耗) / 对照能耗`，报告配对均值与胜平负。等能容差为 10⁻⁷ J。三种消融分别删除显式热信息、显式排队信息、一次跨网动作。它们衡量本实现里的边际作用；单网动作仍可多步重分配，期限裕量亦反映排队。五种子结果为描述性比较。

## 复算入口

以下命令从分支仓库根目录执行，Python 的 `-B` 避免写入字节码。核对已归档结果只需静态输入及 Python 依赖；独立复跑物理实验须符合历史冻结清单（Python 3.12.4、包与运行时指纹）。`--cores` 按本机实际物理核心的逻辑编号传入，本次为 0,2,4,6,8,10。

```powershell
$study = 'research/ch3_cooperative_cuts'
python -B "$study/analyze.py" --source-root . --archives "$study/archives" --output "$study/tables"
python -B "$study/trace_winners.py" --source-root .
python -B "$study/explain_energy.py" --source-root . --tables "$study/tables"
```

如需独立重跑，在干净检出中执行以下命令。原始记录按工况和种子保存到 `units`，归档脚本核验每份回执、原始成员与归档字节。

```powershell
python -B "$study/run_study.py" --source-root . --jit-cache "$env:TEMP/ch3-cuts-jit" --cores 0,2,4,6,8,10
python -B "$study/archive_runs.py"
```

每份归档内含逐次带时间戳的候选搜索记录、资源与热机制分项（协同法）、选中部署的逐层绑定与四场景频率、完整连续物理证据和请求完成账本，以及配置和输出的 SHA-256。历史结果直接取自基础提交的 `research/ch3_final_experiments/formal/tables/run_results.csv`，含 90 次随机运行及 6 条同域参照。
