## 统计定义

- 首次 SAFE 为第一次通过连续认证并记入事件日志的时间。逐运行改进曲线只记录严格更低的已证 SAFE 系统焦耳。给定截止时间，已结束的算法沿用末次结果，尚无 SAFE 的运行能耗留空。
- 配对键为场景配置、温度和种子。同域节能率为 `100 × (对照能耗 − directed 能耗) / 对照能耗`，按双方均有 SAFE 的配对求均值。每一截止时刻同时报告有效配对数、单方可行数；胜平负采用 10⁻⁷ J 容差。
- 期限失败率为去重后的完整策略中，首个失败场景被事件调度器判定超期的比例。新算法在连续热回放前拒绝该策略；分母包含这些失败。Kim 的逐场景 SetFreq 代理筛选不属于完整策略提交。因而不同方法的候选失败率也反映其生成/筛选流程，不能视为最终交付失败率或直接转换为节省的秒数。
- 热修复从**已认证超温**的父状态起算。分母计直接产生、首次测试的不同子策略，包括被期限拒绝的子代；分子仅计整窗 SAFE 的子代。对已完成热回放的子代另记实际整窗峰温变化和能耗变化。四节点序号为 CPU、GPU、DLA0、DLA1；场景序号为本次执行顺序。原算法在超温候选上的离线探索与用户设备实际执行的 SAFE 策略分开。
- 两个新方法的操作预约、能耗提示、搜索时间和归档策略共同冻结。各自在此前父状态基础上扩展，修复对照检验**整项定向策略**对搜索的影响。逐候选成功率受父状态分布影响；同种子最终能耗配对是机制归因的主要结果。新域最优能耗未知。

## 命令

在完整仓库根目录运行，已交付的归档可直接复算，不需要重新求解。SVG 保留可编辑文字，PDF 用于排版。

```powershell
$study = 'research/ch3_energy_repair'
python -B "$study/report_data.py" --root . --out "$study/tables"
python -B "$study/figures.py"
```

在干净检出上，用冻结依赖和已编译的相同数值核独立运行正式批次。改变 JIT 缓存预热状态会影响时间曲线。已有回执的槽会校验执行配置后跳过。

```powershell
python -B "$study/run.py" --root . --jit-cache "$env:TEMP/ch3-cuts-machine-6ec3214"
python -B "$study/archive.py"
```

每个新工况的 TAR 包含 10 份运行。每槽保留预约、进程日志、逐候选事件、返回状态、生成器与评价计数、最终切点/物理绑定/四场景 OPP、逐场景连续热上下界和全部最终请求账本。回执记录源码和输出 SHA-256。历史四法的原始数据由基准清单引用。[历史归档](../ch3_cooperative_cuts/archives/) · [执行配置](config.json) · [冻结输入哈希](frozen_inputs.json)
