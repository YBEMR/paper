# Kim 适配与 Thermal-GA 实现规范（拟冻结）

当前只定义 P2–P4 的接口和检验方案。数值结果见 P1 归档表。以下候选顺序、回退上限、种子和预算均为本次设计提案。

## 共同输入、评价与输出

输入由实例 ID、带 ID 的请求流、固定顺序的合法部署集合、四场景和 27 个 CPU/GPU/共享 DLA 三元组组成。使用 `kim_multidnn_expansion/catalog.json` 的物理绑定与 DLA 交换对称代表。一个部署贯穿整窗，频档仅在场景边界改动。所有方法使用同一资源争用、边界排空、计能及尾窗约定。模拟精度固定。四节点初温 30°C，温限 80°C。25°C 是环境参数。

输出部署、按执行顺序的四段频档、规范编码、内部代理分数和统一评价结果。保留每个请求的期限裕量、时间戳、峰温上下界及整窗能耗。期限失败先记 MISS_DEADLINE；上界全合规为 SAFE，任一下界越限为 UNSAFE_THERMAL，界跨阈值为 UNRESOLVED。单独记录有见证、取得范围证书、预算截止和候选耗尽。搜索截止后无见证不产生 NO_SAFE_PROVED。原搜索过程可保存诊断能耗；图 A/E/G 只读取 SAFE 能耗。所有准备、排序与最终回放均计入比较预算。

## Kim-Adapt

依据 Kim & Ha，IEEE TC 2023，§5.1、§5.2.1–5.2.3，算法 1–3。离线母论文随基准仓库保存于 `papers/2023_Kim_Energy_Aware_Mapping.pdf`。

| 原步骤 | 在本模型的具体处理 | P2 验收 |
|---|---|---|
| 单网络切分、实机剖析与 Pareto 候选 | 从冻结目录读取结构和已固定的物理绑定。原作者的引擎构建、功率实测和 GA 生成的历史 Pareto 集缺失。两种 Kim 适配都用同一合成目录 | 对照 A、C 和两个扩展部署的层段、处理器和 DLA 段数；记录目录 SHA |
| 算法 1 的部署染色体与算法 2 的绑定 | 主比较用现成的 81 个物理代表依公开目录顺序访问，每个合法部署做一次算法 1 评价。外层确定性遍历替代原论文的外层 GA，物理映射由目录提供。记录已访问与已完整评价部署数 | 小域按原顺序列出访问轨迹，核对容量约束、重复代表和预算停止位置 |
| 算法 3 SetFreq | 每场景由 HHH 起步，依 GPU→CPU→共享 DLA 两轮贪心。每轮处理某域时先回到该域最高档，其他域保留当前值，逐档下探。检查该场景全部请求期限；失败时回到该域上一个可调度档并结束该域，最高档已失败亦结束该域。本轮保留严格改善代理能耗的最优可调度三元组。第二轮检验回升某域是否改善能耗。保存每个受试三元组、通过状态和最佳值 | 用表驱动替身逐项核对尝试序列、失败回退、第二轮改善、无可调度动作和并列保留首个动作。另用 27 项小表作质量参照 |
| 算法 1 适应度 | 任一场景没有可调度动作则丢弃该部署。每个场景以相同初温独立计算冻结板级功耗模型下的场景能耗代理，末段含尾窗，按实际驻留累加。原论文算法 1 对场景适应度取平均；此处公开使用本任务的有序驻留窗。只用期限筛查进行内部排序。场景重置与真实完整输出分别记账 | 固定实例手算总分、尾段只计一次；核对代理分数、真实能耗两个字段 |
| 输出 | 以总分、目录顺序、规范编码稳定排序，取首个，在真实入口温度连续传播的统一评价器中完整回放一次。超温、超期或数值未决保留原结果 | 逐请求校验与四节点全窗证书一致；测试禁止读取 CT 最优表指导排序 |

同一算法超期或多轮均未给出可调度候选，分别标注超期原因或 NO_SELECTION；内部评价遇到数值故障须保存故障记录。算法 3 的严格改善采用预注册的 (10^{-9}) J 容差和固定并列顺序。31→161→81 的筛选属于合成平台的冻结输入，在论文中明确 Kim-Adapt 的适配身份。

## Kim-Adapt+SAFE

与 Kim-Adapt 共享候选生成、排序与分数；比较计时各自从冷启动开始。先检第一名，如回放超温、超期或未决，按已冻结的原排序继续。提案最多检 **3 个不同部署—频率序列**，首个 SAFE 即返回；达到上限、耗尽排序、超时分别记录，保留每次失败原因。为避免把最后一条未完成回放算作见证，预留最终回放时间并以落盘时间结算。逐项断言两版候选顺序相同，增强版第一名 SAFE 时输出应与原版相同。若代理候选不足 3 个，按实数报告。禁止利用全域 SAFE 分类表挑回退对象。

## Thermal-GA

染色体为一个合法常驻部署 ID 和四个场景频档索引。部署基因均匀取自比较域，频率基因取 0–26。拟用种群 16、精英 1、二元锦标赛、均匀交叉概率 0.8，各基因独立以 0.2 概率重采样为合法值。初代随机，按冻结种子记录。用统一连续评价器评价个体；已评的完全相同染色体复用原判定，并记录请求数和唯一评价数。每个种子最多 8 代（含初代）或 120 s，先达到者结算。

按可行性优先排序。SAFE 个体按整窗能耗、规范编码升序；失败个体按超期请求数、最大超期量、已确认热越限量和规范编码排序。统一规定热数值未决位于已认证 SAFE 后面，单列并保存上下界；某项因提前退出而缺失时按最差值处理。所有正式 SAFE 见证都需落盘通过完整热与期限复核。保留初次 SAFE 时间、各代最佳、失败类别、每个种子的预算与结果。汇报成功数/种子数及 SAFE 能耗的中位数和范围；无 SAFE 的种子保留在成功率分母。最优差距只对同一域、同一请求流、已知最低 SAFE 能耗的实例计算。
