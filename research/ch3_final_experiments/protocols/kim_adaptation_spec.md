# P2 规范修订：Kim 的外层搜索、SetFreq 与安全回退

**方法身份。** 论文主对照 `Kim-Adapt` 保留应用映射组合的外层 GA，内层按场景调用 SetFreq。确定性遍历 81 个代表的旧提案更名为 **Kim 式 SetFreq 枚举适配版**（`SetFreq-Enum81`），仅作范围可控的诊断。P0–P1 表中的 Kim 栏均为未运行；本修订定义后续实现及验收。

**外层 GA 接口。** 使用每应用一个结构等位基因，加一个适配用的物理绑定索引。由 `catalog.json` 中 `per_app_candidate_ids` 分组，同组合法代表按部署 ID 稳定排序；绑定索引指向组内代表。容量超限、空组或越界绑定记为非法个体，不计为已评价部署。初始化在本轮允许域内抽取合法代表并编码；均匀交叉可交换各应用等位，单点变异可改一个结构或组内绑定。索引越界后的重采样和失败计费须预先固定。小域测试要求合法编码往返、81 个代表全部可表达，并列出算法 2 被替换的绑定步骤。可表达的代表数与限时实际访问数分别记录。

Lexicase 提案以四个场景的内部代理能耗为选择用例，以预先固定的种子打乱场景顺序，逐场景保留最小值容差内的个体，末尾并列随机选取。全场景期限合格的个体优先；整代均无合格个体时按期限合格场景数择优并记录。论文给出了选择算子名称；本段的用例向量、容差与非法处理是本项目的实现约定。输出候选池仅包括完整评价且四场景期限合格的部署及其 SetFreq 方案。按总代价、目录顺序与频率编码稳定排序，能耗并列容差拟用 10⁻⁹ J。原文未给出的概率与停止细节须写入预注册。禁止使用历史 SAFE 标签、CT 最优解或全域分类引导搜索。

## Kim-Adapt 与 Kim-Adapt+SAFE 的配对验收

两版使用相同种子、初始种群、生成算子、已冻结的生成预算和评分类别；为认证预留独立时间，两版均计入同一总墙钟上限。保存候选池有序摘要、随机数生成器版本、评价次数、唯一部署数、剩余预算。小域替身测试要求同种子同池同序；正式运行遇到截止导致两池不同，标为非同池，不能归因于回退本身。

1. 原版只完整检验排序第一名。增强版依次检查不同的（部署，四段频率）对，遇第一条经完整回放的 SAFE 即返回。每次拒绝记录超温、超期或数值未决及用时。重复候选跳过并计数。
2. P2 的 **K=3 指最多检查 3 条，含首选**。候选少于 K、候选耗尽、达到 K、进程截止和验证故障分别结算。检查预算含冷启动至证书落盘。保留所有已确认见证；未找到见证时不签发全域无解证书。
3. P2 只测生成耗时、首检与额外回放耗时、实际可检查数。冻结正式 K、生成预算和预留回放时间时公布依据；试跑质量或与 CT 的能耗差不参与选 K。若时限不足以完成一条认证，应调整申请或停止推进。
4. 确定性诊断 `SetFreq-Enum81` 使用相同内层评价和计分，外层按目录顺序穷举。只在替身小域检查 GA 最佳代理值与枚举参照的关系；81 部署正式诊断须另列预算。其输出使用独立方法 ID。

## Thermal-GA 与共用结果接口

Thermal-GA 直接搜索一个合法部署和四个场景的频率索引，个体按完整连续热与期限评价。它与 Kim 的“搜索部署、SetFreq 选频”采用不同决策变量。P2 试参数为种群 16、最多 8 代（含初代）、精英 1、二元锦标赛、均匀交叉概率 0.8、逐基因变异概率 0.2。按完整个体缓存重复评价，分别记录候选位置、唯一评价数、回放耗时与实际完成代数。正式代数、种群及种子数在 P2 后决定，8 代仅是试运行上限。

SAFE 优先；SAFE 个体按全窗能耗、编码排序。失败或未决个体按预注册的期限／温限违反量和确定性并列规则处理，缺失量不给予有利排名。统一记录请求完成率、最小期限裕量、峰温上下界、完整能耗、首次 SAFE 时间与证书范围。四节点初温 30°C、温限 80°C、含尾窗的完整系统能耗沿用冻结模型。两种随机主方法均报告各自种子和全部失败次数；最优差距只对同请求、同候选域且有精确证书的实例计算。

**进入 P2 的验收顺序。** 先用替身验证外层编码/算子、SetFreq 尝试序列、期限失败、第二轮改善、并列、同种子排序、首选 SAFE、第三条 SAFE、全部失败、未决/截止与空候选。再按[预算表](P2-P4_minimum.md)申请真实小域试运行。通过验收后提交代码、候选池摘要、成本记录与正式参数冻结稿。
