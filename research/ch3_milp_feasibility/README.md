# 第三章有限域 MILP 可行性判别

**建议保留 M2 为论文的有限域精确参照，将本实现收录为经验证的替代求解器。本轮探索结束。** 两组问题均在 120 s 内重现已有最低 SAFE 能耗，并取得全域数值证书。常温 81 部署的取证时间由历史 M2 的 56.49 s 降到 29.42 s。这里的可迁移发现是可以分开计算精确能耗和按需认证连续峰温。现有证据不足以把时间差归功于整数规划本身，也不足以据此替换第三章主线。

## 主问题与证书如何对应原问题

1. **原始合法域。** 从冻结的目录选择一项四网常驻部署，切点、DLA 容量和物理绑定随部署确定。A 采用完整 81 项，B 仅采用指定四项。每场景有 27 个原 CPU/GPU/DLA 频档。按原始事件调度器检验每个场景的请求期限。合格场景在服务边界排空队列，因此场景期限筛查可组合。缓存键包含场景、活跃应用的具名物理阶段链和频档；缓存限于同一请求流、环境温度与进程。原工作量、FP16、四节点、漏电与尾窗由冻结物理模块验证。没有 Stage 起点决策变量。历史带可移动 Stage 和 400 ms 尾段的 MILP 仅用于辨明研究边界。[旧模型结构审查](../chapter3_experiments/milp_structure_audit.md)
2. **整数选择。** 二元变量 z[d] 选唯一部署；y[j,f] 选场景频档。期限可行的三元组设连续变量 x[d,j,f]∈[0,1]。施加 Σ_f x[d,j,f]=z[d]、Σ_d x[d,j,f]=y[j,f]、Σ_d z[d]=1，于是整数可行解中每场景恰有一项 x=1。模型无需为每条完整序列建变量。
3. **精确仿射系数。** 令 t 为相对四节点初温 30°C 的偏移。固定事件链和频档时，两条不同入口轨迹的温差遵循同一个齐次线性热系统。原求积器从 30°C 计算参考能耗 e 和出口偏移 b，沿用 M2 特征模态计算 F 和漏电能量梯度 w。因此出口为 b+Ft，全窗能耗为 Σ(e+wᵀt)，包括最后场景的 40 ms 尾窗。仅物理相同的片段复用系数。[原精确仿射热核](../kim_scene_dvfs_admission/joint_thermal.py)
4. **入口线性化。** 逐部署从 t₀=0 区间传播，按矩阵元素正负计算所有档位出口的外包络，逐层向外扩 10⁻⁸ °C。对各模式引入四维入口贡献 v，施加 lx≤v≤ux。对相邻场景约束 Σv_next=Σ(bx+Fv)。由于整解中只有一个 x 激活，v 精确等于所选入口，非激活贡献为零。第一场景入口已知；末场景出口可由所选映射恢复。目标为 Σ(ex+wᵀv)。按同样的区间下界，只有在包含某选择的方案必定差于已认证 SAFE 上界时才固定该选择为零。
5. **连续峰温。** 第一次求解采用能耗/期限松弛。每个选出候选都经原评价器从首场景回放至完整尾窗，保留四节点连续峰温上下界和全部请求完成账本。下界越限的确定性前缀可排除其所有后缀。每场景在参考轨迹为每节点选一个事件边界时刻 τ，其真实点温度是 pₙ(τ)+hₙ(τ)ᵀt。对安全解，在这些点温度必不超限，可加入 (pₙ−80−10⁻⁸)x+hₙᵀv≤0。点约束只提供必要条件。SAFE 判定使用原评价器全窗上界 ≤80°C；无法确定安全或超温时停止，不用该点生成违规切割。
6. **最优性。** 在精确算术中，所有可能改善已认证上界的原 SAFE 整解都保留在松弛内。有效主问题下界与可行 SAFE 能耗夹住原最优值。实作保守扣减求解器对偶界 10⁻⁸ J，并以 10⁻⁷ J 为闭合阈值。给出的证书适用于各自冻结的有限域和双精度模型。独立核验器从归档系数作前缀覆盖，逐项验证报告下界；无需重新调用 HiGHS，也不使用历史最优值形成该证明。
