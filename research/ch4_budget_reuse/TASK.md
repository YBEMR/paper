## 一 任务目标与执行范围

请直接执行本任务书规定的适配、必要核验、最小匹配实验和 GitHub 归档，并依据预先规定的判据给出第四章的收敛结论。常规实现选择由 Work 自行处理，不再开展一轮算法选题讨论。

第三章当前主算法已选定为 ed437fc 中的 Energy-Only。本轮研究第四章的独立问题：在相同连续热约束下，怎样利用场景结构复用精确评价，以及是否值得据此分配有限搜索计算预算，使达到同等安全解质量所需的时间减少。

本轮必须分别回答：

1. 按需接入 M2 后，实际候选调用流的评价是否等价、是否节省时间，构核和峰温回退能否在有效求解阶段摊销？

3. 若实施下文唯一候选规则，它相对 Energy-Only＋M2 是否还有可辨识的额外收益？

研究范围在本任务内收束。保留原 81 部署域的覆盖与最优性认证成果；不要求对 4,319,803 个代表部署完成全域最优性证明。无需重做 Kim、双网联合修复、热点定向修复或第三章父状态消融，不新增网络、负载、温度、种子和第二条搜索规则。

### C 允许的唯一变化

保持原候选池、父状态、超温档案资格、重启、SetFreq 和总名额不变。继续优先满足原期限风险分层，保留 DVFS、交换、其他结构动作的原保留名额；在余下填充名额中保留一个按原能耗顺序选择的候选。其余填充名额使用：

`score(c) = max(Ehat(parent) - Ehat(c), 0) / Chat(c | 当前缓存)`

`Ehat` 使用现有能耗代理，在相同父状态温度条件下比较。`Chat` 使用本次运行已经完成的调用统计，以及廉价可获知的核命中/未命中信息，估计尚需支付的评价成本；用简单计数和时间均值即可，不训练模型、不离线调参。核查询与传播、冷构核所需工作、过去观测的峰温回退成本均应考虑。缓存状态以已经完成的计算为准；选取与统计自身的耗时计入搜索预算。

## 五 指标与判定口径

### 主指标

既定参考能耗直接读取 ed437fc 同工况的共同最低已见 SAFE 值，主目标为该值×1.001，另报 1e-7 J 容差内命中参考值。该参考仅供报告，不注入起点、搜索评分或提前停止逻辑；不因 C 的结果改变主目标。若发现更低能耗，另外报告。

必须报告首次 SAFE、目标命中时间、5/10/20 s 与 116 s 的最好 SAFE 能耗和命中数，以及完整改善曲线。尚未获得 SAFE、尚未命中目标分别记为未达成；不能删除失败运行后只比较成功者时间，也不能把未命中直接伪装为“116 s 命中”。晚于接纳截止返回的方案不进入计分曲线。

C 只影响主循环；首 SAFE 若来自八个起点，其相对 B 的主要价值应看后续到达质量目标的时间，不能用启动噪声宣称搜索规则改善首解。

### 解释指标

用互斥或明确标明包含关系的计时记录初始化、候选生成/排序、调度、SetFreq 代理热计算、热核构建、查询及仿射传播、峰温筛查、原积分回退、证书补算和日志开销。避免父子计时重复相加。单列调用量、实际构核数、合法核命中、期限拒绝命中、回退、缓存淘汰与峰值内存。

至少区分到达参考目标之前的有效求解阶段与后续探索，另给 0—20 s 和 20—116 s 统计。分项统计用于解释，不能以候选数、后期命中率或吞吐量代替主指标。

### 预先约定的采用门槛

为防止根据很小的差异反复调整，采用以下工程决策门槛；它不代表统计显著性或普遍优势：

- 比较 B/A、C/B，并对拟采用的 C 另比较 C/A。以九个同工况同种子的主目标命中时间之比计算配对中位改善；不跨工况直接平均焦耳。
- 将配对中位命中时间下降至少 10% 作为清楚时间收益的门槛，各工况配对中位时间退化不超过 10%；未命中不得从比值统计中悄悄剔除。
- 候选方案应保留匹配基线在 20 s 的主目标命中数，保持 116 s 的 SAFE 成功数，且同种子最终 SAFE 能耗不劣于匹配基线超过 1e-7 J。
- 若主目标命中发生截尾，完整报告命中数及截尾，不能依靠删失样本宣称通过时间门槛。

10% 仅作为时间收益的采用门槛。独立的质量路线固定看 20 s：至少一个预定工况的三个种子相对匹配基线均有超过 1e-7 J 等价容差的已认证 SAFE 能耗改善，其余工况中位能耗不退化，并满足上述 SAFE 成功数、目标命中数和最终能耗保护条件时，可按“预算内解质量改善”保留方法。逐工况报告实际改善幅度，仅作三个种子的方向性证据；不将其改称加速，不事后换用其他检查点，不把数值容差误当作实际效果大小。

这些门槛在主结果产生前固定。不足门槛时写“未达到本轮采用标准”，不等于断言方法在任何场景都无效；也不因此补种子、改权重或设计另一规则。若实际机器波动或执行故障使本轮不可判断，保留原件并说明具体原因，不伪造成功结论或自动扩大矩阵。
