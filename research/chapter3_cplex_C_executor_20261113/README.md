## 科学验收和停止

完整 x0 仍为 23780 维，唯一 `check_feasibility=1` start；只有原生日志明确支持才记接纳，否则拒绝或未知。不因拒绝改连续变量、改成整数 start 或重新初始化。start 被拒绝时，已经启动的同一搜索可正常结束。

原生有限界、gap、根 LP、节点和向量各自记录，不能替代完整验收。公开 `MIPInfoCallback` 不注入候选、不加割、不改搜索参数；第一份/目标变化的 incumbent 向量另存。它不保证看到相同目标的不同调度、每个内部候选、割生成细节或受保护内核。日志保留原文及父进程接收时间；缓冲到达时间不冒充内部发生时间。根 LP 完成仅用明确日志，不由节点 0 或有限界推断。[IBM 根节点说明](https://www.ibm.com/docs/en/icos/22.1.2?topic=problems-too-much-time-node-0)、[信息回调说明](https://www.ibm.com/docs/en/icos/22.1.2?topic=callbacks-what-is-informational-callback)。

严格成功必须同时满足：及时收到的最终原生完整向量；原/互补矩阵绝对及归一化残差均≤1e−9、整数距离≤1e−6；原独立调度合法性；AB/AC 全部连续电热 SAFE 且原精度达标；调度不同；以完整精度有理区间比较 `新能耗上界 < 本次共同初解能耗下界`。原生 `cᵀx` 与完整电热能量分别报告；舍入日志目标或 gap=0 不替代这个标准。

普通时限/无候选/start 拒绝/无改善：只结束本次，不重试，不冒称数学不可行。原生错误、内存状态或数值失败：保留原始错误和已有向量，不继续热评价。界与候选目标数值冲突、来源/正确性未知或清理异常：停止全部后续科研调用，需先明确影响范围。界一致性阈值为 `1e−7×max(1,|目标|,|下界|,|上界|)`，只作数值一致性检查，不作精确不可行证明。

若严格成功，下一步优先申请同一 CPLEX、统一表达/精度/初始化/预算、每组独立重构和认证的 A/B/C；不拿旧 intlinprog A/B 与新 CPLEX C 宣称加速。若只返回共同初解，先据根 LP、节点、界、start 和真实成本决定是否值得研究表示或精确分解。若因许可、内存、数值或时间限制结束，本次即停止，不扩大预算或补跑。
