CPLEX 自身在唯一 MIP 调用内部的预处理、根 LP、割、节点 LP 和启发式属于正常算法；不额外调用 `presolve()` 或独立诊断算法。`search=0` 允许原生自动选择；实际算法、线程与预处理情况据日志记录，未知不补推断。

完整 23780 维 `x0` 仅提交一次，保持 binary64，`MIP_starts.effort_level.check_feasibility=1`；不补交仅整数 start，不允许修复 effort、调度修复、重新初始化或改精度。共同初解在调用前通过新旧矩阵数值准入、独立合法性和原完整 AB/AC 评价，费用计时。矩阵准入残差阈值固定 1e−9、整数距离阈值 1e−6，记录绝对和归一化残差及最坏行；二者均满足才准入，不把浮点准入称为精确有理可行证明。

原生存入/读回成功与搜索接纳分开。仅明确原生日志/事件可标 `ACCEPTED`，否则记 `REJECTED` 或 `UNKNOWN`；start 不接纳时不切换方案，允许唯一已启动搜索自然结束。初解评价失败则不调用。

## 原生证据与候选

保存带父进程接收时刻的完整日志、原始行及解析依据；缓冲日志的到达时刻不冒充事件发生时刻。Display=4 用于根 LP 和 MIP start 信息；根 LP 进入/完成分别依据明确日志，有限下界或节点 0 不能单独证明根 LP 完成。记录预处理删除量/剩余规模、实际算法、节点数、迭代数、原生上下界和 gap 的来源。

只使用公开 `MIPInfoCallback` 信息回调，不使用会改变可选搜索行为的控制/查询回调。进度最多每秒一次，原生 incumbent 变化另记，回调不加割、不注入候选、不改参数。读取公开界、节点/迭代、incumbent 目标与向量；API 不可用或日志无对应信息则记未知。只有截止/资源保护可请求中止。信息回调兼容动态搜索，但观测仍有成本；它不保证暴露每个内部候选或受保护内核步骤。

返回后记录 `solution.get_status()/get_status_string()`、`is_primal_feasible()`、可用的 `get_values()/get_objective_value()`、`solution.MIP.get_best_objective()/get_mip_relative_gap()` 和 `solution.progress.get_num_nodes_processed()/get_num_iterations()`。不存在的字段为 null 并保留原因，不用外部初解填原生候选。界必须是有限实数且不是 CPLEX 无穷哨兵，保存原始值、方向和来源；原生界与同一个 MILP 可行点的 `cᵀx` 比较，不直接与独立物理能量比较。

及时收到的最终完整向量保存为 binary64 归档、记录哈希，再验证原互补矩阵与原变量前缀对应的原矩阵。只有通过整数距离检查后才解码选项，禁止把非整数候选修成整数调度。调度合法性调用原规则，完整电热评价调用原 `thermal.evaluate_candidate`，保持原配置精度和 AB/AC 两场景；不启动 MATLAB，不改用近似热评价器。

回调向量是额外原生过程证据。本候选只对及时返回的最终原生向量进行一次完整评价，不事后挑选历史回调向量补救；最终向量缺失则明确没有完整科学验收候选。

分层结论：身份 → 根 LP 进入/完成 → 有效原生界 → 原生完整候选 → 两矩阵准入 → 独立合法 → AB/AC SAFE → 调度不同 → 严格节能 → 独立最优性。每层独立记录 `PASS/FAIL/UNKNOWN/NOT_REACHED` 和证据文件。不得把保留外部初解、矩阵缩小、原生报告 gap=0 直接写为后层通过。

严格节能条件为 `E_new.upper < E_common.lower`，以完整精度十进制/有理区间端点比较，不用浮点舍入或经验百分比。历史共同初解区间约为 1.08488637130371118 J，完整端点在 JSON 中固定；新前置评价须符合相同来源与原精度，历史评价不能免费替代本次评价。候选同时必须与共同初解的规范化调度身份不同。缺少任一层则不宣称优化成功；没有独立证明时最优性始终未知。
