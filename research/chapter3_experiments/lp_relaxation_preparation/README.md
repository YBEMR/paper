# K.190独立连续松弛：零调用准备

本目录只有纯数值检查和协议生成，没有`execute`或MATLAB工作进程入口。运行`prepare.py`只读取K187归档数组、K189回执及本机R2023b可读源码；屏蔽Popen和SciPy两种优化入口，不构模、不积分、不评价调度。

唯一拟变换：从K187原载荷省略1681项整数性要求。LP参数仍是原`c/A/b/Aeq/beq/lb/ub`，不能使用K189固定后的上下界。原整数索引和x0保存在来源证据中，不传给LP；本机R2023b `linprog`不支持x0。

`lp_checks.py`逐项保留七数组，按原1e−9约束容差核返回值。原整数距离只登记，不影响LP接纳，不取整或修复。目标一致性检查沿K189的`1e−9*max(1,abs(c@x))`输出核对规则，不改变原生容差。LP的可行原始目标值本身不是MILP下界，更不是新SAFE/U。

`prepare.py`输出`results/k190_lp_preparation01`：15项纯夹具、真实数组身份、两份既有数值见证、R2023b接口/选项来源hash，以及`authorized=false`的单次300秒提案。实际原生选项对象和读回尚未运行。获批后才实现一次性独立LP交接及生命周期检查，冻结新执行目录，再消费唯一请求。

协议和范围以[报告](../../连续松弛数值诊断与小域精确对照准备_K190.md)为准。本轮不授权小范围整数释放、增广、3600秒、K168、期限24或小域研究求解。
