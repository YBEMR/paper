## 结论边界

最接近的历史参照是“现场 HEFT + 原模型”的同一 600 秒实验，最终保留上界 `0.920195499983960944974381976769171389159940855612137674194178 J`，没有在预算内改善初解。本次增加等价变换及逐向量原约束检查，并且主机资源状态不同，因此单次差异不能完全归因于精简。更早七方法对照中的 MILP 初始化不同，应单独标注。

本实例是 `bpre_recovered__R1`，包含两个评价场景，不能将两个场景视为两个独立实验样本；五次 SA 是同一实例的不同种子，不代表五个独立工作负载。温度和能量来自模型的完整区间评价，不是硬件实测。后续验证建议见分析报告，本次未开展任何新实验。
