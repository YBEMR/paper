# K.189：执行已批准的K.188固定整数诊断

本目录仅实现用户批准的1次300秒原生数值诊断，日历480秒。基础载荷为K187归档MAT；不构模、不初始化新调度、不调用热积分或正式评价器。

唯一变换：原MAT实际`intcon`的1681列上下界均设为原`x0`值。保留全部27971列、176953行、原目标、矩阵、索引、初始点和非整数列原界。整数坐标必须已精确为0或1，不取整、不修复、不删行。数值版本`original_binary64_rows_fixed_intcon_bounds_v1`。

原冻结`matlab_bridge.py`及`solve_model.m`直接复用。只恢复桥接模块`REPO`至本工作区，使MATLAB使用原有偏好目录；脚本来源`HERE`仍是K187源码快照。R2023b版本、Python包和原选项核对，只有`MaxTime`按根剩余预算变化。

## 一次性入口

依次使用同一Python环境执行`run_once.py prepare`、`precheck.py`、`run_once.py execute`。`prepare`绑定代码及原载荷hash；预检屏蔽真实子进程，仅使用手工夹具和归档矩阵静态运算。执行必须在宿主权限环境中进行，不能从Windows AppContainer启动MATLAB。

`execute`在启动前核查无其他MATLAB、至少2 GiB可用物理内存/4 GiB可提交余量/2 GiB磁盘。条件不足时不写调用占用记录。通过后以排他创建的launch/method/request记录限制一次执行、一次请求；旧记录存在即拒绝，无重试路线。该目录不是常驻科研工具。

300秒从worker导入科学模块和读取载荷之前计时，包含hash、输入读取、固定界、原点数值接纳、MATLAB启动、传输、原生求解及返回数值核对。原回调只归档，不解码或作热评价。源桥接通用metadata中的“independently evaluated”不适用于本诊断，实际消费者仅归档。根截止后不得新接纳；清理最多40秒、worker监督420秒，均受480秒日历限制。已捕获进程按PID＋创建时间核验，不能按进程名清理其他会话。

## 输出与停止

输出保存至`results/fixed_integer_native03`。`fixed_integer_native01/02`仅保留前两次冻结及纯测试失败记录：Windows平台读取、NumPy测试工具CPU特性探测先后被预检子进程屏蔽器拦截；均没有launch/method/request记录或原生调用。修正为先核对平台信息，数组断言改用无系统探测的`array_equal`，全部测试仍屏蔽子进程。40项组合测试及原载荷导出静态核对通过后冻结为03，不覆盖01/02；科研调用仍限1次。

数值结论与生命周期完成分开：原矩阵/固定界通过仍需核查原选项、预算及进程清理。出现`-2`且原x0通过时，记接纳状态冲突；超时记未决；任何异常留证后停止。

返回向量按原ConstraintTolerance=1e-9、IntegerTolerance=1e-6核原矩阵和固定界。额外核对`fval`与`c@x`，差异门为`1e-9*max(1,abs(c@x))`，仅作输出一致性检查，不改求解器选项，也不放宽原矩阵容差。返回辅助目标不记作新物理能耗、安全U或调度收益。

本次不进行60秒热post，不启动3600秒整体求解、K168或期限组剩余24次。运行结束不自动续接。原K188机器提案保留原待审批历史，新授权及实际执行记录单列。
