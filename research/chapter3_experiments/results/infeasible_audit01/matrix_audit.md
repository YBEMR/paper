# R2内部无解：归档矩阵独立只读审查

**结论：已定位到可复核的数值风险，但未证明根因。** 原始`x0`并非精确满足每一条导出浮点行，只在声明容差内接纳；同时，未发现它所代表的固定方案没有连续可行提升的证明。最值得核查的是**极紧的热／能量上下行、行内尺度跨度和LP预处理之间的作用**，不是重新寻找安全调度。

输入为`formal_comparison02/response_R__R2__milp/matlab/`中原请求MAT和原生MAT，完整数据及精确二进制有理数行见[matrix_audit.json](matrix_audit.json)。原档案审查前后SHA保持。未运行LP／MILP求解、热评价、调度搜索或完整模型重建，未回填正式结果。

## 1．矩阵与初始点的具体结构

| 项目 | 归档事实 |
|---|---:|
| 约束／变量／非零系数 | 511952／77347／6565025 |
| 保留整数列 | 6373，`x0`整数偏差为0 |
| 最小／最大非零系数绝对值 | 4.99924×10⁻⁸／60.2166 |
| 小于10⁻⁶／10⁻⁷的系数 | 777514／82080项；没有小于10⁻⁹的非零项 |
| 最大行内／列内系数跨度 | 约1.2004×10⁹／2.0003×10⁷ |
| 固定变量 | 8796个，全部固定为0；`x0`没有越界 |
| 空行 | 7行，均没有负右端，不构成`0≤负数`矛盾 |

系数绝对值没有极端到下溢量级，变量界也只在−5至55之间；风险主要是**同一行同时出现约60、1和10⁻⁷量级项，并在活动状态下相减形成极窄容许带**。不能简单称为“大M取了天文数值”。

按冻结构造顺序、温度变量连续块及归档逻辑列总数交叉核对，零基列范围为：

| 变量 | 半开列范围 |
|---|---|
| 全部逻辑列，包括已连续化的辅助逻辑量 | `[0,39740)`与`[47439,71736)`，共64037列 |
| AB温度 | `[39740,43164)`，856事件×4节点 |
| AC温度 | `[71736,74232)`，624事件×4节点 |
| AB／AC活动功率及分段能量 | `[43164,47439)`／`[74232,77347)`；每段四个q后接一个能量变量 |

64037个逻辑列的`x0`都精确为0或1。因此不存在“辅助量差一点才是整数”的接纳问题。**不能仅凭变量界为[0,1]来识别逻辑列**，这会混入少量物理变量。固定逻辑诊断应保留13310个物理连续变量，不先把名义温度／能量值锁死。

原生MAT的`initialPoint`与请求`x0`逐元素相同；没有目标严格改善截断，原选项`ObjectiveCutOff=Inf`，也没有热反馈排除行。因此，“只是在更优子域中无解”“初始点没有传进去”均不符合现有归档。

## 2．最大残差包含明显的取消误差

NumPy稀疏乘加报告1177个正残差行、最大2.13163×10⁻¹⁴。把这1177行的**原binary64系数及原binary64向量**精确转为有理数再点乘：

- 仅190行仍为正残差，987行实际满足；此核对不是全矩阵精确可行性证书。
- 零基行408179的普通残差为+2.13163×10⁻¹⁴，精确残差却为−2.12100×10⁻¹⁵。
- 零基行432923的精确残差为+2.48398×10⁻¹⁵；在已检查子集内，最大精确正残差为行401787的+4.30803×10⁻¹⁵。

所以，不能把普通最大残差直接解释成真实矛盾大小。但存在精确正残差也明确说明：**这个名义向量是容差接纳点，不是导出矩阵的精确可行点。**

## 3．一组可直接复核的紧行

零基行432922／432923（MATLAB行432923／432924）对应AC场景、CPU2、事件段344，即225⅓—225⅔ ms的`thermal_propagation`上下行。该对应关系由原构造顺序、温度列连续块及输入事件时刻重建核对；归档没有直接保存行tag。

两行绑定温度目标列73117，源温度列73112—73115、活动功率列75952—75955，选中状态门列60867为1。这时所有q均为0，已经在空闲尾段。固定其他名义值后：

- 目标容许区间宽度为精确的`1/140737488355328`，约7.10543×10⁻¹⁵；
- 名义目标值为23.989102998248956，低于该区间下端约2.48398×10⁻¹⁵；
- 目标变量界为[−5,55]，并非逼近温限或变量界；局部调整约一个浮点步长即可进入这两行的区间。

这组行解释了“独立热安全且容差接纳，仍不精确满足每条辅助行”怎样发生，但**不能用局部可调整性证明整条传播链可行，也不能用局部违约证明整条链无提升**。

进一步检查全部选中状态的相邻仿射上下行：

| 类型 | 对数 | 精确容许带宽范围 | 单对负宽度 |
|---|---:|---:|---:|
| 温度传播 | 5912 | 7.10543×10⁻¹⁵—2.13163×10⁻¹⁴ | 0 |
| 分段能量 | 1478 | 4.33681×10⁻¹⁹—2.08167×10⁻¹⁷ | 0 |

这些正宽度只表明**没有发现单对上下行自身矛盾**。它们仍通过前后温度、活动功率和能量下界相互连接，不构成全局连续可行提升的证明。

## 4．可证伪解释及最小后续

| 候选解释 | 当前依据 | 怎样区分 |
|---|---|---|
| 紧行尺度／预处理导致内部无解报告 | 行内跨度约10⁹、活动能量带宽约10⁻¹⁹；`IntegerPreprocess=none`并不意味着LP预处理也关闭 | 对原归档矩阵作单因素LP预处理诊断；取得向量后仍独立核归档行残差，不能以退出状态代替核对 |
| 该固定方案实际无连续提升 | 名义`x0`确有精确行违约 | 固定正确逻辑列，保留物理连续变量；可行提升会否定该解释。当前没有排除证书支持它 |
| 严格改进截断、漏传x0或整数偏差 | 现有归档均不支持 | 已核原目标域、原生初始向量和精确0/1，不优先沿此扩展 |

建议只做已经明确的原矩阵单因素诊断，或固定逻辑的连续提升诊断。若需提取更小行集，可先取上述两行及其原源值／目标界作为**局部数值夹具**；该夹具本身有正宽度，不能宣称它已经复现整个无解故障。要检验链式效应，至少保留相应前后传播、初温和能量下界关系。

本审查不开发精确提升器或MILP认证系统，不修改物理参数、工作负载、合法调度域或安全标准。当前能确认的是“名义点只有容差可行、紧行风险具体存在”；内部无解的最终根因仍待隔离诊断。
