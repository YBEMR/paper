# K132：数值表达最小路线

结论：**全局取补未通过精确导出门槛；仅在物理条件行使用补变量的增广表达通过了存档代数检查，可作为下一次受控原生接纳技术检查的唯一候选。** 尚未修复或复现原生 `exitflag=-2`。本轮没有求解、MATLAB启动、热重算、生产接口修改或Git操作。

输入为K131新版AB的已存请求MAT，8525变量、39733不等式、357483非零；变量标签由同阶段唯一重建且8数组逐项匹配的结果提供。本脚本仅读这两份存档，不导入生产构模、求解或热评价模块。详见[facts.json](facts.json)、[代数脚本](audit_saved_affine_route.py)。

## 被拒绝的全局取补

对2400个连续joint辅助量做`w=1−z`，其他变量不动。该变换在实数域可逆，也不修改441个整数选项。但导出必须令`b′=b−A·t`，269行`energy_state_lower_bound`的精确有理数右端不能由一个binary64精确表示。不能用最近浮点值或向外放宽后继续声称原存档数值多面体相同，故拒绝此路线。完整失败行见[rejected_full_complement_rhs.json](rejected_full_complement_rhs.json)。

脚本保留最近浮点右端上的诊断统计，但不导出该模型、不将其计为等价预检通过；`rhs_rational_roundtrip_exact_rows=null`表示门槛失败后未执行全局回映，不表示39733行全部失败。

## 通过存档代数检查的增广表达

保留全部原变量、原目标、原整数索引和非物理行。对每个joint量新增连续变量`v∈[0,1]`，加入精确链接`v+w=1`。仅把具有明确单一joint gate的24000个`thermal_propagation`／`complete_energy`行

\[
a^T x+M w\le b
\]

改写为

\[
a^T x-M v\le b-M.
\]

逐行将原binary64解释为精确二进制有理数，核得全部24000个`b−M`均能无损表示为binary64；系数只改变符号。链接消元后逐行恢复原行，因此增广模型在原变量上的**精确实数投影**相同。保留269个能量强化行避免了全局取补的右端障碍，原`Aeq`为空；若未来出现原等式，须原样扩零列保留。

| 存档代数检查 | 结果 |
|---|---:|
| 物理行消元后精确恢复 | 24000/24000 |
| 非物理原行逐项保持 | 15733/15733 |
| 连续gate交替取1/4、3/4时，原／新全部行残差精确分数相同 | 39733/39733 |
| 连续样本精确链接 | 2400/2400 |
| 原整数坐标、原目标系数及样本目标 | 保持 |
| x0原8525维前缀 | 按位保持 |
| x0补变量与链接 | 精确0/1；链接残差0 |

这不是新的可行性证书。原x0在原坐标的残差必须继续保存；[行追踪的有理数核查](../row_trace/tight_row_dyadic_facts.json)仍存在微小精确正残差，代数等价不能把它们抹掉。原输入上已独立完整评价的SAFE凭据也不因辅助变量数值状态被撤销。

代价明确：变量8525→10925（+2400，约28.2%）；不等式仍39733行，新增2400等式，总行42133（约+6.0%）；非零357483→362283（+4800，约1.34%）。没有原生运行，不能据非零增幅推断求解开销或收益。

仅作算术观察：同一x0的浮点最大正不等式残差从`2.1316282072803006e−14`变为`3.552713678800501e−15`，正残差行183→39；活跃物理行的“各项绝对值和加右端绝对值”中位数约168.636→48.651。原最坏浮点行16380的残差变号，说明求和取消发生了变化，不能解释成原行被修复。原最大同行系数比约4.80e9保持；其所在行13838在原x0上本来松弛约60，不能直接当作原生无解原因。

## 浮点接纳边界与接口要求

数学投影等价不表示容差接纳域相同。设链接误差`ε=w+v−1`，则原行残差与增广行残差满足

\[
r_{\mathrm{old}}=r_{\mathrm{aug}}+M\varepsilon.
\]

在原`ConstraintTolerance=1e−9`下，链接本身可允许约`M·1e−9`的原行偏移；存档最大物理gate系数60.1810551641，对应约`6.0181e−8`。不新增链接缩放、不调容差来掩盖它。后续若接生产接口，须同时保存增广残差、链接残差和**原矩阵原坐标残差**，不一致按数值状态处理，不能自动追加热反馈或宣称无解；完整物理SAFE仍只由原输入的独立评价提供。

未来接口只需保留原变量前缀，所有final和callback向量先核维数、数值有限、链接及原坐标残差，再投影前8525维交现有解码器。原前缀必须通过原矩阵、原变量界下的`1e−9`约束容差及`1e−6`整数容差接纳；未通过即停止当前数值路径并标为未决，不能只记录异常后继续采纳solver状态、候选或反馈。此前已在原输入上独立完整评价成立的SAFE证据保留。原`intcon`保持，新变量不入整数集；x0只追加精确`1−w`，不修复原前缀。目标附2400个零，因此`fval`及solver-reported lowerbound不需平移或改单位，但须保存原生字段并校验目标一致性，仍不得升级为独立界。`diagnostic_search.Recorder.poll`直接读取不可变事件文件，不能只在最终response做投影而漏掉callback。

动态热反馈继续在原模型上生成；每次请求重新适配全部明确单gate条件行，并保存该请求的原始矩阵、增广矩阵身份和列映射。新行若有多个gate或`b−M`不能精确binary64表示，直接拒绝该变换，不近似、不丢行、不删除强化行，也不悄悄退回其他方案。变换、检查、序列化和事件投影成本均应计入原方法预算。

## 不优先缩放的原因与下一步

正行缩放不改变同行系数比；对存档按行最大系数做二进制幂归一化虽可无损缩放数组，但缩放因子1/32至16会把原单位的绝对容差改成`3.2e−8`至`6.25e−11`，不是统一保留1e−9。连续变量对角缩放只会重新分配小时间步弱耦合的系数量级，每项`|a_j|·(ub_j−lb_j)`保持，可能把问题转移到活动功率等式；不直接缩放整数列。温度平移也不降低原系数比，本次联合取补并平移25会产生23614个不能单float精确表示的右端。以上均不作为本阶段实施候选。

建议下一阶段仅一次独立冻结的原生接纳技术检查：使用同一存档AB、上述唯一增广表达和原x0，不更换物理条件、目标、容差或安全标准；事先限定技术预算，保存原生x0接收／候选／退出和全部映射证据，返回后只做矩阵与目标复核，不重算热、不把结果补入K131质量配对。若出现相同`-2`、接口未决或新的表示失败，保留失败并停止；若原生接纳，也仅说明这一数值表达的技术兼容性，再决定是否实施生产接口。当前未执行这项检查。
