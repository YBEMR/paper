# K170：部分赋值下界与安全剪枝的数学合同

**推荐采用两个完整松弛的最大值，另与同条件legacy界取最大。** 不能把CPU前驱／驻留界直接加到已经分摊CPU基准的模式界上。本接口只给原模型下、指定部分赋值的能量下界；不是候选生成、热安全、可行性或全域最优证明。纯代数检查通过也不授权求解、热积分、正式评价或恢复原24次。

## 1．作用域和输入前提

保留主线四节点、有限窗口、固定必需Stage、auto-L、零切换／交接开销、单元独占、共享CPU域同频、GPU／NPU单设备及跨场景共享具体设备。场景权重非负且归一，所有场景的合法性都必须保留，包括零权重场景。时间统一换成秒，能量用J，全部运算使用精确有理数。

准备时必须核对：G对称、非对角非正、正接地行和，C正；环境温度等于功率参考温度25°C，入口温度不低于它；本地活动功率非负、时长正；L档逐节点基准注热和漏电系数不大于任何合法OPP；CPU L/M/H频率与基准单调，所有分布与域／单元／源节点一致。依赖图无环；请求、Stage、设备和场景身份唯一、成员关系完整，绝对期限在窗口内。未支持的声明应拒绝，不用默认值替换。

`prepare(instance)`预计算必须绑定输入身份并持有独立归一化快照。成本按**场景＋Stage副本＋模式**索引，因为绝对期限可能不同，不能只按共享Stage缓存。输入可变对象不得在准备后悄悄改变已缓存成本的解释。

## 2．背景和模式源成本

记每节点最低基准注热为b₀、最低漏电系数为λ₀，θ＝T−25。背景标量比较使用

\[
\beta=\max_k\frac{\sum_jG_{kj}-\lambda_{0,k}}{C_k}=19/20,
\quad\rho=\min_k b_{0,k}/C_k=25/6,
\quad x_{0,c}=\min_k\theta_{c,k}(0).
\]

采用三阶奇Taylor下包的背景面积

\[
Q_c=\frac\rho\beta W+
 (x_{0,c}-\frac\rho\beta)
 [W-\beta W^2/2+\beta^2W^3/6-\beta^3W^4/24].
\]

**当前这一式要求β＞0且x₀,c−ρ/β≥0。** 乘子为负时，不能继续把指数下包乘上它并称为下界；不满足即拒绝或采用另有证明的分支，本轮不自行扩展。P0入口50°C满足。背景总界为

\[
B=W(P_{ext}+\sum_g b_{g,L})+
\sum_c p_c(\sum_k\lambda_{0,k})Q_c.
\]

这里CPU基准每域计一次，CPU两个节点各计一份本地λ；外部共同功率不注热。不再叠加旧20°C负温度floor或另一份初温／基准响应。

Stage副本i的绝对期限Dᵢ及源节点k给出

\[
a_k=(G_{kk}-\lambda_{0,k})/C_k>0,\quad h_i=W-D_i,
\quad\eta_{ki}=\max\{0,(\lambda_{0,k}/C_k)(h_i-a_kh_i^2/2)\}.
\]

其直接活动及最低后续漏电成本为
\(s_i(m)=q_i(m)d_i(m)[1+\eta_{k(m)i}]\)。这是正系统分解的活动源下包，直接qd只算一次；实际活动时刻不晚于Dᵢ，使期限处响应是所有可能注热时刻的统一下界。β／ρ背景只计最低基准和初温，sᵢ只计活动及其额外漏电，因此二者可相加。

后述高OPP项只计**参考基准的正增量**，未把高OPP漏电另加进去；忽略非负额外漏电可以保持下界，不构成缺项错误。

## 3．部分赋值及共享设备的量词

部分赋值为`shared_units{shared_id:unit}`和`by_scene{scene_id:{stage_instance_id:{unit?,opp?}}}`。省略表示未赋值，空dict不表示L档或CPU。unit是具体执行单元，OPP按副本／场景限制；同一共享Stage可在不同场景选不同OPP，但具体单元必须一致。

先用全部显式字段筛选每副本剩余模式，再对每个共享身份取其所有副本共同支持unit的交集，并向全部副本传播。零权重副本同样参与合法unit交集。某副本显式CPU1而另一副本显式CPU2、`shared_units`与副本冲突、空剩余模式、未知身份／字段／设备／OPP或非法标量，均返回**无可用界**及原因，不忽略字段，不返回∞，不报告原问题已证无解。

对任意模式成本cᵢ(m)，定义保留共享unit的一致松弛

\[
\Phi(c)=\sum_{i\text{仅一个副本}}p_{scene(i)}\min_{m\in A_i}c_i(m)
 +\sum_{\tau\text{多副本}}\min_{u\in U_\tau}
   \sum_{i:\tau(i)=\tau}p_{scene(i)}
       \min_{m\in A_i:\,unit(m)=u}c_i(m).
\]

Aᵢ是经传播后的模式集，Uτ是共同unit集。对任一兼容完整安排，其实际unit是外层最小值的一个候选，实际模式是内层最小值的一个候选，所以Φ不超过该安排对应成本。这里既不把场景各自最优unit拼成共享部署，也不把共享设备误写成共享OPP。单副本组也可用同一min-unit公式，结果等价。

模式表中某支持模式可能因具体期限而无法形成完整安排；不删除它只会放松最小值，不会破坏有效性。返回有界数值也不证明部分赋值可完成。

## 4．容量分摊界Lcap

令域容量为N_g，模式的域参考基准增量为δ_g(m)＝b_g,opp−b_g,L≥0。CPU N＝2；GPU／NPU N＝1。对每个合法完整安排，各域同OPP活动总工作量不超过N倍该OPP驻留并集，因此

\[
c_i^{cap}(m)=s_i(m)+\delta_g(m)d_i(m)/N_g,
\qquad L_{cap}=B+\Phi(c^{cap})
\]

是部分域下界。此处CPU分摊只分一次域功率，不用两倍CPU基准。没有利用起点、单位互斥、依赖和温限的其余限制只会扩大松弛域，不会使下界偏高。

## 5．forced阈值界Lforced

对场景c及阈值r＝M或H，只有当某副本的**全部剩余模式**都在CPU且OPP≥r时，才放入F_c,r。只存在某个CPU/H选项不算强制。其时长下界取剩余模式最短时长ℓᵢ；如果全部剩余模式还属于同一具体CPU核，才进入该核已知工作量。

定义

\[
T_{c,r}=\max\{\tfrac12\sum_{i\in F_{c,r}}\ell_i,
 \max_{u\in CPU}\sum_{i\in F_{c,r}:unit\text{已强制为}u}\ell_i,
 CP_{c,r}\}.
\]

CP是**完整DAG**上将forced节点赋权ℓ、其余节点赋权0后的最长路径长度。这样可保留经GPU／NPU或非forced节点相连的前驱链；只在forced节点的直接边上求链会漏掉这些关系，但漏掉只变弱，虚构前驱关系会变得不安全。每个被计链上的forced任务都不能重叠，所以T_c,r不超过真实阈值驻留并集。

CPU三档用嵌套阈值分解：

\[
E^{CPU}_{extra}=0.30|I_{\ge M}|+0.40|I_H|,
\quad F_c^{CPU}=0.30T_{c,M}+0.40T_{c,H}.
\]

H被两个阈值计入是合法的阶梯分解；不能再把H全额0.70叠加到0.30阈值上。两个阈值分别求下界可相加，因为两个系数非负，且估计的是上式两项；单核工作量、总量/2和链是**同一项的替代界**，只能取max，不能相加。

令cᶠᵢ＝sᵢ＋GPU／NPU模式完整参考基准增量δd，CPU模式不加基准。则

\[
L_{forced}=B+\Phi(c^f)+\sum_c p_cF_c^{CPU}.
\]

GPU／NPU单设备独占、auto-L使其非L驻留等于相应任务时长之和，因此该分项可以逐模式计。Φ只放松合法组合，F则对每个兼容完整安排都成立；两个不相交计量分项相加安全。AB与AC驻留分别计算，再按权重加，不跨场景合并并集或工作量。

最终

\[
\boxed{L(P)=\max\{L_{cap}(P),L_{forced}(P),L_{legacy}(P)\}}.
\]

Llegacy为旧基准floor＋同部分模式限制／共享一致性的Φ(qd)，并标明这是**派生的条件legacy对照**，不是旧API早已支持逐副本OPP。三者每一个都不超过同一部分域中的每个完整安全安排，所以最大值仍安全。

## 6．必须覆盖的反例与预检

| 检查 | 应得到的行为 |
|---|---|
| 两核两个H任务同时执行各1秒，域额外功率δ | CPU额外仅δ，容量分摊δ、forced界δ；相加2δ错误，取max正确 |
| 两个H任务各1秒在不同核但有前驱链 | 驻留至少2秒，链强于总量/2与单核1秒；核标签不同不抹掉前驱 |
| H task同时属于≥M和H | 系数0.30＋0.40＝0.70，禁止0.30＋0.70 |
| GPU或NPU处于H | 单设备额外δd计一次；不再在forced GPU／NPU项另加一次 |
| `opp=H`但unit未定、还支持GPU/NPU | 不是forced CPU/H；不能借字面H把它压到CPU |
| CPU单元未定但所有剩余模式均CPU/H | 可计总量/2和DAG链，不能把整个工作量分别计给CPU1和CPU2 |
| 场景1偏好CPU、场景2偏好GPU | 共享unit松弛先共同选unit；两场景分别取unit的最小值只能作更弱对照 |
| 零权重场景的某unit不支持 | 该unit仍不在共享可行unit交集中；不能靠权重0忽略合法性 |
| 未知scene／stage／unit／OPP、字段拼错、分布错源、冲突或空模式 | 拒绝生成界／剪枝，不静默忽略、不报全域无解 |
| 部分赋值增加约束 | 兼容域只缩小；源／容量／legacy松弛最小值不应下降。forced集合与最短时长也只加强 |
| 下界大于某旧U，但该U不满足此部分赋值 | 允许：它是可排除的部分域，不是全局下界异常 |
| 部分赋值兼容某已存完整SAFE方案 | 本下界必须≤该方案可信U；这是一项有针对性的安全回归，不能重做其热积分 |

另有一个不能用“取某个argmin的CPU份额后替换”的反例：CPU额外δ＝1、两核；已强制CPU1/H工作20秒，真实域驻留20秒，容量份额10。另一个可选任务A在GPU/L的源成本1、CPU份额0；选B为CPU2/H运行4秒、源成本0，可完全藏在前者20秒内，CPU份额2。容量界在A为11、B为12，故选A；forced界为20。若按A减掉份额10再加20，错误得到21，而B的真实总成本只有20。**对完整松弛取max**得到max(11,20)＝20，正确。此例是纯代数／资源反例，不是新增研究输入。

## 7．后验安全剪枝合同

只允许用已存、独立完整安全、同输入／同目标／同权重的可信能量上界U。纯预检应只读该回执，不重新求候选或热评价；U的数值是安全区间**上端**，不是内部目标、均值、区间下端或历史不同模型答案。

若L(P)＞U，则P的每个完整安全扩展都更贵，可排除该部分域的“不劣于现U”候选。**L(P)＝U保留并列**；用Fraction严格比较，不设epsilon，不将未决／无界／输入错误变成可剪枝。此结论只针对该条件域，不是原问题无解，也不是全域最优证明。

界记录应分开保存输入身份、规范化部分赋值、各下界分项与选择依据、阈值forced集合及其最短时长／链／单元工作量见证，以及U来源／作用域。没有可信U时仍可返回可靠条件下界，但`prune`必须为false／未启用；不能自己寻找或借用未声明答案。

**阶段边界：** 可以实现以上纯代数接口和手工反例／存档回归；不导出MILP行，不调用solver／热评价，不宣称实际剪枝速度或节能收益。后续真实搜索接入、计时和开关消融须另定任务。
