# 完整 R1 的选项传播与构模缩减

完整 R1 在已有期限前置过滤上增加依赖与共享部署传播后，电热状态块从 15,687 降到 11,352，减少 27.63%。小域 K194 的 274,500 种结构合法联合时间表全部保留。MATLAB R2023b 配对入口和共同初解已通过求解前检查，原生配对待在具备该运行环境的宿主执行。

## 对象与比较口径

使用 K108 的 `base__R1` 冻结输入。AB、AC 各 6 次 Stage 执行，初温 50°C，温限 80°C，期限因子 β=1.3，启动网格 5 ms，评价窗 400 ms，空闲保持末档。前期 6,422 个选项、1,779 个区间、48,033 个状态块是该输入在期限预过滤之前的规模。两边共同开启期限前置过滤、聚合 OPP 锁、辅助变量连续化及能耗下界强化。传播版只在生成事件前增加两条规则。正式配对两边均使用已有严格相反行等式转换。 [原 K108 基线](../../README.md) · [原始规模口径](../../fixed_deployment_structure_audit.md)

## 保留完整调度集合的依据

对依赖边 (i\to j)，保留域内前驱最早完成时间是后继可启动时间的下界，后继最晚启动时间是前驱可完成时间的上界。比较采用原始有理数时间，允许完成和启动发生在同一时刻。对共享 Stage，完整时间表为它的每次执行选择同一个具体单元，所以取各执行的单元支持交集。频档、起点仍按执行分别选择。两类规则循环至稳定。

若一份原合法时间表中的某个选项首次被删，同一时间表的前驱、后继和同一单元的其他执行选项此前仍在域中，必然给出该选项的支持，和删除条件矛盾。过滤只保留原选项，因此在使用原约束判定时，缩减前后的结构合法调度集合相同。K194 用原独立枚举器复核全部 1,550 份单场景时间表标识。期限过滤后 72 个局部选项缩为 69 个，所有单场景标识及按共享部署连接的 274,500 个合法组合均保留。

对任一保留调度，重建的事件轴仍含该调度实际起止点和评价窗两端。消失的分界只会合并实际工作点与活动功率均保持的相邻区间。相同仿射电热系统的流具有复合性质，故连续温度轨迹、峰温和积分能耗保持。数值系数和外包误差按新区间重算，最终候选沿用独立连续电热检查。 [传播规则](../../option_propagation.py) · [构模入口](../../milp.py)

## 同一初解与原生配对

两边均重新执行同一增强 HEFT 过程，并各自进行完整连续电热检查。共同时间表的 SHA256 为 `bf2a4ba36ab0fed9ede9f30a58a3b5ca60d0560ccf5b62f6d3edcf9486335bd4`，安全能耗上界均为 0.985107069465 J。按各自的时间轴补全后，两套初值分别通过原矩阵、回解与等式转换检查。等式转换前的最大不等式残差均为约 \(2.13\times10^{-14}\)，原检查容差为 \(10^{-9}\)。求解前检查的首次接口尝试发现直接热评价回执缺少初值补全所需的输入身份，接入原模型绑定评价接口后完成核验。

原 `test_formal_milp` 的 5 个模拟流程测试在改动前后的版本上均复现失败。夹具替换模块级 `Recorder`，调用仍使用函数定义时绑定的默认工厂，并尝试向夹具不存在的目录写日志。传播、已有前置过滤、自动降档构模和等式转换测试单独通过。

MATLAB 配对沿用两个独立的 300 s 根预算。输入、构模、MATLAB 启动、共同 HEFT 生成及安全检查、初值补全、等式转换、原生求解与反馈均计入各自预算。原结果记录共同初解及求解器返回的独立 SAFE 候选、形成时刻、原生状态与界。当前宿主没有 MATLAB R2023b，可用于比较的原生求解记录为 0。 [复跑入口](../../verify_option_propagation.py)
