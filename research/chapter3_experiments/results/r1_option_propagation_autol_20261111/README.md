# 当前 auto-L R1 的前置传播验证

当前完整 R1 保持原 auto-L 物理策略、β=1.3、50 °C 入口、80 °C 温限、12 次 Stage、5 ms 启动网格与 400 ms 评价窗，加入依赖双向及共享设备支持传播后，电热状态块减少 30.31%，原约束行减少 29.73%。两版现场生成同一份完整增强 HEFT 初解，能耗均为 0.881087997281 J，均通过连续电热及数值准入。原生求解调用为 0。

本轮属于构模和初解通路验证。来源包括用户 2026-11-11 确认的 auto-L R1、归档提交 `4339bdcc`、传播实现 `84fa1b5b`。全部统计为单次实际构模观测，保留原结果及文件哈希。 [机器汇总](summary.json) · [复现入口](../../verify_option_propagation.py)

## 输入与比较条件

远端 2026-11-10 的传播验证使用 K108 的“空闲保持末档”输入，共同 HEFT 初解为 0.985107069465 J。本轮改用用户确认的最近 auto-L 输入，其实例和配置 SHA256 分别为 `01eacb2a653d56419c32f38740021a787ea01ac9e7ade407bef2edd81ec6ef89`、`132323b4b18dd514b9baa929543d235ff91bb07026a60e7b629e1adb6aaaa5e2`。旧入口默认值及旧结果保留，当前入口显式选择 `--profile auto-low`。 [旧 hold-last 结果](../r1_option_propagation_20261110/README.md)

两版共同开启已有期限前置过滤、OPP 锁聚合、辅助变量连续化及能量下界强化，累计前驱强化保持关闭。新版本仅打开 `propagate_options`。原设备、频档及网格起点均先进入同一原始选项生成器，再删除已证明无支持的选项。输入及物理源码保持原版本。

## 规则与等价性检查

依赖边 i→j 的前向规则删去早于前驱域最早完成时刻的后继选项，后向规则删去晚于后继域最晚启动时刻完成的前驱选项。共享规则对同一 Stage 的全部执行副本取具体设备支持交集，频档及起点仍分别选择。每条规则只删除缺少必要支持的选项，逐次删除保持完整结构合法时间表集合。重建电热系数后，候选仍需原连续热后验。

K194 复核保留全部 1,550 份独立合法单场景时间表，时间表标识集合完全相同，因此原共享关系连接出的 274,500 个联合组合全部保留。额外 8 项规则测试覆盖 fork/join 完整分配穷举、共享支持传播、非整数结束及接触边界、重复执行副本、零权重必需场景、空支持、幂等性、取消与输入不变。另 3 项入口测试核对当前输入、旧入口兼容及身份漂移拒绝，合计 11 项通过。 [小域证据](small_domain.json) · [测试记录](checks.json)

前向传播删除 310 项，后向删除 246 项，共享支持在本 R1 删除 0 项，3 轮达到不动点。共享规则本身由针对性夹具验证，本实例的缩减全部来自依赖传播。区间和状态按实际 auto-L 构模器统计。旧附件中的 48,033 个状态块与本轮基线有不同的物理策略和已启用优化条件，故本轮收益只相对表中基线计算。每侧仅一次构模，构模时间差属于本机观测，原生求解效率仍待配对验证。

新增传播自身耗时 0.0176 秒。电热条件行生成是构模的主要成本，观测耗时从 8.221 降至 6.630 秒。系数生成及查询由 2.829 降至 2.723 秒，实际生成的不同系数组数却从 515 增至 541，因为合并区间产生了新的时长。这说明状态块下降主要减少了行生成成本，系数计算成本仍需单独测量。
