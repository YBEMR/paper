# 完整 R1：严格可行见证与固定整数连续诊断

**保存的 OFF 数值矩阵严格可行；原 x0 和两次原生返回向量不是严格可行证书。原生内部失败机制及自由 OFF／ON 共同修复路径仍未知，停止追加原生实验。**

依据 [efcbb8e](https://github.com/YBEMR/paper/commit/efcbb8e28d43fbebc830f21bc6648af282378370) 与 [bb3838d](https://github.com/YBEMR/paper/commit/bb3838d56f0771080e281840594841bb36cbe1a5)，先冻结 52 个已发布文件，再以实际 binary64 数的精确有理数解释检查全部约束、边界和整数条件。未重建 R1、改变物理参数／目标／原生选项，未新增剪枝、优化缓存、运行完整 MILP 搜索或正式 OFF／ON 配对。

| 向量／阶段 | 精确不等式违反数 | 结论 |
|---|---:|---|
| 原 x0，两种表示 | 97 | 最大约 3.21e-15；等式、边界和整数条件严格满足 |
| 一次构造的有理数见证，两种表示 | 0 | 全部行、边界及整数条件严格满足 |
| 原表示固定整数后的原生返回 | 1,127 | exitflag=1；最大严格违反约 1.64e-14 |
| 等式表示固定整数后的原生返回 | 1,126 | exitflag=1；最大严格违反约 1.64e-14 |

97 条原 x0 违反全部位于保留的活跃门控仿射行对，新等式全部满足。69 条精确正残差被浮点检查漏掉，另有 317 条浮点正残差并非精确正残差。18,832 行系数幅值比达到 1e9，最高约 4.80e9；相关活跃区间最窄仅为原目标辅助值的 0.5 ULP。这些是可复核的尺度风险，不能据此指定 MATLAB 内部故障原因。

一次保存顺序的有理数中点构造只改动 2,120 个连续辅助坐标，最大约 3.24e-13；1,125 个原整数列全部保持不变。完整 19,857 维见证经过 Fraction 逐行核验，以及另一份仅用整数乘法／二进制移位的独立检查器核验，两种表示均通过。固定整数域属于原域，故该见证也证明原未固定 OFF 数值矩阵可行。它不是新的物理 SAFE、最优性或节能证明。

预冻结诊断只令原 intcon 列 lb=ub=x0，保留目标、intcon、原 x0、所有行和连续边界。两种表示各一次，实际分支节点均为 0；所有原生选项逐键匹配，包括原 MaxTime=270.64159389999793 s、容差、dual-simplex、两种预处理 none、Display 和原回调。完整回执分别为 25.156 s／19.406 s，清理通过；时间仅描述本次连续诊断，不是性能配对。两个浮点向量的严格违反均明确保留，不能用 exitflag=1 或 gap=0 替代严格证书。

本轮共 2 次原生调用、0 重试、0 新构模、0 物理评价、0 正式配对。保留先前完整 SAFE 调度及其身份；物理调度安全与浮点辅助向量严格满足矩阵是不同证据。固定调度不是自由调度优化的修复；有理数见证也不能未经验证转为 binary64 热启动，因此不提出新的共同修复验收方案。
