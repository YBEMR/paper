累计停止规则

普通超时、没有候选、候选拒绝、SAFE 未建立或没有节能：结束当前试次，不重试，不新增影响范围。
当前试次的原生下界冲突且输入身份已核验：阻断当前试次；身份不明则全局停止。
联合状态约简证书错误：持续阻断全部后续 C；选项支持证书错误：持续阻断 B/C；独立试次错误不自动扩大至同模型组。
共享输入/表达/源码漂移、同调度出现不相交能耗区间、未知错误范围、进程清理或控制器完整性异常：全局停止。历史文件不回写。
本次冻结计划只有一个 C_noheur_observe，不能借通用协调器新增 B、C 或后续优化试次。

观测接口与兼容性

Display：使用 R2023b 支持的 iter，不使用 iter-detailed。记录标准输出的字节前缀和每次读取完成时间，不强制刷新求解器，不将日志到达时刻等同于内部阶段发生时刻。8 MiB 上限，超过即标截断；最终标记未出现可由缓冲造成，不能推定求解卡死。停止采样时只读取已到达字节，不延长等待。

Profiler：仅公开 profile 接口，timestamp、performance 计时器、historysize=100000，检查公开 status 中的 on/timestamp/performance/mmex/100000。没有私有探针，没有解码或改写受保护文件。记录开始、rootlp 回调和结束标记；profile('info') 只在原生返回或异常后调用一次，它会停止采样，不在回调中反复取快照。

历史完整性：达到容量上限一律视为可能截断。PartialData、缺少标记、非法索引、事件逆序、区间内部不闭合均阻断完整时间线解释。Profiler 启动/停止自身可留下区间外未闭合调用；只检查明确 begin/end 标记之间的调用栈，不为区间内部缺失调用补造退出事件。原始 MAT 保留，单包上限 64 MiB；超限不尝试更大历史或再次运行。

时钟对齐：每个命名标记的 Profiler 进入时间与 MATLAB request-tic 前后包围时间形成偏移区间；开始、根 LP、结束三点须有共同交集，最大不确定度 50 ms。标记函数必须来自冻结的 solve_model.m 文件，不能仅按相似函数名匹配。Python 的请求发布时间和完整事件回执时间另外形成因果包围区间；无法缩小到 50 ms 时，资源序列与函数序列的对应关系保持未知。日志只有到达区间，不用于精确归因。时钟速率一致是明确假设，不宣称硬件同步。

进程资源：名义每秒采样一次当前工作进程及其已识别子进程，记录 PID+创建时间、用户/系统 CPU 累计时间、内存与读写字节。每次保留实际时间戳，采样工作本身可能使间隔略大于一秒。身份变化、访问错误或线程异常均入账。它不监控用户其他 MATLAB，也不以高 CPU 推定是哪种算法阶段。父监视器独立负责清理核验；只对已识别自有进程采取清理措施。

开销：记录 Profiler 设置、取快照、MAT 保存、callback 包围区间、资源采样与日志读取耗时。重叠区间不可重复相加。profile 返回的 Overhead 字段不用于测量或扣除观测成本；Profiler 本体、输出和系统调度扰动的总增量开销无法由一次带观测运行严格识别。不得将本次耗时与历史无观测 C 直接解释为算法速度变化。

即使诊断正常，也可能不可观察：割分离各轮、重复/被拒绝的割、可靠性分支内部的探测 LP、节点处理子步骤、LP 单纯形迭代、退化/数值修复及内核线程等待。受保护 .p/MEX/native 实现可能只有一个包含子调用的总时间；没有 cutgen 事件或 numnodes=0 都不能排除这些工作。

O0/O1/O2 冻结验收

O0：输入、原生选项、脚本和来源身份一致；响应及完整 Profiler 文件读取在 550 秒之前；观测设置有回执；科学证据分类、读取、哈希和封存均在 600 秒之前；自有采样和进程清理完整。父控制器的退出/进程核验有最终否决权。历史截断或日志截断是已声明的观测缺失，不将其伪装成完整记录。

O1：O0 成立，且相对于旧事件序列，确有根 LP 后新增的公开函数记录、资源样本或迭代输出。只有启动期间 CPU 样本、空日志或旧候选重现，不算根 LP 后的新增观测。O1 不说明具体瓶颈。

O2：在冻结证据上做独立只读语义复核，明确一个具体计算机制，并能与其他候选解释区分。复核必须给出：原始文件 SHA、函数索引及可复核公开源码/文档定位、根 LP 后区间边界、完整性和对齐检查、去除父子包含重复后的独占区间、可见/未知时间覆盖及竞争解释。若称“主要瓶颈”，被确认机制的保守独占时长须超过对齐根后区间的 50%；未映射区间保留未知。观测回调/采样开销须单列，不得冒充此前无观测运行的算法根因。

执行器自动结果固定为 O2=NOT_ESTABLISHED，只产出复核材料，不靠函数名猜阶段。O2_review_eligible 仅表示区间资料足以开始只读复核；它不是 O2，也不是实验授权。普通 rootlp/cutgen/heuristics 事件、CPU 高、内核包含时间、零节点或缺失事件均不能独立满足 O2。

只有经上述规则确认 O2，才可在下一阶段提出与证据对应的单因素干预。若仍然黑箱，停止参数扫描和相同原生诊断，不增大历史缓冲、不临时换参数、不补跑以寻求有利结果。本轮不冻结任何具体优化参数或优化试次。

N(t)=floor(min(540,max(0,600-t-10-50)))。
t 在 MAT 序列化完成、请求 JSON 发布之前测量；N≥30 才可发布。记账后若跨越配额整数边界则本次不发请求，不重新计算到一个更方便的额度。MATLAB 实际 MaxTime 不大于该额度及自身剩余守卫时间，实际值与分配值均存档。

例：发布前 t=20/60/120 秒，对应原生上限 520/480/420 秒；t=510 秒可分配 30 秒，超过此点不请求。普通原生超时不意味着数值模型失败。600 秒是严格证据截止，合作式停止不是硬实时完成保证。680 秒外部监视器、40 秒会话清理上限、10 秒末端进程等待只用于止损；全部实际墙钟和清理时间报告，不能换取新证据或新调用。

预算风险与准备成本

新观测执行器尚无真实成本测量，不能保证进入原生阶段或完成 O0。保存矩阵入口明确不承担此前完整 R1 的重新构模/证书生成，因此不能与正式 A/B/C 的端到端性能混用。
作为已有事实，C_noheur 历史新构模为 13.453 秒，约简复核 7.797 秒，互补转换及精确投影 31.078 秒，MATLAB 启动 6.391 秒，初/末完整评价分别 0.735/0.750 秒；它们不是新观测入口的成本预测。本次仍需支付矩阵/证书读取、身份检查和初解评价，启动时间可能显著变化。最显著未知为 Profiler 造成的求解增时、历史容量消耗速度、快照大小，以及剩余 50 秒能否容纳读取、完整评价与归档。任何一项不足均如实结束，不免计成本。

研究终点与后续决策

现有 C_noheur 仍只返回共同初解，约 1.0848863713 J；本轮没有产生新科学结果。观测接口成功不是节能成功。
