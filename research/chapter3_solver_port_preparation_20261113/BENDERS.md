# D281：固定整数后 LP 与 Benders 的只读分析

本文件是数学推导及源码核对，不是实施许可、数值证书或新求解结果。经典来源：[Benders (1962), *Partitioning procedures for solving mixed-variables programming problems*, Numerische Mathematik 4, 238–252](https://doi.org/10.1007/BF01386316)。以下符号直接针对本保存矩阵推导。

## 1. 固定整数后的严格对应关系

令 y 为 `intcon` 全部 1125 个列，z 为其余 22655 个列。它们是完整变量索引分区；不能仅固定选中的 12 个 y=1 而遗漏其余 y=0。全部 c、A、b、E=Aeq、e=beq、l、u 均按保存 binary64 的精确有理值解释。

原模型为

\[
\min c_y^T y+c_z^T z,\quad
A_y y+A_z z\le b,\quad E_y y+E_z z=e,\quad
l_y\le y\le u_y,\ y\in\mathbb Z^{1125},\quad l_z\le z\le u_z.
\]

固定 y=ȳ 后，所有余项都是线性的，没有新增离散决策、乘积、ODE 或二次目标。因此它**严格是保存 MILP 的连续 LP 子问题**。所有连续界有限，若可行则目标有有限最小值；不允许由“共同初解存在”推断任意整数调度都有可行延拓。错误部署、共享频率冲突或热不安全调度都可能无追索解。

数学上可写 RHS `b−Ay*ȳ`；实现时普通 binary64 点积再减法可能舍入，从而改变极窄可行区间。后续若实施，优先保留原矩阵，固定全部 y 的上下界为选定整数，并去除这些已固定列的整数标记，在相同线性系统上求连续 LP。若消去 y，必须认证右端变换的精确性，不能默认浮点消元无损。这一 LP 仍要单独授权；本轮没有运行。

## 2. 有效割的符号及证据

只作数学整理，将连续约束写成 `Wz ≥ h−Ty`，z 视为自由变量：原 ≤ 行取负，等式写成正负两行，有限上下界分别写作 `z≥l`、`−z≥−u`。这样不遗漏变量界，不改变可行集；不是建议本轮实际扩展百万系数矩阵。

固定 y 的连续目标 `Q(y)=min{c_z^T z:Wz≥h−Ty}`。对偶可行 π 满足

\[
\pi\ge0,\quad W^T\pi=c_z.
\]

由弱对偶，对任意可追索 y 有 `Q(y) ≥ πᵀ(h−Ty)`。主问题最小化 `c_yᵀy+θ`，可加入最优性割

\[
\theta\ge\pi^T(h-Ty).
\]

不要求 π 最优才有效，但非最优 π 可能弱。若子问题不可行，Farkas 射线 r 应满足 `r≥0, Wᵀr=0`，且在当前 ȳ 有 `rᵀ(h−Tȳ)>0`，才可加入可行性割

\[
r^T(h-Ty)\le0.
\]

上述符号可直接从 `rᵀWz=0≥rᵀ(h−Ty)` 核对。只有 INFEASIBLE 状态而无有效射线，不足以写割；INF_OR_UNBD、超时、数值失败、缺少对偶等必须保持未知，不能错删调度。原生 Pi/FarkasDual 的行向、界项和约定须按实际 API 映射，不能直接复制本符号。[Gurobi 线性约束属性及 Farkas 说明](https://docs.gurobi.com/projects/optimizer/en/current/reference/attributes/constraintlinear.html)。

浮点近似 π/r 可能违反对偶条件。严格无损割需要按原 binary64 有理系数精确核验，或用经过证明的残差/有限变量界补偿给出保守有效割；不能简单四舍五入、放宽物理参数或将近似射线视为证书。本轮没有构造任何实际割，也没有建立有限迭代数、运行时或加速保证。

## 4. 目标与物理评价一致性的边界

保存 c 的 424 个非零项全部为场景权重 0.5，对应完整分段 energy，构模源码描述为含漏电与空闲尾段的完整系统能量。互补门控新增变量目标系数为零；精确投影证书保留这一目标。Benders 的 θ、上下界与割必须针对**同一个 MILP 的 cᵀx**，不能只优化动态能量、忽略空闲，或换成某一场景而不更改问题。

物理语义保持并不意味着原生 `cᵀx` 与独立连续电热评价的高精度区间端点逐位相等。条件行带认证导出误差/容差；完整连续 SAFE 评价仍是最终安全与节能依据。不能将评价器给出的能耗直接当作 LP 对偶值生成最优性割，也不能只因评价 UNSAFE 就产生未经证明的全局线性割。

因此，Benders 是保留中的后续求解策略，而不是本次环境缺失的即时替代实施。即便取得其 MILP 最优性证明，也须说明与完整物理评价的差异；当前尚无任何新更优调度或最优性结论。
