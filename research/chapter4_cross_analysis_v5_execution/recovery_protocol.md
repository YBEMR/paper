# 第四章交叉验证的中断补测规则

11 月 27 日在原机重连接时，Windows 26300 的 F1 / D / 102 已过截止时间，保留了 5 轮配置日志，缺少结果及回执。其余正式位置继续沿用原有顺序。本规则在同批 F1 / C / 103 运行期间登记。

- 原十项登记照常结批。仅当一个位置有原始启动记录、已过截止时间、同时缺少结果与回执时，才在独立目录登记一次补测。资格仅取决于文件与截止时间。已完成、已有错误或超时回执、已有终点但缺回执的位置均保留原状态。
- 每个补测从同一份 Q4 初解开始，使用原 Windows 26300、冻结工作程序、输入、种子、物理核和串行顺序。每项 900 秒包含该工况已实测的初解构造时间。按原文件逐字节复制并核对初解池，计费单独记入新启动。
- 保留旧目录及全部中断证据。补测前记录来源批次、文件散列和新增预算。每个位置至多启动一次补测。正式回执与逐轮证书经原审计器核对后，方可进入最终表。
- 最终报告同时提供补测前的工况汇总和纳入补测后的逐种子结果，列明 C、D 各自的系统版本和尝试来源。中断成本单列，保留相同系统版本内的对照。
