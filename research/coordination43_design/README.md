# 43号设计输入 v1

此目录是设计资料，不含实验执行器或结果。

- `inputs_v1.json`：共同输入及10项显式案例；单位见文件头，全部数值为L3合成设定。案例字段与`common`共同组成完整输入，没有随机生成步骤。
- `freeze_manifest.json`：输入、43号规则文档及本说明的SHA256，供未来实施前核对。
- `static_checks.txt`：本轮JSON解析、数量、结构、对照配对与本地链接检查；不是调度可行性、热安全或算法检查结果。

规则以[43号](../43_多CPU单元配置协调最小验证定义.md)为准。无热／热参考、C0、C1均尚未实现。不得将旧P0/P1或单CPU枚举直接当作本版本实现，也不得向策略传递未来热参考见证。

修改任务、温度、期限、功率或策略规则时创建新版本并解释原因；不得覆盖本输入后沿用v1名称。程序错误修复与研究输入变更分开登记。未来运行须另存源码、环境、日志和结果，不写入本设计目录冒充本轮已运行。
