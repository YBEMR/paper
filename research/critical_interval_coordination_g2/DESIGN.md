# 定型设计与判定规则

## 紧凑模型

按请求序固定 pre，令其结束时刻为 a。为 main 选择设备 u 和档位 k 后，读取该设备上一次结束时刻 F 和档位 r，此 main 从 max(a, F + 5·[r≠k]) 开始。只更新所选设备的前沿与频档。按最早启动规则，一组配置确定唯一的执行时序。每个频域间隙比较保持与满足切换时间的尽早降档，平局选择保持。对已指定空闲控制也能逐项重放。活动、频域驻留、切换、公共项和两设备返回最低档后的末段，均采用 G1 的完整参考计能。动态规划搜索使用有理系数分母的最小公倍数与 Python 无界整数，参考目标的整数化误差为零。E2-a 单独沿用原皮焦模型及其误差界。

固定画像中，任一 main 至少 134 tick，同一设备上连续两次完成至少相隔 134 tick。post 最长 13 tick。因此，按 (main 完成，编号) 排序的任何三个相邻完成事件，首尾至少相隔 134 tick，足以消化前两个 post。由队列递推归纳，某 post 的开始只可能由自己的 main 或紧邻的前一 main 加其 post 时长决定。比前一事件更早的跨设备事件也给出必要的不等式。同设备的完成事件间隔足以覆盖前一 post。对于不同设备，若两完成时刻相距至少最长 post，则较早 post 必能在晚者完成前结束。实现按此已证明的窗口查找另一设备的完成事件，同时检查新事件成为先行者和成为后继者的两个方向，包括相等完成时刻时的编号顺序。

Compact 使用前沿束搜索构造，再对开放配置作有界时间的深度优先分支定界。搜索的分支覆盖全部 13 个合法配置；每个完成叶按全任务流和末段成本评价。非负的未计间隙、切换及各剩余请求的最低忙态成本给出参考能耗松弛界。固定 CPU/FIFO 成本界仅用于相应参考模型。全物理域的 SAFE 质量下界来自 G1 屏障条件复核后的解析界。运行报告区分超时、参考目标穷尽和热安全的真实节能。束搜索按前沿合并用于取得初解，精确分支搜索保留不同 post 历史。

## 冻结比较

共同自动构造先给 G1 宽度 1024 的容量价格构造分配构造时限的 35%，随后尝试精确 post 束宽 1、32、128、256、512。每例构造上限为主预算的 20%，D3 压力测试 120 秒。相同启动态的实际构造用时在各正式方法中计入，初解按认证区间挑选。强初解诊断只使用给定 FIFO 参照和本批共同构造中已认证的较优解，D3 纳入 G1 的 10/12 后缀见证。

AB 与 Proposed 共用按种子生成的目标列表，依次轮转单点低能耗配置及长度 1、4、8 的设备连续组降频。根据轮次开放最多 12、24、32 个配置。AB 按资源与实际释放侧的时间邻近排序补齐。Proposed 反向追踪实际阻塞 post 的事件和设备连续忙段，试放替代配置，依次比较全局期限违反量、阻塞事件推进量、原设备容量释放和忙态增量。相同违反量下也允许选择能释放容量的补偿任务。重构后更新关键区间，剩余位置按相同的普通规则补齐。两种方法均只用目标作为搜索提示，实际补偿配置由相同的子问题决定。

每轮时间片上限 30 秒，包含选域和建模，最多 5 秒用于关键链选择。两种方法使用相同的参考搜索、留存与认证规则。留存头三个和最新一个参考候选，倒序提交原认证器，只有在截止前取得严格分离的 SAFE 证书才更新。共同后处理最多占总预算的 20%，以相同种子选取相邻四个请求的全部阶段，运行 E2-a 的 P3 权限局部模型，允许移动 CPU 配置、设备、次序和起点。每臂记录配置阶段独立终点及后处理终点。初始化失败记录为构造结果；预算内没有改善仍保留共同初解。

主比较为 4 个实例 × 3 个种子 × 3 种方法；另有 S80、D3 两组强初解的 AB/Proposed 配对。最多三个不同物理核运行不同方法，每臂单线程，按种子轮换核。所有工作程序由父进程墙钟截止。预检与工程验证合计上限 1,200 秒。提交与发布不占用研究求解预算。

## 判定

按种子配对比较最终认证区间，然后回到配置阶段的终点、实际配置差分、目标/补偿日志和能耗分项核实归因。多个实例重复出现严格改善，同时实际配置变化及阶段贡献可解释，才能支持独立节能优势；相同初解和近似相同节能结果也要保留。少量纳焦移时、只有共享后处理贡献、或仅强人工起点的表现均不足以支持正式采用。只在已有实质配置证据并定位到可修复缺陷时允许一次修订。效率或构造成功率的证据单独评价。
