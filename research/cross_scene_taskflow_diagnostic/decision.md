## 3. 跨场景继承与局部机制

对 29 个不同最终排程逐一重放。仅在边界重置温度后，2 个排程的安全判定改变，7 个排程的工况内能耗点估计名次改变。峰温变化最大的排程来自 D3，连续传播与重置后的峰温上界分别为 81.4127°C 和 69.0799°C。重置结果仅作诊断。

例如 D3 的排程 89d3de97fa2a 在连续模型中为 HOT，在重置模型中为 SAFE。

- D1 的四 Stage 局部 Δθ 可靠区间为 [-2.24607, 2.24346] J。
- D2 的四 Stage 局部 Δθ 可靠区间为 [-2.32765, 2.32765] J。
- D3 的四 Stage 局部 Δθ 可靠区间为 [-11.76046, 11.75785] J。

D2 的固定单元与相对次序域 R 已将共同初解从 12.758597 J 降至 12.613428 J，严格节能至少 1.137%。这一改善可以由局部调档和起点调整取得。

D3 的固定单元与相对次序域 R 已将共同初解从 64.764940 J 降至 64.664301 J，严格节能至少 0.155%。这一改善可以由局部调档和起点调整取得。

R 的每个可行解也属于 F，安全解也属于同域无温限问题。上述区间利用这些包含关系复用现有上界。各臂原始回执和独立界见 local_rf/。

G4 目标筛查实际调用 0 次，机制组调用 0 次，全窗三组筛查共调用 0 次。

冻结筛选要求已知超温候选的完整能耗低于机制初解，或其至少一个 main 的参考增量活动能耗下降。已保存的超温候选未触发该条件。G4 恢复率、同规模邻域胜负及全窗算法节能率均无可报告的对照数据。

## 4. 立项判断

- **已证实**　P1 在本轮检查的模型和数值边界内自洽。开发工况有可行排程。部分非热合法排程在真实连续传播下超温。
- **仍未决**　有限搜索给出的安全与无温限最优能耗界尚未分离。各局部 Δθ 区间均包含零。
- **项目决定**　本轮不进入第三章正式算法实验。联合时热机制相对同规模普通邻域的独立收益，以及包含留出的双对照 1% 改善，尚未证实。
