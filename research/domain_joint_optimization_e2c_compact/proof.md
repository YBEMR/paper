# 固定配置下包络保留最优解的证明

设原起点为 tᵢ，整数位移为 xᵢ。固定一组合法频档后，释放、期限、首末切换和 ±500 tick 给出 lᵢ ≤ xᵢ ≤ uᵢ。每一条生效的边成为 xⱼ ≥ xᵢ + aᵢⱼ，其中 aᵢⱼ = dᵢ + gᵢⱼ − (tⱼ−tᵢ)。请求边的 g 为零，同设备异档分隔为 5 tick，异核 CPU 边仅在两个档位不同时生效。边方向沿用全模型。未变档、未移时的任务支撑数为零，其余任务的并集基数至多 24。

对一组可行配置，从其合法排程中先取支撑数最小者，再取总绝对移时最小者。若 xⱼ > 0，将它减一不会破坏任何出边或起点上界，也不会增加实际支撑数。若既无紧的下界又无紧的入边，因所有差分均为整数，这一步合法且严格减小总移时，矛盾。因此正位移必有紧下界或一条紧入边。沿紧边向前追溯，只追溯正位移任务；到非正前驱或紧下界即止。实际生效边有正执行时长，沿其方向排程的绝对起点严格增加，追溯不会形成环。同理，对 xᵢ < 0，将它增加一不会破坏入边或起点下界，因此必有紧上界或紧出边。沿负位移后继追溯亦终止。

正链的第一个正任务若受自身下界约束，第一轮的最大下界增量覆盖其位移；若来自非正前驱，零初值加上该边最大残余压力也足以覆盖。对后续正任务逐点归纳，一轮推进一个任务。负链从末端反向用最大上界减少量和同一边的最大压力归纳。任一同号链的实际移动任务数不超过 24。配置改变而起点不变的任务也计支撑，只会减小可用的移动任务数。各轮在 500 处截断仍覆盖对应实际位移，因为原模型已有同一界。同步更新从全零开始且单调，故第 24 轮覆盖此最优排程的每个分量。

提前包络 Aᵢ 和延迟包络 Bᵢ 得自所有授权频档的边界以及每一条可能生效的边的最大权重。CPU 异核边仅在异档组合中取最大值；不可能激活的边无须传播。最大权重不进入正式辅助模型。正式约束保留同档 CPU 跨核重叠和异档条件，并对消去的任务代入原常量。若一条边的两个端点和权重均确定，只在显然恒真时省去约束。起点固定的配置候选仍保留频档及其对执行时长和条件边的影响。

因此，对每组可行配置，至少一个最小支撑、最小总移时的整数解满足 −Aᵢ ≤ xᵢ ≤ Bᵢ。紧凑域是原域子集，反向包含关系对可实现配置及其最优目标成立。辅助收益只依赖配置；由此对全体配置先最大化估计收益、再最小化支撑和总移时，最优目标不变。第二次求解除去的是一整个频档组合，对其余各组合上述逐组证明照常成立。原目标系数使 1 微焦优先于 24×12001+12000 个次级目标单位，字典序无溢出或平级倒置的含义混淆。

这项结论不保证任意原可行移时、原提示、真实热最优解或限时求解轨迹位于紧凑域。因此物理可行提示先直接认证，超出紧凑域时仅跳过向该 CP 模型注入提示。有限验证另设一个可在全模型任意多移 1 tick、却超出零包络的合法赋值，以区分物理排程集合与最优目标的等价性。
