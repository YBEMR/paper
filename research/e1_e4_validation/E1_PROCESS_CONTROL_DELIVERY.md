## 1．完成了什么

| 能力 | 实现与验证 |
|---|---|
| 实际进程计时 | 父根在本次输入、源码复制/校验和进程启动之前建立；子进程继承同一单调时钟起点，规划300秒、后验60秒不重置。单列启动、实际进程耗时、停止和超期量 |
| 超时停止 | 最早的根、整槽420秒、整批1800秒截止生效；根到期发STOP，最多5秒仅归档/停止，再结束并回收本任务自己的进程。整槽/整批硬限可提前结束宽限 |
| 防重复调用 | 固定authority_store＋唯一授权ID；批、规划、后验及worker启动均独占消费。更换输出目录、重启和并发不能退款重试；崩溃/半写文件保留消费，异常锁不自动清除 |
| 正确保留旧证据 | 最后请求未决或进程被强停时，只恢复已完整保存、身份与预算有效的检查点；不补评分/搜索/重选。技术故障可同时保留旧SAFE，但停止本批 |
| 固定最终后验 | 只复核该臂按规划评分选出的候选；绑定输入、配置、精度、目标、评分、原回执、候选和源码。完整原始后验回执及能耗区间必须通过核验 |
| 进程隔离 | 每调用复制白名单源码，隔离Python解释器、工作目录和缓存；受信Python文件边界限制历史文件读取并禁止worker派生子进程。不是OS安全沙箱 |
| 真实闸门 | 默认`execution_gate.json`关闭。真实模式必须另获明确授权且源码、输入、预算、目录全部匹配；模拟短限/时钟偏移不能进入真实模式 |

除`exports.py`补充“更早的总截止”参数外，已有E1搜索、评分和真实回执记录逻辑保持；原物理/合法性核心及配置15份逐字节不变。没有调物理参数、温限、响应、合法域或安全标准。
