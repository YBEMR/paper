# E3-a　高质量 SAFE 排程的执行区间联合重构诊断

**C10 上，按参考能耗选择局部区间的 C 同时优于关键区间反馈 A 和普通 VNS 适配 B。完整电热引导 D 在三个开发工况上均未取得更低的终点能耗。** C10 的最佳改善为 5.1877 mJ，占历史强初解的 0.008805%。D1 只有 B 取得纳焦量级的改善，D2 各方法返回同一初解。建议保留普通执行区间联合重构作为第三章的局部后处理候选。单种子开发结果尚不足以确立跨工况性能或主动热感知的独立贡献。

## 历史排程与接口

D1、D2 各有 160 个请求。第三章正式归档的最低完整 SAFE 能耗分别为 9.179860893 J、9.215413581 J。第四章 Windows 26200 交叉验证归档的 D 臂取得更低的完整排程，分别使用种子 103 和 101。C10 使用 35°C 下的 960 请求 HHHHLLHHLLLL 任务流。其强初解来自 M1-i 的 ZQ-Beam，低于 M1-j 和 M3-a 所查 C10 记录的 59.531471812 J、59.324561747 J。历史选择按可恢复的完整 SAFE 排程进行。[原始排程、请求、证书与源码摘要](inputs)

两个冻结版本的事件模型、连续热积分器、四节点参数和设备画像逐文件相同。请求生成适配器的源码不同，三个工况的实际输入逐字节一致。本机使用两个入口重放相同原排程，事件矩阵的 31 列全部一致。C10 与 M1-i 归档的原矩阵也逐字节一致。D1、D2 对照历史 Windows 数组的前 14 列完全一致，全部列中的最大绝对差均为 7.11×10⁻¹⁵。[历史数组核对](results/original_trace_identity.json) · [双入口回执](runs/preflight)

按预登记规则以 50 ms 步长扫描 100 ms 的实际轨迹窗口，分别识别空闲碎片、非最低频档空闲驻留、切换和期限压力。D1、D2 初解均无非最低档空闲驻留，各产生六个窗口条目，C10 产生八个。每个选区保留请求的全部前处理、主阶段和后处理。单配置阶段枚举锚点各阶段的合法设备及频档。固定映射和联合重构独立从相同历史初解出发。记录首个物理冲突，所有可执行候选均经全时域连续重放。[预登记](PROTOCOL.md) · [原始窗口与期限阻塞链](results/seed_window_audit.json)

## 排序反转与选区归因

第一阶段按精确有理数参考能耗和严格分离的真实能耗证书比较不同 SAFE 解。D1、D2、C10 的全池分别包含 15、47、65 个不同 SAFE 解，发现 0、8、22 对严格反转。C10 的一个候选参考能耗低 7.193 µJ，但真实能耗高 1.179401 mJ。该对候选的真实能耗分别为 58.932533011 J 和 58.931353609 J，均高于历史强初解。因此该案例证明了排序反转，节能收益另由上面的联合重构案例给出。

A 提取 G2 原有关键执行区间反馈，再调用统一的 E2-a 求解器。B 以随机锚点和时间邻域适配普通 VNS。四方法依次采用 2、3、4 请求的开放规模，拥有相同的局部求解权限、种子 101 和每工况每方法 300 核秒上限。C、D 重新重放同一批按区域预登记的探针。三个工况的公共探针池均未出现严格反转。

C10 中 C、D 的三对选区换序均发生在精确参考能耗相同的探针之间，完整能耗中点最多相差 4.26×10⁻¹⁴ J，差异落在证书重叠范围内。D1 的两对换序也在证书分辨率以内。D2 的一对同参考能耗探针可凭完整电热能耗可靠区分，差 11.72 µJ，但没有转化为更好的最终排程。普通方法取得了本轮全部主要节能收益。后续若继续研究主动热感知，应把可由证书可靠区分、且能改变最终选择的节能机会作为依据。

B 是 Zhang 变邻域搜索的 P1 机制适配，处理器关闭和跨处理器依赖任务合并不属于本模型的动作。Chen 的睡眠状态也未移植，本实验联合优化现有最低档空闲控制、执行频率与时序。Huang 关于给定速度区间计算温度相关能耗的讨论作为计能依据，实际数值均来自冻结 P1 认证器。[文献与重放说明](REPLAY.md)
