Keywords:                                                    The growing demand for on-device deep learning inference, particularly in latency-sensitive applications, has
Deep learning                                                driven the adoption of heterogeneous accelerators that incorporate GPUs, DSPs, and NPUs. While these accel­
Inference                                                    erators offer improved energy efficiency, their heterogeneity introduces significant programming complexity due
Heterogeneous accelerators
                                                             to reliance on vendor-specific APIs. Existing deep learning inference frameworks, such as LiteRT, provide high-
NPU
Scheduler
                                                             level APIs and support multiple backend APIs. However, they lack the ability to exploit parallel execution across
                                                             heterogeneous accelerators. This paper introduces a novel inference framework that overcomes this limitation.
                                                             Our framework utilizes a batch inference API to enable parallel execution across heterogeneous accelerators. The
                                                             framework schedules heterogeneous accelerators to process batched inputs concurrently. To address the chal­
                                                             lenge of integrating commercial NPU APIs that do not support LiteRT, we develop a portable hooking engine.
                                                             Furthermore, the framework mitigates accuracy inconsistencies arising from diverse quantization methods by
                                                             dynamically adjusting postprocessing parameters to balance accuracy and latency. The proposed framework
                                                             minimizes both average turnaround time and postprocessing time. Experimental results on a Qualcomm SA8195
                                                             SoC with Mobilint and Hailo NPUs demonstrate significant performance improvements compared to existing
                                                             inference frameworks.

2. Background

    LiteRT, formerly known as TensorFlow Lite, is a prominent inference
framework for embedded systems, released by Google in 2017 [16].
Fig. 2 illustrates the LiteRT workflow. LiteRT supports models trained
using various deep learning frameworks. To convert a trained model to a
LiteRT model, developers must use the LiteRT converter at pre-runtime.
During the conversion, it is essential to quantize the model to ensure its
compatibility with DSPs and NPUs. The quantization scheme employed
by the converter determines the accuracy of the converted model. The
converted model is then transferred to the target embedded devices,
where it is run via the LiteRT API.
    The LiteRT interpreter reads the model file and executes it on CPUs.
To utilize a GPU, DSP, or NPU, developers must employ the appropriate
LiteRT delegate. The GPU delegate executes the model on the GPU, with
the CPU serving as a fallback if certain layers are unsupported by the
GPU. The Hexagon delegate executes the model on Qualcomm Hexagon
DSPs, while the NNAPI delegate leverages the Android NNAPI for model
execution. These delegates rely on the OpenCL, OpenGL ES, Hexagon,
and NNAPI libraries, respectively.
    The execution model of LiteRT is synchronous, meaning that the
execution of a model occurs in a single, uninterrupted sequence. Initi­
ation of a subsequent model execution is only permitted after the                                          Fig. 3. Target hardware.

stricts LiteRT to executing a single model at a time within a task. While        on-Chip (SoC) is a Qualcomm SA8195, featuring eight CPU cores, a GPU,
