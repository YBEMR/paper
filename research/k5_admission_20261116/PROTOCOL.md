# K5-NPU-M1 冻结协议

日期2026-11-16。材料类型：公开时延与合成参数的确定性最小实验；不改正式模型。本协议与inputs.json在任何本轮热计算前冻结，冻结时间与SHA256见freeze.json。所有1944项笛卡尔参数组合保留；不删失败、零收益、简单方法最优项，不追加参数。

## 模型与解析预期

两条DAG均CPU.pre→NPU.main→CPU.post，t=0释放，前处理同步完成于r=0.05L，后处理紧接各自主任务。各NPU阶段固定核组、不抢占、不迁移、不改变核组或频率；重叠核组禁止同时运行。

E=1W·W+4·0.5W·0.05L+p(kA)(fA−sA)+p(kB)(fB−sB)。基准、CPU、NPU分别保存；完整事件积分独立核对。无干扰时活动能量与起点无关，多核是否更省能取决于p大/p小<d小/d大。两任务重叠长度O时，慢化额外能量=(pA+pB)·σ/(1+σ)·O≥0。因此在当前恒功率模型中，普通并发本身不会因缩短makespan而减少固定窗口基准能量。

NPU热方程C·dT/dt=0.2W+Σ活动增量−G(T−Ta)。归一化为dθ/dt=(κ(0.2+Σp)/p1−θ)/τ。无漏电反馈、无热降频，不存在热状态直接改变活动功率的额外收益。每一恒功率段解析传播θ'=θ∞+(θ−θ∞)exp(−Δt/τ)，段内单调，故完整连续峰值恰在初始或事件端点，包括最终空闲尾段。双精度端点采用1e−8 K边界缓冲；落入缓冲区标UNRESOLVED，不作安全／最优断言；所有选定见证另用独立高精度Decimal核验。不是依赖作图采样证明安全。

功率非负；G,C均正，单节点为被动稳定RC。κ≤2，任意合法并发活动功率≤3 W，故T≤25+20·max(0.95,2·3.2)=153°C。这只约束抽象模型，超45°C的方案保留为违规。

## 有限时序域及完整覆盖

每个有序核组对取以下全部基因：顺序AB/BA；首任务延迟u/L∈{0,.25,.5,1}；次任务锚点为首任务起点或首任务**孤立完成时刻**；锚后延迟v/L∈{0,.25,.5,1}。共25×2×4×2×4=1600个原始基因/慢化档。起点确定后，按实际重叠期间进度率1/(1+σ)计算完成时刻；锚点“孤立完成”模式本来就无重叠，因此没有循环依赖。剔除核冲突，重复时间表去重但保留基因—时间表映射。

本域允许同步、错开、两种串行次序和冷却等待，覆盖定义域的每个基因；**不声称覆盖所有连续起点或任意离散网格**。E必须枚举全部合法时间表，不能只枚举25组核映射。CPU起点/后处理规则对所有方法一致。期限允许边界相等；NPU资源区间左闭右开。全部基因在4L内完成，超期限方案仍保存分类。

## 对照预定义

| 方法 | 冻结规则 |
|---|---|
| A | A固定core0、B固定core1；在其全部有限时序中选最低能量完整安全方案。它比仅同步启动更强，失败可证明该固定配置在本域无安全解 |
| B | 两者固定012，资源互斥；在全部有限时序中选最低能量完整安全方案 |
| C | 25组核映射、全部有限时序中最小最大完成时间，次级按完成时间和、完整能量、稳定编号排序；不使用温度筛选，原样评价 |
| C_repair | 保留C的核映射，在其全部有限时序中找最低能量完整安全方案；失败只说明该固定映射无安全方案 |
| D_list | 两个普通列表次序。每步在全部5种模式中按孤立活动能量、最早完成时间、模式编号择优；后继取可并行的首起点或串行锚点，优先完整期限可行。两个完整候选保留原始状态 |
| D | 从D_list的两个次序候选分别作坐标下降；一次改一项核组/顺序/锚点/首延迟/次延迟，所有该坐标合法值都可选。按违规约束数、归一化违规量、完整能量、makespan、稳定编号排序，最多各100步。完整候选热预测，不采用仅检查已提交前缀的弱基线 |
| E | 在同域全部合法核组和时序中逐项完整评价，选完整期限/热安全最低能量；保存总数、违规和未决数 |
| F_plain_search | 普通完整搜索：按实际完整能量从小到大排序（能量在本模型不依赖温度），逐个完整热核验，首个安全解即同域能量最优；不是新算法。用于判断是否已有简单办法足够 |

C/D/E及F核组和时序权限一致；策略偏好与搜索邻域不同。D不读取E结果、最佳时间表或其热缓存；E在策略结束后运行。各方法单独计时，公共合法时间表生成另记，均纳入总预算。不报告含不同工作量的“加速倍数”。

去热约束E0在完全相同的域计算，保留其原样峰温和违规；只有完整按时且热安全的两份方案之间才计算节能率／能量差距。热代价E−E0仅称约束代价，若E0超温不得称节能率。通过全部并列最优映射集合判断热约束是否迫使映射变化，不因任意打破并列就宣称翻转。

## 预算、核验与停止

总科学计算≤600 s，包含第一阶段、域生成、策略、枚举、高精度复核及结果汇总。主计算单进程由外部监控器限制剩余额度；超时保留已完成结果，所有未完成预定组合写UNRESOLVED，不续跑。修复纯实现错误须保留失败日志和版本，不能改冻结参数，修复也消耗同一总预算。

预冻结独立核验：25组精确有理数解析与位占用检查；独立笛卡尔生成器核对1600原始基因；解析慢化与事件驱动进度求解逐候选对照；能量分解与独立事件积分；选定见证用Decimal高精度解析热传播复核；全部DAG、核互斥、截止期及尾段检查；先验被动性和温区界。核验是同一助手编写的独立实现，不冒充外部评审。
