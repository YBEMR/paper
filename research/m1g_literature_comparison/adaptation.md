# Zhou 2018 与 Li 2019 的 P1 适配说明

两种主方法都是依据论文步骤编写的 P1 适配。原论文的处理器实验、功率公式、任务图和输入均与 P1 有别。本轮比较对象是这里明确规定的实现。主方法可以逐任务选择物理设备、频档、开始时刻；每条请求三个阶段都须执行。在可用画像中，前后处理分别可放在两个 CPU 的三个档位，主任务可选 GPU 十档或 NPU 三档；两个 CPU 核共享频域。两台设备上的不同时长、切换占用、尾段能耗、跨窗温度和期限都进入原 P1 认证。

## Zhou 的虚拟核排序与 first-fit

原文 §3.1–3.2、式 (10)、(15)–(16)、定理 1、§5.3 算法 1。实核的不同频档对应多个虚拟核；同实核上的虚拟核共享容量。动态能量排序依赖任务因子与模式因子的乘积表达。按虚拟核耗散因子升序扫描，未分配任务遵守依赖关系，独立任务按因子降序，以可排性和温限逐一 first-fit；遍历后仍有任务未排，构造失败。[作者全文，印刷页 5–8](https://faculty.ecnu.edu.cn/picture/article/1408/23/0c/a9d761e34644a4cd9f7306e31fb5/c768f3a9-e6a8-4a5b-8f82-a6949912d301.pdf) · [DOI](https://doi.org/10.1016/j.sysarc.2017.09.007)

**可分离性核查。** 在 35°C 查表，以同一 OPP 的忙功率减去空闲功率，乘离散时长，得到活动能量矩阵 E。它是接近原动态能量的 P1 可观测量。分别对 pre、main、post 的 A/B 两行求全部二阶子式，使用有理数做精确判零。主任务 13 个模式的 78 个子式全部非零，A/B 能量比从 1.04762 到 1.20462，有三对模式在 A、B 上的能量优先序相反。P1 表不能继承原排序的交换保证。归一化拟合的最大相对误差是 4.670%，精确不成立的结论不依赖误差阈值。[逐模式表、虚拟核优先级](data/factors.csv) · [精确子式及反序数量](data/separability.csv)

**已经实现的替换。** 每类任务的因子取该行几何平均，模式因子取两行分别除以行因子后的几何平均。这等价于在对数域拟合加性的行效应、列效应，两类等权，没有使用 14 条输出拟合。分配时保持虚拟核顺序，以实际查表时长/功率检查，而非以近似乘积替代。三个拓扑层依次排程，层内按任务因子、释放时间、任务编号排序。对先占用的物理日历作插空，纳入频域切换间隔；为尚未执行的本请求后继保留最快合法时长。采用静态已知输入，可在相同物理设备上为后读到的早释放请求插入空档。这是将原文帧利用率和静态依赖条件移植到异步逐请求期限所作的选择。

**热测试。** 每次试放将该作业的忙功耗和温度斜率记入物理时间上的 10 ms 分箱，用 P1 热导、热容、热耦合、初温和温度相关功耗作中点积分。整个窗口序列连续积分；预测超 80°C 时退回试放并继续扫描。探针只含已放任务的忙区间和低档空闲，暂未放入的任务、切换和高档驻留未进入试放近似。完整排程必须经原 P1 逐事件连续认证，才取得 SAFE。探针拒绝及构造失败仅属于本实现；不能由此宣告物理问题无解。

## Li 的热映射、任务子期限与 LFT

原文 §4 式 (12)–(17)、§5.1 算法 1、§5.2 式 (18) 及算法 2。ETA-TS 先按任务 upward rank、虚拟核的热耗散因子尝试分配，使用分层子期限，不满足时退回最早完成。其后按实际完成时刻逆序作 LFT 调整，在同一处理器上离散降频，并按剩余余量的一半调整开始时刻。[原文 PDF](../../papers/2019_Minimizing_temperature_and_energy_of_real_time_applications.pdf) · [DOI](https://doi.org/10.1016/j.sysarc.2019.07.001)

| 原步骤 | 本实现如何落到 P1 | 可核验的边界 |
|---|---|---|
| 任务秩与层级期限 | 对每条 pre–main–post 链，从后向前累计各合法处理器最高频时长的平均值。先用所有请求做最高频最早完成参考；按请求的参考 AFT 与退出任务余量，依三层的 1/3、2/3、3/3 分配子期限。参考未能排全的请求只用自身孤立最快链估计子期限。 | HEFT/EFT 仅提供参考时间。算法从空另建热映射，没有复用 HEFT 排程或共同池。建参考日历与算子期限的时间计入 Li。 |
| 虚拟核热耗散因子 | 以表值模式因子乘 P1 稳态自热响应的对角元。响应为热导减去模式空闲温度斜率后矩阵的逆；CPU 同步调整共享频域。 | 这个标量对应原文热负载权重的静态角色，保留按热耗散因子优先映射。它没有使用 NT 的动态延拓或原论文的处理器电压公式。 |
| 分配与回退 | 依 upward rank 为每阶段试合法虚拟模式；优先选满足子期限的第一个。如各模式都不能满足子期限，就选最早完成且保留后继最小时长的模式。两个 CPU 可在同频时重叠执行。 | 最早完成仍须服从释放、前驱、互斥、频域和真正的 300 ms 期限；无合格模式时保留失败位置和已放计划。 |
| 逆序 LFT | 在完整热映射上按 AFT 逆序，按后继、同核下一任务、切换时间与最终期限计算界；从最低受支持的更低频档起试，把可用剩余空闲对半分，计入共享 CPU 频域冲突。映射及 LFT 后分别认证。 | 保留任务映射；只能使用实际存在的离散档。算法自然终点为 LFT 后排程，预算内另报告全部已认证解的最优值。 |

第三章的 Adapted-ETA-TS 使用 P1-HEFT 或共同池起点，再做余量优化。这里直接按 Li 的热耗散规则独立构造；参考时刻从未作为候选提交。为了支持跨核、共享 CPU 频域和逐任务合法插空，本次重新实现日历与逆序移动，只复用冻结 P1 物理和认证代码。第三章的旧成绩没有移入本表。[第三章原有构造代码](https://github.com/YBEMR/paper/blob/c585f3461378c3188b4a032991cd875fa5fa4aa4/research/chapter3_final_evaluation/literature.py)

## 辅助同配额对照及功能核验

ZQ、LQ 从空运行冻结 N 生成器，在各自实际到达的父前缀使用原名额；选一个前缀继续。ZQ 先过滤预测已达峰温超限者，再最小化当窗任务所用模式在 Zhou 序中的总排名；LQ 先最小化超过 Li 参考主阶段子期限的任务数，再最小化热因子模式排名。再按参考能耗与配置身份打破平局。LQ 有独立的逆序窗口步骤，在保持设备分配下尝试对整窗某设备降档，以 FIFO 重放、任务 LFT 和实际期限过滤。NT 保留其四席起始束和加宽能力。该辅助实验把合法动作限制为相同窗口配置；候选保留、搜索规模及计算预算利用方式仍不同。ZQ、LQ 的收益只署为配额适配，不署为文献独立构造。
