# 46号冻结配对的实施核对

MATLAB R2023b入口：`run_prefix47`。在此目录加入MATLAB路径后运行；使用工作区的`.runtime/matlab_prefs`作为偏好目录。

只读取`research/prefix46_design/inputs_v1.json`的`common/cases`，不向策略提供预声明时间表／动作顺序。`p47_cases`是独立只读适配器；原c44入口和源码均不修改。C1直接调用原`c44_policy`；完整后缀见证对照仅在0时刻、按相同动作排序，每动作检查一条最佳无热完整代表。

两案例各自、每方法独立重新生成无热集合，60 s预算包含构造与评价。全部策略保存后才运行热参考；参考在这组仅18条的集合内完整热评价，并复核C1实际前缀。参考评价与前缀诊断共用60 s，超时或阈值未分辨不作排除证据。

每次运行生成独立`prefix47_reports/run_*`，含输入／规则／源码快照及哈希、MAT、CSV、事件JSON、逐行参考证据、检查表、日志与两张图。C1部分完成方案的能量／差距留空，其温度只代表已提交轨迹，图中明确标注。

预检查的负预算副本只用于状态处理测试，不计入研究案例。解析预期与程序不同应保留差异，不改冻结输入或偷偷修改旧排序器。读取报告中的实测结果，不把预期当运行结果。
