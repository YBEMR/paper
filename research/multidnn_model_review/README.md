## 判断

可以进入下一步**输入接口泛化及这 12 个工况的问题诊断**；目前不能判断 Kim、M2 或 Energy-Only 谁更适合新问题。没有新能耗、期限可行性或最优性结果。

四节点热积分、事件调度和精确仿射热传播具有复用基础，但外围实现不能直接运行全部新输入。主要阻碍是写死的 500 请求检查、40 ms 同步到达代理、30°C 初态、固定四场景，以及新初态下失效的 DLA 对称约简。具体位置、可复用范围和最小改动见[代码复用审查](reuse_audit.csv)。

新增网络还缺少目标平台性能和功耗来源，以及完整算子语义和引擎合法性证明。因此本轮只给出来源候选，未用臆造参数把新网络塞入实验。第一轮仍是四个原网络上的**合成平台诊断**。

## 已冻结的 12 个输入

完整配置：[protocol.json](protocol.json)；逐工况索引：[cases.csv](cases.csv)；文件校验：[input_manifest.json](input_manifest.json)。

| 负载 | sc0 / sc1 / sc2 / sc3 活跃网络 | 网络 0/1/2/3 周期 ms | 各网络请求数 | 总数 |
|---|---|---|---|---:|
| 均衡请求份额 balanced | 0 / 012 / 123 / 3 | 40/40/40/40 | 125/125/125/125 | 500 |
| 高并发 concurrent | 01 / 0123 / 0123 / 23 | 40/40/40/40 | 187/187/188/188 | 750 |
| 非对称周期 asymmetric | 0 / 012 / 123 / 3 | 80/40/40/80 | 63/125/125/63 | 376 |

每种负载分别使用正序、逆序，以及参考冷态、统一预热态，共 3×2×2=12 组。全窗仍是 10 s 服务 + 40 ms 尾窗；四网全窗常驻。sc0/sc1/sc2/sc3 的驻留分别固定为 62/63/62/63 个 40 ms 网格，逆序时驻留跟随场景名称。边界处周期相位重新从零开始；连续两个活跃场景也重启相位。因此非对称负载不是一个跨所有场景永不重启的 80 ms 时钟。

**本轮三类负载均保留 40 ms 期限**，使非对称负载只改变周期。问题定义允许逐网络期限；异构期限尚未进入这 12 组验证。高并发同时增加共现与总请求数，不能把其变化归因于纯共现效应；均衡指请求份额相同，不表示四网计算量相同。两类新负载来自事先声明的分析性设计，不冒称实测应用流。

环境均为 25°C。参考冷态为旧模型四节点 30°C，**不是环境平衡态**。预热入口按 CPU/GPU/DLA0/DLA1 为：

`[40.02694115509108, 73.82896057497442, 37.571727578256485, 37.57034559465566] °C`

来源是旧完整评价器已归档的 C 部署，正序原负载，LLL/LLL/LHL/LHL，25°C 环境、30°C 初态，运行一次完整 10.04 s 的终温。历史证据为 500/500 请求完成、峰温上界 76.50563180983404°C、期限余量 2.721279 ms、预热能耗 43.110757928033735 J。[预热配方与来源哈希](inputs/preheat_state.json)

预热只定义共同外生初态，能耗单列，不进入后续 10.04 s 的优化目标。评价开始时部署视为已加载；未建立从预热部署 C 到各候选的加载、迁移与温度延迟模型。这是初始化条件实验，不能声称模拟了一次包含重部署成本的完整在线切换。将来执行前只按该配方复核一次，不能因新结果不理想改预热次数或调温。

### 81 域的证书边界

[domain81.json](inputs/domain81.json)逐项保存旧 81 个**具体切点和物理绑定**及全部频率。每场景 27 个三域频率组合，四场景有 531,441 个序列；每工况域大小为 43,046,721 个组合（期限等约束尚未筛查）。

旧 81 域由 161 个物理部署按 DLA 交换对称约简得到。预热后 DLA0、DLA1 相差约 0.001382°C，已不满足严格相等的入口条件。不能人为平均温度以恢复对称，也不能继续把此处 81 个候选的最优值宣称为全部 161 绑定的最优值。本轮遵从用户指定的 81 域，将其作为固定候选子集，所有后续方法使用同一份具体绑定。新任务模型若要声称更广合法域最优，须独立冻结完整物理绑定域；本轮不扩展。

## 下一步的范围

先在新目录建立参数化实例接口、保留严格逐请求检查，并修复使用这些新输入所必需的初态与缓存上下文传递；通过原输入回归后，才执行预定 12 组诊断。一次诊断不足以证明任务分布的普遍代表性，更不能据此预选优于 Kim 的场景。
