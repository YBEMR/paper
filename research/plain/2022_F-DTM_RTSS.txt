aware real-time task scheduling in CPU-GPU integrated sys-                                                                                                         DVFS as the only thermal-aware control action, we extend the
tems, but they mostly explore static scheduling and do not take                                                                                                    OpenCL runtime framework with the ﬂexibility of performing
care of dynamic scenarios. Dynamic scheduling for resource                                                                                                         DVFS as well as task partitioning and migration as platform-
mapping while trading off between different performance mea-                                                                                                       level control actions to minimize the platform peak tempera-

been explored using different optimization techniques based                                                                                                        change. Future work includes improving the MPC with lookup

[40], [12], and control theoretic techniques [41], [42], [42],                                                                                                     analytical latency models [48]. Integrating task mapping op-
[14]. Control theoretic approaches using feedback to learn                                                                                                         tions like coarsening [49] and kernel fusion [50] can be another
