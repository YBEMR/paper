## 数值适用域

- 时间用1/4000秒、能量用1/16000焦耳整数单位。适配器核对输入乘基数与整数的二进制转换误差；不是把任意连续输入取整成合法值。53号十进制有理数为建模契约，IEEE754解析仅为传输表示。
- 启动间隔仍是4个时间单位（1 ms），结束时刻不取整。所有整数计数远小于double精确整数上限。
- 热包络仅支持本轮对称RC：C=1/400 J/K、环境导热1/20 W/K、耦合1/40 W/K。对共模/差模使用精确20/40 s^-1衰减率；不冒充一般RC的认证实现。
- 以z=exp(-20t)表示恒功率段，每节点温度为e+a z+b z²。检查两端和区间内二次多项式驻点；系数符号不能确定时用整个z区间包络。
- exp使用24阶交错Taylor与25阶绝对余项上界；本窗口20 ms保证0≤20Δt≤0.4。区间基本运算每步向外扩8个浮点间距，工作区间有限、无溢出/下溢；依赖标准IEEE754基本运算舍入语义。区间误差和1e-6°C判定带宽分别处理。
- 上界低于温限减带宽才接纳，某节点峰值下界高于温限加带宽才排除。否则未分辨；不能以多次浮点结果接近来替代包络。
- 旧s55/thv解析结果提供峰值时刻、名义轨迹及独立交叉检查；新方法不以其裸浮点峰值决定热剪枝。

## 输出与复核

每次运行保存输入、全部源文件及哈希、MATLAB环境、逐方法MAT检查点、状态、队列/处理中节点/未分辨叶、能量界、事件及修复日志。CSV中的能量单位为mJ、时间为ms或字段明确标注的秒；搜索内部边界日志保留整数能量格值。

`bounds_*.csv`四列依次为耗时秒、下界mJ、上界mJ、待查节点数。`events_*.csv`六列为耗时秒、节点编号、证据代码、整数能量格值、队列数、累计生成编号；代码1=无热排除、2=非改进、3=已有配置见证、4=承诺热违规、5=安全见证。未启用的修复计数为0，不等于已验证该修复无效。旧方法组件耗时NaN表示未插桩，不是耗时为零。

`cost_s.repair`记录贡献排序与修复安排构造；修复中的热评价另计入`thermal`，避免重复计时。总耗时还包括输入、日志、控制与未细分开销，各组件不要求恰好加总为总耗时。输出序列化及事后复核单列为预算外记录，不得新增搜索证据。

新方法的`thermal_calls`是未命中缓存的搜索热接口调用数；每个被接纳见证另作一次预算内完整复核，次数对应事件代码5，耗时在`validation`中。事后复核单列。旧方法没有相同的组件插桩，因此不把两个实现的该计数直接解释为等成本计算量。

`history_before.json`记录实施前1,682个研究历史文件的哈希；排除证据记录及本轮新增目录。结束后逐项复核。它不是研究数据，也不是算法输入。

预检夹具与正式案例分开。代码错误修复可重新预检，研究预算超时不增加预算或扩参数重试。首次安全见证不自动意味着最优，CPU标签对换不算映射收益。新方法默认不列全并列最优配置，不能和完整集合参考直接作等任务加速比较。
