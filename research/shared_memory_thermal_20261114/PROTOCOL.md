# SMT20261114：共享内存—热频率限制联合价值准入协议

2026-11-14；问题与模型范围由用户指定。新阶段独立于TF20261114及B；不改第三、四章和以前结果。只做轻量资料核查、必要的最小实验、复算与归档；不开发MILP/启发式/学习控制器。

## 先决门槛

优先核查HaX-CoNN、OPTiC、RT-TAS及Jetson Orin官方EMC/DRAM DVFS。检索同平台、同软件/精度、同工作负载下的合法执行支持、计算/访存进度、频点、共享竞争、系统功率、热反馈与转移成本。官方机制存在、论文测量、原始数据可下载、联合参数可辨识是不同层级。

**缺少支持联合数值模型的依据时，不运行调度数值扫描。** 改交付符号模型、null未知量、条件判据、四组消融与强基线的冻结评价契约、准入失败记录及复算代码。不得继承TF的任意归一化数值填空，不得跨芯片拼接，不得以“合成”标签替代本轮数据准入要求。此时所有节能率和数值最优安排记NOT_RUN，不能填0。

## 允许的最小结构

两条链A1→A2、B1→B2；两种合法资源、一个共享内存资源；标出计算/访存需求，少量离散工作点。任务工作量、精度、到达、期限及共同尾段固定；任务执行中不迁移。没有合法支持表时仅使用抽象X/Y符号，不声称真实NPU或任意算子支持。热状态只按有证据的机制限制计算/EMC合法频率上限。

候选结构必须包含映射、工作点和显式重叠/串行选择，避免固定派发器消除了待检验变量。重复次数及各数值需有证据后另行冻结，不以增加任务制造效果。完整模型计计算、内存、基础、转换、传输及共同尾段能量，避免重复计算已包含内存的板级功率。

## 因子消融与统一复评

相同任务、合法动作目录及边界下定义四模型：M00无争用/无热cap；M10仅争用；M01仅热cap；M11联合。前者的“不争用”仅改变共享带宽分配约束，不删除内存访问/内存功耗；“无cap”只关频率上限反馈，不删除热状态或温度相关功率。每个模型选择的安排最终一律在M11复评。失败方案不计算相对可行者节能率。

强对照包含：最佳固定映射/频点；仅争用优化；热限制但固定重叠规则（包括串行与尽早重叠两者的较优者）；至多一次模板切换的最佳离线方案；全合法有限目录最优。精确已知未来/参数的离线方案不可称在线阈值策略。热频率反应式若加入必须单列，不扩大当前结构。

## 分析与停止

先核查cap实际改变了有效能力，再比较选择变化、完整服务可行性和全窗能耗。分开报告普通内存争用效应、热限制的条件增量、非加性交互；不将两个不同模型的各自最小值差直接当联合策略收益。只有相对最强简单可行者仍有≥1%完整能耗改善空间，且不依赖无法支持的极端参数，才可能值得另行授权算法研究。

保留无争用、无cap、计算受限而带宽裕量充足、同最优方案等无收益条件。资料缺口、无热参与或强简单类已同等最优均停止新算法开发。本轮不扩大方向，不索取硬件，不发送作者邮件。公开工件下载与静态解析不执行其硬件控制/训练/求解脚本。
