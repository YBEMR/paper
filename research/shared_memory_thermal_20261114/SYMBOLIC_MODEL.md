# 符号模型与条件判据

本文件冻结**模型结构和评价契约**，不提供虚构参数。所有硬件/任务数值待辨识；没有运行调度仿真。它不是已标定Orin模型，也不继承TF20261114的数值。

## 1. 任务、资源、重叠和计费

两链A1→A2、B1→B2；抽象计算资源X/Y及共享内存M。令任务i具有固定计算工作c_i、访问量m_i、精度p_i、到达a_i和链期限d_i。允许用A1/B2代表计算偏重、A2/B1代表访存偏重的**符号角色**；没有将某个真实算子擅自归类。合法设备集合D_i、有限请求频点F_X/F_Y/F_M须逐项核实。已有GPU/DLA回退不能被解释成每个任务只用一个设备。

每设备单执行槽；任务开始后不迁移，依赖和设备互斥始终满足。候选不仅含映射/请求档位，还包含两链之间的额外先后约束：既允许跨设备重叠，也允许人为串行。只取无环合法顺序，按就绪事件派发；不通过改变派发器偷偷固定所有重叠。内存分配由固定硬件仲裁函数A决定，调度器不拥有资料未证明的带宽配额控制权。

一般进度模型为 `dz_i/dt = Φ_i(f_device, b_i, cache_state; θ_i)`，完成时z_i=1。Φ、实际访问量和计算/访存重叠需要联合识别。便于推导的**理想流体子模型**可写为 `dz_i/dt=min(S_i(f)/c_i, b_i/m_i)`；它假设访问量固定且计算/访存充分流水，不能从单点时长或EMC百分比直接推出。真实相位交替、缓存和延迟隐藏未知时不将该子模型当实测事实。

共享模型约束 `Σ b_i(t) ≤ B(f_M(t))`；仲裁允许非对称和优先级，不能默认CPU/GPU各半。无争用消融为每个任务保留其孤立带宽服务曲线，去掉共享总量约束；**访问字节、内存功耗、转移开销仍存在**。此消融是诊断反事实，允许总供给超过真实物理带宽，不能作为部署平台。

热状态可符号化为 `C dT/dt = −G(T−T_amb)+H P`，C正、散热网络被动稳定，H把不重叠的功率分量映射到热节点。计算/EMC实际频率由请求、负载调频、模式限制和热cap共同决定。热cap状态机必须给出监测传感器、进入/恢复门槛、采样、确认延迟、切换暂停和能量；当前均未知。关闭热cap时仍保留温度递推、功率模型及其他限制，以免混入“删掉温度相关功率”的额外消融。

统一窗口[0,H]+共同尾段[H,H+L]。完整能量 `E=∫(P_compute+P_memory+P_base)dt+E_transition+E_control`；传输占用带宽和能量必须计入相应分量且只计一次。使用板级输入功率时不得再叠加已经包含的DRAM/CPU/GPU功率。两方法均完成同一工作量、精度和全部期限才计算节能；失败只报完成量、违约和能量记录，节能率=null。

## 2. 四组消融和共同完整模型复评

|模型|争用|热cap|选择与复评|
|---|---|---|---|
|M00|关|关|在同一候选目录中选最优，再以M11复评|
|M10|开|关|充分考虑共享竞争，不提前考虑热限制；M11复评|
|M01|关|开|充分考虑热反馈，目录不变；M11复评|
|M11|开|开|完整模型有限目录参照|

设σ_mh是相应模型下能耗最优可行安排，所有选择使用同一确定性并列规则；还保留最优集合，避免把并列解索引变化误认机制效应。若该模型无可行者，不伪造“最优失败”来算收益。

**关键指标必须分开**：

- 固定同一安排σ的交互量 `I(σ)=E11(σ)−E10(σ)−E01(σ)+E00(σ)`，用于描述非加性；失败时能量仍可作过程描述，但不可称同服务收益。
- 热的条件决策价值：比较M11中的σ10与σ11。二者均可行才算 `g_H|M=[E11(σ10)−E11(σ11)]/E11(σ10)`；若σ10失败，先记可行性改善。
- 内存的条件决策价值：相同地比较M11中的σ01与σ11。
- 算法投入空间：与下节**最强简单可行者**比较，不能拿M00弱基线代替。

`I≠0`既不保证选择改变，也不保证≥1%收益；`I=0`也不排除任务相关的可加热代价改变排序。不能把四个模型各自最小值做二阶差分，冒充固定安排的物理交互。即使热限制参与，最终选择完全由内存决定也应报告热感知独立价值未成立。

## 3. 强简单类及信息条件

所有类都按M11复评。需冻结下列集合及包含关系，再启动任何数值运行。

|参照|选择信息|能力边界|
|---|---|---|
|最佳固定映射/工作点|离线知道真实参数和到达|每次重复沿用同任务类型映射及请求档位；硬件cap正常工作；预设重叠规则|
|仅内存优化σ10|离线知道工作及竞争模型|在完整合法目录中找M10最优，然后M11复评|
|热感知但不联合优化重叠|离线，知道热反馈|重叠规则固定为尽早执行或全局串行；各自充分优化映射/工作点。保留二者较优作为更强简单参照，避免故意选差规则；可用M11预测竞争，但不搜索逐任务重叠关系|
|最多一次模板切换|离线知道未来、真实参数与初温|沿重复窗口执行预排，模板含映射/档位/重叠；不称在线阈值控制|
|有限完整合法目录|离线、已知未来|目录内最佳，非所有连续开始时机的全局最优|

重复次数N尚未给数值。若每窗口m个模板，至多一次切换类大小为 `m+(N−1)m(m−1)`；N=1或2时它等于m^N全目录，**比较额外收益必为0是集合恒等，不是实验发现**。不为绕开这个负结果擅自增加N。当前无实际在线方法的实验结果。

## 4. 何时可能翻转：符号条件正例

先给一般判据。若两安排σ、ρ在M10下都可行且 `D10=E10(σ)−E10(ρ)<0`，定义各自热增量h_σ、h_ρ。联合下次序翻转的条件是 `D11=D10+h_σ−h_ρ>0`，即热的差分损失超过原优势；同时必须检查M11服务可行性。单一温度下降不是这个条件。

一个嵌入两链访存阶段的条件构型：两个同规模访问阶段各需W字节、孤立计算瓶颈时长t，冷态带宽 `B_H≥2W/t`。无热cap时二者并发约t，串行约2t。若并发造成热cap在τ开始切换（0≤τ<t，已含观察/确认延迟），切换期间暂停进度ℓ，随后带宽降至B_L并维持到完成，而串行全程不触发，则理想流体子模型给出：

`t_concurrent = τ + ℓ + 2W(1−τ/t)/B_L`，`t_serial=2t`。

在 `τ+ℓ<2t` 时，`B_L < 2W(t−τ)/[t(2t−τ−ℓ)]` 使并发更慢；若剩余期限满足 `2t≤D<t_concurrent`，便有“原并发可行、热反馈下串行更可行”的条件区域。若τ+ℓ≥2t，暂停本身已耗尽这个比较裕量。前驱、转移等公共成本须已扣除且确实相同。

设k_H/k_L是并发前/后cap阶段相对共同基础功率的增量，k_pause为暂停增量，k_S是串行阶段平均增量，R保留不同泄漏、切换/转移冲量及尾段贡献。能耗翻转还要求：

`k_H t+R_C0 < 2k_S t+R_S0`（无cap并发较省），

`k_H τ+k_pause ℓ+k_L·2W(1−τ/t)/B_L+R_C > 2k_S t+R_S`（有cap串行较省）。

这些不等式**只定义可能区域**，不证明实际芯片能同时满足它们。尤其“并发触发、串行不触发”、B_L、τ及功率项必须由同平台数据或已识别热模型给出；当前不能凭空指定。计算cap还可能降低请求带宽、缓解争用，交互符号也可能相反，不能预设热限制必然更偏向串行。

## 5. 无收益与停止条件

1. 全目录热cap都不绑定：M10与M11相同，热独立决策价值为0（使用相同其他机制与并列规则）；普通内存优化仍可能有价值。
2. 全目录没有重叠，或最低合法EMC带宽仍足以满足所有请求：共享争用约束不起作用；不能宣称联合争用机制贡献。
3. 时间不受EMC cap影响但内存功率变了：**不能仅据执行时间不变判零收益**；还需证明能量改变量与安排无关或最优集合不变。
4. 同时无cap、无争用，且各强简单类包含一个共同最优安排并按同一规则选中：所有方法同质量。更强的退化例是任务能量可加、与映射/次序无关，固定窗基础能量相同、无额外转移/尾段差异且全部候选可行，此时整个目录同能量。
5. 最佳一次切换或固定类已达到完整目录值：复杂算法空间为0；离线预排不因此变成在线控制。
6. 相对最强简单方案满足 `E_joint+E_extra≤0.99 E_simple` 才达到用户1%参考；误差存在时需对**同一个**有依据参数集合检查服务及能量，而非每点重选后声称部署鲁棒。

本轮没有这个有依据的联合参数集合，因此没有正/负数值情景，也没有1%结论。`symbolic_checks.py`只核对14个代数关系、守恒与集合大小恒等式，不进行参数实例化或证明经验可达性。
