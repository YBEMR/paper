## 数学口径

变量x(j,r,f,s)表示阶段j以合法资源r/配置f在整数时刻s启动。每阶段恰选一次，每资源每1ms片段最多一个阶段；每条DAG边要求前驱完成不晚于后继启动。配置合法集合来自输入，不新增抢占或迁移。

总能耗（mJ）=H(ms)×Σ空闲功率(W)+Σx×(执行功率−对应资源空闲功率)×执行时长。该公式依赖完整工作量、固定时域和无额外切换开销，与旧模型一致。各阶段独立最小增量能耗之和给出合法下界；达到它的可行解就是本模型的全局最优解，不需要新的热剪枝算法。

热模型沿用`thermal_build`。将每个候选执行脉冲的线性响应叠加在全空闲轨迹上，形成0.25ms采样热约束。完整方案用独立功率时间线及0.005ms直接状态递推复核。若MILP候选只满足粗采样，则添加细采样违约时刻的完整热约束行，直到安全或耗尽原预算；优化时使用的松弛下界仍适用于细网格。没有连续时间温峰证明。

## 结果解释

- `certified_optimal`：完整合法、细采样热可行，能耗与有效下界在数值容差内一致。
- `feasible`：完整合法、细采样热可行，尚未证明最优。
- `not_found`：构造策略未找到可行解；不是实例不可行。
- `timeout_no_solution`：用完预算仍无经验证方案；不是实例不可行。
- `proven_infeasible`：MILP给出不可行退出状态；与启发式失败区分。
- `seconds`包括各方法的目录/热响应预计算、初解、构造和内部检查；`verify_seconds`是最后一次独立复核。求解器MaxTime是软上限，必须看实际耗时。
- `milp_warm5`若初解已达到解析下界，将直接结束，`calls=0`；此时不是MILP热启动后的求解加速。
- 方法内差距使用当时自身可得下界；最终可用同实例各方法取得的有效下界复评。不得用不完整方案的低能耗计算收益。

这是有限合成实例上的计算审计，不是原论文复现、真实NPU节能或在线实时性验证。实例数量不支持统计推广。若通用MILP耗时高但简单基线已达到下界，不据此宣称新算法必要。
