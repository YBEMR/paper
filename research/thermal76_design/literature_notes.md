# 76号设计：有限热约束生成的来源核查

日期：2026-09-28。范围：定向核查2篇新来源，并复用48／49号对Zhou、JOSS的原文定位；不运行实验，不修改历史材料。使用 academic-research-suite 的定向事实核查流程。已盘点 `papers/` 并读取当前 `RESEARCH_BRIEF.md`、相关 `RESEARCH_METHOD.md` 与第三章MILP小节；本文件是来源与适用边界记录，不是新颖性审查完成证明。

**结论：任务模式查表、热约束MILP、有限主问题与分离反馈都是已有工具。第三章可论证的工作应限定为：在本题有限选项域、连续耦合RC及数值判定规则下，怎样把违规峰时刻转化为有效约束，并说明它与原完整赋值排除法的关系。该适配是否具有方法贡献，仍需正确性论证和同域比较。**

## 1. 热调度MILP先例：Pierson等

Jean-Marc Pierson, Patricia Stolf, Hongyang Sun, Henri Casanova. *MILP formulations for spatio-temporal thermal-aware scheduling in Cloud and HPC datacenters*. 在线2019；卷期2020，*Cluster Computing* 23:421–439，DOI：[10.1007/s10586-019-02931-3](https://link.springer.com/article/10.1007/s10586-019-02931-3)。正文读取[作者稿](https://henricasanova.github.io/files/papers/pierson_cluster2019.pdf)，共19页；以下页码是作者稿自身页码，不套用期刊页码。

| 原文定位 | 本次核实内容 |
|---|---|
| §3，p.4–5 | 数据中心独立单节点作业；不建模内存／网络需求；目标含完工时间和给定完工约束下的能量。不是CPU–NPU推理DAG模型。 |
| §4，p.5，式(1)–(3) | 明确用步长 `Δt` 离散时间；RC时间响应与空气回流矩阵组合，每步入口温度及功率固定。 |
| §5.1，p.6–8，式(4)–(20) | 以分配、占用、开始／结束等变量编码放置和资源；式(10)在离散 `t` 约束温度。HPC允许暂停降温；Cloud允许份额共享。 |
| §5.2，p.8–9，式(23)、(26) | 能量由功率时间积分和冷却项表达；实验功率按作业份额线性相加。 |
| §5.3，p.9，式(28)及段末 | 讨论速度幂次功率的DVFS扩展及线性化选项；随后明确全部实验仍用式(26)，不采用此DVFS模型。 |
| §6开头与§6.1，p.9–10 | 小实例求解案例；热模型验证援引既有工作，未在本文重做。实验为12作业、6同质节点的合成实例，不能当作本题设备标定。 |

**据此能说：** 热动力学、资源放置与能量目标进入MILP已有明确先例；不能以“把热约束写成MILP”认领新方法，也不能把其DVFS讨论描述为已经在该文实验验证。

**据此不能说：** Pierson的原模型必然遗漏段内峰值，或已有实验会超温。其每步固定入口温度下的单节点RC插值，与本题直接耦合节点状态的连续RC不是同一模型。按标量RC公式，在输入与入口温度固定的单段，温度相对固定平衡点单调；因此，“只查端点可能漏峰”必须由本题耦合模型独立论证，不能借该文的时间离散直接断言其有错误。这里的单调性说明是对原式的数学推断。

阅读范围：定向读取作者稿§3–5及§6开头、§6.1的可访问PDF文本；未复核全部实验图表。PDF页面截图接口失败，故不声称已目视核验公式版面；关键判断采用完整文字段落及相应公式号，页码按在线PDF文本映射。出版社页面用于题名、卷期和日期核对，其全文为订阅预览，未用于补充正文事实。

## 2. 有限约束／分离反馈先例：Subramanyam等

Anirudh Subramanyam, Chrysanthos E. Gounaris, Wolfram Wiesemann. *K-adaptability in two-stage mixed-integer robust optimization*. 在线2019；卷期2020，*Mathematical Programming Computation* 12:193–224，DOI：[10.1007/s12532-019-00174-2，出版社开放全文](https://link.springer.com/article/10.1007/s12532-019-00174-2)。[作者预印本入口](https://optimization-online.org/wp-content/uploads/2017/06/6093.pdf)可访问；本次技术定位以正式版HTML为准，避免混用预印本页码。

| 原文定位 | 本次核实内容 |
|---|---|
| §1，式(1)前后 | 研究两阶段鲁棒优化；其决策／不确定集及系数具专门表示假设，不是热调度问题。 |
| §3，式(5)后 | 将无限约束限制到有限子集形成逐步收紧的松弛；作者明确联系半无限规划离散化和Kelley切面法，`K=1`联系静态鲁棒切面法。 |
| §3.1，式(6)–(8)、算法步骤4–6 | 有限场景主问题与最大违规分离问题交替；无违规时接受，有违规时加入场景并作相应分支。 |
| §3.2，定理1–3、例2 | 区分终止时正确性、渐近收敛、特殊条件下有限收敛。定理3要求有限二阶段决策集且仅目标不确定；例2表明一般情形可不有限终止。 |

**据此能说：** “先解有限约束主问题，再找违规点并反馈”具有直接原文先例。若76号采用该框架，应称针对连续热约束的适配，不能以新增“反馈”“交换”“分离”名称认领通用算法。

**据此不能说：** 该文定理已经证明76号有限收敛、正确删除热违规候选或给出浮点数值证书。时间 `t` 在本题中是连续约束索引，不因类比就成为随机场景；本题也不需要引入K个补救策略或其分支结构。由固定RC产生的指数响应系数未必符合该文关于不确定参数的仿射表示假设，所以这里只借用通用组织思想。

阅读范围：正式开放全文§1的建模假设、§3至§3.2（包括主／分离问题、算法步骤、定理陈述及例2）；未复核其实验与全部附录证明。以章节／式号定位，不虚构正式版PDF页码。

## 4. 对76号设计的约束

下列是本研究的适配判断，非上述文献原结论。

1. **区分原方法与新设计。** 75号第三章现有流程在候选明确违规时只加完整赋值no-good；若76号改为固定违规时刻的热行，应说明同一行还会约束哪些其他选项组合，以及为何不会删除安全组合。两者都不能仅凭名字宣布先进性。
2. **证明正确性所需接口。** 要先固定线性时不变RC、与选择无关的初态／公共基准、可加且预定的选项注热；才能将固定节点、固定时刻的温度写成“公共项＋选项贡献线性和”。模式时长保持真实值，启动网格不等于热检查网格。改成温度相关功耗或并发残差后需重查叠加条件。
3. **数值有效性独立处理。** 违规见证证明某一候选不可用，不自动证明任意近似热行对所有安全候选有效；反馈行的系数／右端误差方向须与“有效外松弛”一致。分离器未发现违规不等于已证明全时域安全；完整窗口、尾段、段内峰、阈值附近未分辨状态必须保留。
4. **有限终止单独证明。** 若选项域有限、每次只在可靠违规时加全域有效且严格排除当前候选的约束，精确主问题与可靠分离可给出基于有限候选数的终止论证。这是本题条件证明的入口，不借用K-adaptability定理3，也不推出求解快或现实预算内收敛。未分辨或预算到期仍应输出未决。
5. **收益必须有对应证据。** 同域比较完整赋值排除与固定峰时刻反馈；分开“连续热约束表达必要性”和“反馈行减少迭代／搜索成本”。历史未触发热排除的输入不足以支持反馈收益。可能出现同解、同能量、反馈无收益或额外构建成本，应保留。

建议措辞：“在已有模式表与有限主问题—分离框架上，构建适用于本题选项表示和连续耦合RC的热约束反馈，给出其有效性与终止条件。”在推导、实现和比较完成前使用“拟构建／待验证”；不得写“首次”“通用新热MILP”“已证明优于现有方法”。
