# K.31：TP-1一次性四组合诊断

本包承接K.28—K.30，使用原TP-1输入，执行一次局部评分、完整评价与合法单模式反例检查。没有增加参数、案例或预算。TP-1为L3条件构造，不是设备测量。

- 输入及范围：[冻结协议](PROTOCOL.md)、[原输入](../thermal_pressure_precheck/input.json)。
- 入口：`run.py frozen`，必须满足预检、审查哈希和`state.json`准入条件。正式目录已存在或运行次数非零时拒绝执行；中断不自动重跑。
- 预检：`precheck02/result.json`保存原20项合成流程检查；执行前审查发现超时冲突保留缺口后，`precheck03/result.json`补查完整链。K.30预检负责连续评价及预算接线。`precheck01/failure.md`保留临时目录权限失败。
- 保存：每次评价独立20秒；输出逐项记录，保存与只读事后核对另计。16次局部评分、4次完整候选评价、8次单模式探针，共28次。不同调用不共享计算结果。
- 事后核对：`postcheck.py results/diagnostic01`仅复核保存的时间表、计量、身份和汇总，不重新运行热轨迹或补搜索。

完整候选必须有持续安全证书且全部U1路径有效，才参与安全能量比较。真实合法反例可以排除固定组合；共同温度盒未通过、数值未决和超时均不能排除。局部分数缺失时保留不完整选择，不能补造排名。简单回补只作事后决策演算，不比较其计算性能。

本阶段止于这一次结果及独立审查，不根据是否取得收益追加参数或运行。
