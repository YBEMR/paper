## 误差保证与实现核对

| 核查点 | 独立判断 |
|---|---|
| 相似变换 | 增广状态为温升、漏电积分、常数1。D=diag(100,…,100,1,1)，transform逐项计算M_ij D_j/D_i，初值除D、输出乘D，等价于w=D⁻¹z。不改变G、C、工作点、温限、段长或物理能量单位。系数及状态均以原区间运算包络。 |
| 漏电与常数 | 漏电能量坐标尺度仍为1；变换自动把温升到漏电积分行的系数乘100，与内部温升除100相抵。常数坐标尺度为1，原thermal在每片后恢复该已知精确常数，合法且不重置温度或漏电积分。基准、活动和外部能量仍由原代码累积。 |
| 步数 | 对变换后的区间矩阵取各元素magnitude，以有理数行和构造上界，再ceil(4Mh)。独立按TP-1空闲系数计算M=1300 s⁻¹，80 ms得到416片，与实现／结果一致。1/4为原TaylorPanel的1/2舍入边界留有余量，不以近似范数取代保证。 |
| 端点转移矩阵 | 对每个精确单位基向量，由原有向Taylor及余项得到exp(M't)的一列包络。区间矩阵乘当前区间状态包含真实点值；丢弃列间及状态间相关性只会扩大结果，不使包络失效。t=0直接返回包含真实状态的现有区间。该论证依赖原Taylor余项，不依赖闭式数值恰好吻合。 |
| 段内峰值 | 非退化时间区间仍调用原Taylor多项式及余项像；peak仍用区间像的导数符号、点值下界和时间细分。端点改进未将连续检查替换为采样。正比例缩放不改变导数符号；容差Decimal指数精确减2，输出乘100后继续接受原物理精度检查。模型有效温区检查亦保留。 |
| 缓存身份 | key包含变换矩阵全部区间端点、h和评价时刻t，矩阵变化涵盖活动功率与漏电变化。缓存只存算子、不存初始状态，每次thermal新建。改变状态仍重新做矩阵乘法；不同h或矩阵不会误用旧算子。预检覆盖矩阵、时长与状态变化，未共享跨调用结果。 |
| 模块隔离 | FunctionType复用原thermal代码及复制的globals字典，仅替换TaylorPanel和panel_count；未修改旧模块全局字典。旧coeff_matrix、区间类型与输入验证保持原实现。不是修改旧积分器后再把历史结果当作同版本。 |
| 预算与证据 | 函数复制、变换、基向量传播、缓存生成和峰值检查都在同一调用预算内。虽然单次矩阵构造并非可即时中断，原thermal仍在整片处理后检查预算再提交状态，最终结果返回前再次检查；超时不会把未提交片段当作完整安全证据。初始违规及无见证中断的既有分流保持。正式调度外层计费仍待接线，不由本轮认定完成。 |
