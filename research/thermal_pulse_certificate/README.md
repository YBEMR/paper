# K.33：固定方案的活动间隔持续证书

仅补原TP-1 a_n b_c的持续安全未决，不改变物理参数、服务、入口、温限或原程序。依据[K.32推导](../thermal_pressure_diagnostic/SUSTAINED_ROUTE.md)；不开展温度轨迹仿真、能耗重跑或候选搜索。

## 接口与范围

- `verify_pulse(c, semantics, budget)`：先用旧V2验证合法性与期限，再严格匹配批准的TP-1固定表／全部四入口／执行规则，推导有理数释放密度、活动间隔和耦合温度上界。参数不符只返回未决，不作为不可行排除。
- `verify_sustained`：保留旧共同盒通过和真实反例；只对其未决补脉冲证书，不修改旧V2模块。
- `evaluate_safety_bundle`：完成原联合输入验证，生成绑定新旧源码与输入的持续安全回执；**不评价或接纳能耗，不读取历史结果作为答案。** 安全回执迟到不接纳，已形成真实反例仍保留。

覆盖原四入口块（A/B、CPU H/L、NPU H、初温[30,35]°C、相位0、无未完成工作），全部实数合法切换时刻、任意长期驻留及重复。证明使用间隔归纳与累计活动包络，不采样转换相位来代替全域证明。不支持任意其他参数、不同轮内时序或初始非零相位；无效输入与有效但不支持的输入分别记录。

CPU精确上界为25＋3255/206°C，比较包络为41°C；NPU上界为9996419/125829°C＜79.445°C。指数只用有理数级数余项，不调用浮点指数或峰温取整。保留CPU/NPU耦合、温度漏电、空闲保持工作点；外部公共功率不注热。

## 可复跑入口

在项目根目录使用 `F:\Anaconda3\python.exe research/thermal_pulse_certificate/run.py precheck --output precheck_new`。每次选择尚不存在的目录；precheck01是保留的入口失败，不可重用。当前复审凭据为precheck03/result.json，旧precheck02属于修订前版本。

主线6审查通过后，由主线用`make_ready`与create-only保存函数封存ready01.json，再运行`run.py certify --output certificate01 --ready ready01.json`，只执行当前输入的持续证书，不重新运行F1/F2能耗。准入要求：必要预检全部通过且哈希匹配；审查首行为`K33_REVIEW: PASS`，并单列`K33_HASHES_SHA256: <全部依赖映射的摘要>`；ready同时绑定预检和审查文件的字节SHA256。旧PASS配新源码、审查文字变动或旧预检均拒绝，且拒绝发生在创建输出目录与输入装配之前。

预检只展开合法时序并进行有理数核对及中断／资源注入；不调用热传播。有限切换夹具用于验证执行实现，不承担无限域证明。四组合旧状态及K.31工件保持原样；新增安全证书不自动改写历史安全U或排名。本阶段不宣称新的共同节能收益。
