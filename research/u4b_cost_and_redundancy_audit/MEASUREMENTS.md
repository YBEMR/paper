# 固定工作量实测附表

同一批候选逐项还原后，快速构造花时最多的是选择两类任务的设备配额。回退搜索花时最多的是预测设备温度，其次是用少量试算校准候选的配额。进入完整认证后，建立并交叉核对物理事件的时间超过连续积分本身。三个阶段分别有自己的分母，不能用某一阶段的占比解释整条路线。

## 控制、探针与复核

- 单进程限制至单个逻辑核，原批使用的逻辑核 0/2/4/6 均避开。主批大多数单元在逻辑核 10，I03 第一轮完整、精简与探针的快速末层在核 8；附加两流在核 8。同一配对使用同一核。6 个物理核、12 个逻辑线程；数学线程变量全部为 1。操作系统保有自身辅助线程，未获得整机独占。22 次短采样中所选核占用 8.0% 至 84.6%，中位数 22.65%。阶段 CPU/墙钟、正反序差与波动均已保留。前后抽样无法排除测量中途短促的后台负载。
- Windows 11，Python 3.12.4，NumPy 1.26.4、SciPy 1.13.1、Numba 0.61.2、psutil 5.9.0。每次在私有临时目录复制已有 JIT 缓存，使用无目标标签的模板预热。完成初始化的四次进程，从启动到就绪约 5.46–6.44 秒；栈加载及预热约 3.50–4.28 秒。逐流建模原始记录另列在 `measurements/inputs.jsonl`。固定阶段热运行不含进程启动和建模，计算额度包含这些时间。
- 纯诊断空探针 30,000 次，附加约 4.11 微秒/次。分项探针相对未插桩原记录墙钟合计分别为快速末层 +21.7%、回退首层 +6.7%、次层 +9.1%、单份认证 −1.4%。快速末层的细项尤其受探针扰动；未作有偏的统一减法，微小差值不作性能结论。未插桩两臂都保留少量内存中核对用的引用，在计时外逐项比对。最初八流的精简首/次层仍组装原科研校准元数据；附加两流的严格精简另行测量。
- 共 243 个主测单元、24 个补充配对单元、2 个纯计数单元。三轮的每次工作身份与对应归档一致。首份 SAFE 的指标、计划身份、原始轨迹字节均核验，未重跑整条路线。摘要脚本只读原始 JSON 并重新核对每对哈希、每组重复数、归档身份和预算。
- 5 次启动累计保守扣 **309.139351 单核墙钟秒**。第 1 次在无目标的源码位置登记处失败，修订动态模块路径。第 2 次在 Windows 临时文件更名被占用时停止，已完成第一流第一轮快速末层的三个单元。第 3 次监督器读心跳遇到 Windows 文件共享冲突而退出，截止记录为 I09 第一层纯诊断，最后成功单元保存在原始日志。会话已结束，核查时无存活的 Python 进程；这次从启动一直扣至确认无进程所在秒的末尾，共 226.749351 秒，覆盖了空闲等待。已完成单元按流/轮次/阶段/口径键跳过，随后两次分别完成主批与补充。单元键唯一性和完整性由摘要脚本验证。冻结代码和论文未改动。

## 重建入口
