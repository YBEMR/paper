# 快速构造失败诊断预登记

先查快速方法是否把表面不同、实际上已经在同一时刻超温的方案反复送检。再沿一个确实安全的完整方案倒查，分清搜索从未给出所需分配、任务来不及完成、以及合法方案排名落后三种情况。核对已发生的物理过程后才允许跳过认证。最后检验补充分配选择能否在实际限时内交付安全方案。

| 登记项 | 约定 |
|---|---|
| 来源 | 直接继承 U4-a 0231bc8b1e54977cb617f53a03e64df84fbf7cca 的 PROTOCOL、注册 CSV/hash、models、因果 FIFO、完整热证书及全系统能耗。以其 Base 的真实候选日志为原构造。原生成器、NT60、成组实验均不重跑。 |
| 样本 | I03/I05/I06/I07/I09/I11 还原原始各层和参考安全路径；其余六条是限时对照中的成功/副作用检查。十二条均只作诊断。 |
| 离线 | 单工作进程单线程，累计最多 600 核秒；用外部单调墙钟保守扣除每次整个离线进程（含启动和错误），超限中止，保留已有逐流证据。归档复制、压缩、独立文件校验与在线限时路线另列。 |
| 还原 | 恢复每个真实尝试、各层合法排序、实际保留及末层全部不同合法计划；压缩日志引用冻结原件。各运行分别按原认证顺序统计，记录首次共同配置前缀、首次确定超温的物理事件和各分支被淘汰的层。沿 NT60 最后已交付 SAFE 的真实父状态逐窗枚举频档，分别记录生成、时间合法性、在实际池的排名及父节点缺失。离线可达性与在线发现分别报告。 |
| 严格热证据 | 仅使用冻结连续积分的真实事件端点温度减累计误差仍高于温限的证据。相同输入、初态与已决定配置前缀可以复用至下一决策窗起点减 5 ticks；本窗及之前已知请求按真实 FIFO 执行，跨窗保留积压和频档，未来请求的早降频不得回写决策前时间。完整配置可复用全程。先在原完整证书上检查物理事件字节及无 SAFE 误排，再进行在线比较。 |
| 按需检查 | 每个非末层仅在参考能耗排名居前的多个候选共享父节点时，按需检查这一父节点的开放物理历史，每个父节点只检查一次，严格违规才整支排除；不足宽度的候选按原排位递补。只对真实已确定区间从初态积分，不假设窗口尾部切频。 |
| 配额 | 在真实 SAFE 父路径上逐窗对比唯一配额、冻结的 13 个中心/小整数偏移、以及额外的同总量 A/B 组成两端与中点，另含两种类型各自全选/不选的四角。单独计算覆盖，不以参考路径给在线搜索提示。在线仅当原保留池无法延续时，在首个空层从原父池作一次扩充；用同一完整配置合法性和参考能耗排序。普通补充与热排序分开。 |
| 限时门槛 | 出现此前未归档的、不同完整计划共享严格超温端点的证明，或找到已认证 SAFE 路径具体遗漏并由补充配额复现，则开放同机比较。每流每新路线一次；复用 Base 历史参照。新臂 R 终端复用，P 在 R 上加入开放前缀检查，D 在 P 上允许空层补小扰动，C 在 P 上允许空层补小扰动和组成代表，H 与 C 生成权限相同，扩充层改以已确定物理历史的实际峰温排序（仅排序）。首次空层最多考察 4 个原父节点、全部频档；仍按原宽 4 和末层 12 份上限，原轻量回退与 Adaptive2 保留。 |
| 计时和停止 | 每臂从建模前开始共用 10 秒硬墙钟，原分配物理核、目标盲预热，截止前已记录的 SAFE 才计覆盖。保留首次/终值交付、完整能耗、最小期限余量、分项成本和截断。物理历史验证不通过立即停止硬剪枝；额度耗尽不扩样，不把空池、超时或未找到 SAFE 推及全域。 |
