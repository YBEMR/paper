# 期限容量与有限路径保留预登记

本轮分别检验两个问题：安全排程所需的动作是否进入了候选池；已经进入候选池的路径是否因同一父路径占满位置而消失。先复核具体排程，再在严格时限内观察完整算法能否改善交付。历史排程只供离线核查。

| 项目 | 登记约定 |
|---|---|
| 冻结 | 基线 U4-b c6d1a32f0dc378b80130a8280aca1b7dd9dd5773 的 C 路线和其全部上游版本与输入。35°C、80°C、原期限、完整因果时序、全系统能耗、严格连续认证及 Adaptive2。原始 C 对照使用同机已核验归档，避免重复；不同日期的单次墙钟只作描述。 |
| 离线 | 单进程单核运行，累计最多 600 核秒，以含启动失败在内的进程墙钟保守扣费。先 I06 安全频率序列逐窗重算平衡配额，核全程连续证书、窗口 2 的真实池、父身份、参考能耗/余量。I03 窗 8；I07 窗 3/5/8/9；I11 窗 6/8/10/14。逐窗只替换该窗配额，其余历史配置冻结。核首个违规请求及所处层，按到平衡配额的 L1 距离枚举整个合法整数格，认证最小距离层上所有完整时序合法的不同计划。保留同距离热失败及重复计划身份。 |
| 延迟冲突 | 在真实变更后的前缀上，对后续一窗和两窗各频档的平衡动作进行穷举，记录尝试、合法延续和已知后缀上的首个失效。下一窗/两窗存在合法延续时不得将原动作硬排除。另在首次显现失败的位置、前一窗、前两窗逐个尝试有限修改，固定其余原配置和该窗频档，使用中心、13 个小偏移及组成代表，核完整时序和工作量。全部仅用于指定离线见证。 |
| 在线门槛 | 复现旧频率路径/旧冲突数本身不足以启动。至少新得到一个不同于已知参考、由单一改动恢复期限且经完整热认证的 SAFE，或在实际第四位替代规则选中的前缀下找到新增完整认证的安全后续。门槛通过后逐流分别对照，先四条剩余失败流，均结束后再八条原成功流。 |
| 保留对照 | C 原参考能耗；Parent 前三原样，原合法前四同父才换成最低原排序的其他父候选；Margin 前三原样，剩余候选中优先无跨窗未完成请求，其次最大化跨窗未完成请求最小余量，再最大化本窗释放请求的最小余量，再按原能耗与原破平。全部历史最小余量只记录。空集合记 null。保持宽 4；末层原有最多 12 个完整计划的送检规则不变，已知严格违规一律跳过。检查替代项使用原 C 前缀证明触发规则；对每个实际入位保存父/子、余量、设备可用及积压。 |
| 生成对照 | 保留 C 的原排序和空层一次补充。Small 在每个父节点/频档对均补 13 个小偏移（含中心，去重）；BlockedSmall 只在该频档平衡动作发生具体请求超期时补相同小偏移；BlockedMix 同一触发下再补冻结的任务组成代表。普通排序、合法域、宽度和终端上限一致。含附加 BlockedSmall，以区分触发时机和配额集合变化。记录阻塞请求的设备/起止/截止、补充动作及修复前后完成时刻。 |
| 独立贡献与联合 | 每流每新臂一次 10 秒硬墙钟，沿用冻结同核、盲预热、外部截止和在位交付。先分别查 SAFE 覆盖、共同 SAFE 的严格能量改善、失去的成功、候选父身份和首次决策分歧。只有两类分别均无覆盖损失且新增成功或有严格节能，才进一步比较联合；此时各选净覆盖最多，其次共同能耗最低，再按表内顺序破平。其余停止。时间微差不作定型依据。 |
