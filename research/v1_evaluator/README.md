# V1固定方案评价器

## Material Passport

- 类型：固定有限路径评价与程序预检；ARS experiment-agent run。
- 输入：`../v1_precheck_draft/inputs.json`；时序、物理值和原预期均保持原版。
- 范围：T1整轮平移、Z0零额外准备、给定入口及有限转换路径。
- 实现：独立Python标准库入口；SciPy只用于可选ODE交叉排错。
- 保证边界：检查已给路径，不认证任意转换、无界驻留或持续安全，不求优化解。

## 1．怎样运行和读取结果

在项目根目录运行，结果目录必须尚不存在：

```powershell
python -B research/v1_evaluator/run_v1.py precheck --output research/v1_evaluator/results/new_run
```

入口先核对原输入包的哈希及28组静态检查，失败则不运行评价器。随后评价输入，保存结果，最后才读取独立预期进行比较；`evaluate.py`不会读取预期或历史答案。结果目录保留当前源码副本及SHA256，不覆盖旧运行。

| 输出 | 查看内容 |
|---|---|
| `precheck.json` | 逐项检查、通过状态、输入／源码身份和环境 |
| `traces.json` | F1—F4的输入状态、完整／诊断时间表、请求完成、功率片段、热与能量结果 |
| `F*_schedule.csv` | 可直接查看的逐Stage单元、工作点、原释放／期限及真实起止 |
| `F*_temperature.csv` | 事件时刻的节点温度区间；全过程峰值另见JSON，不靠该表采样判安全 |
| `primitives.json` | H1—H4独立热部件的连续峰值包络、能量和状态 |
| `derived_interface_checks.json` | 重复转换、频率域、非法输入和中断等派生程序夹具；不替换原输入 |
| `ode_crosscheck.json` | 独立逐段ODE排错结果，不承担误差证书 |
| `weighted_energy.json` | F1/F2等权算术核对；不作为节能收益 |
| `source/` | 本轮实际源码快照；修改后需新运行记录 |

## 2．执行与计量

`evaluate.py`按给定转换时刻划分释放区间。旧模式只生成转换前的周期请求，转换时刻的新请求归入新模式；已有旧工作完成后，以实际可执行基准平移新轮全部Stage。释放、期限和后续周期不移动。Stage执行区间采用半开区间。

释放表先做W1检查。发现某个窗内释放的工作原期限在窗外，返回输入不相容。固定偏移必须满足依赖和单元互斥；同一频率域重叠工作必须使用相同电压频率对。域清空后允许切频，域内空闲单元同步到该工作点，之后保持。该同步影响基准功率，不能只更新正在执行的单元。

首版计量要求每个热节点对应一个明确计量的执行单元／设备，避免在缺少分摊数据时发明共享基准分配规则。多个CPU单元可共享频率域，但每个单元有独立节点与已给基准。输入若使用其他热聚合口径，返回不支持，不自动套用本计量方式。

功率事件包括Stage起止、工作点改变、转换／释放时刻及窗口结束。每片段保存当前工作点、活动Stage、基准、活动增量和漏电斜率。基准和活动能量直接积分；温度漏电与温度状态共同传播；公共功率单独积分且不注热。空闲尾段一直计算到原窗口末端。

若请求超期，保留该轮诊断时间表，但热与能量只算到原期限，停止继续生成执行方案，不增加丢弃或排队规则。其前缀能量不能参与完整路径排名。

## 3．连续温度包络的计算依据

**不是按固定间隔采样判断温度。** 每个工作点与活动状态固定的片段都满足常系数仿射方程。令θ=T−Ta，添加漏电能量累计量和常数坐标，得到

\[
z=(\theta_1,\ldots,\theta_n,E_{leak},1)^T,\qquad \dot z=Bz.
\]

温度行采用\(C^{-1}[-G+\operatorname{diag}(\lambda)]\)，常数项为\(C^{-1}[B_{idle}+Q+\lambda(T_a-T_{ref})]\)；能量行是\(\sum_n\lambda_n\theta_n+\sum_n\lambda_n(T_a-T_{ref})\)。公共功率不进入温度行。这里温度坐标按1 K、能量按1 J归一后做矩阵范数计算，避免混淆量纲。

`interval.py`用60位Decimal的向下／向上舍入包住每次加减乘除。JSON十进制直接解析；时间按有理数处理，非整数结束不取整，也不转为浮点后假定精确。

将物理事件片段内部细分，使\(x=Mh\le1/2\)，其中M是B的无穷范数上界。计算18阶Taylor多项式，并为每个分量加上余项界：

\[
R=\lVert z_0\rVert_\infty,\qquad
\rho=R\frac{x^{19}}{19!}\frac{1}{1-x/20}.
\]

理由是指数级数第19项之后，相邻项的比不超过x/20；用几何级数包住其余绝对值。矩阵系数及入口的区间误差、全部多项式运算的舍入误差和此截断界共同保留。不会用“高精度计算结果很接近”代替该误差依据。

对一个时间子区间，以区间Horner法评价整个多项式并添加ρ，得到包含该区间所有温度的范围。若导数区间同号，峰值由端点限制；否则二分时间区间。端点提供已达到温度的可靠下界，整段范围提供峰值上界，直到两者差距满足原10⁻⁶°C要求或资源耗尽。这样覆盖内部峰值，也覆盖没有任务工作的尾段；内部细分不是调度启动网格。

跨功率事件的温度区间连续传递，入口不会重置。完整能量包络要求宽度≤10⁻⁸ J，同时检查峰值、事件温度和末温宽度。参数有效温区的包络越界不被裁剪为安全：本版报告范围未分辨。

这些计算针对声明的确定性线性RC／线性漏电输入，不包含参数测量误差或真实芯片建模误差。若以后输入参数本身不确定，需要另给其不确定性范围。

## 4．状态与资源中断

安全要求整条已给路径合法、完整覆盖、精度达标且所有峰温上界不超限。可靠见证温度下界超过上限即可确认违规；无需为了证明“发生过违规”继续完成后续能耗。若已有违规见证而分析中断，保留违规事实，同时标检查不完整。

资源限制只约束分析器，不改变工作负载。首版默认每次评价60 s、至多100000个传播小段、20000次峰值细分，是防止程序失控的诊断上限，不继承旧研究方法的公平比较预算。每个小段全部计算完成并检查预算后才提交证据；返回前再检查，预算后新结果不补作完整通过。

未分辨、数值异常、输入无效和已证期限／热违规分别记录。只有完整有效路径能量可参与U1算术汇总；全局持续覆盖始终标`not_evaluated`。没有实现配置排除、MILP反馈、搜索或运行时调整。

## 5．与历史代码的关系

已核对旧`s55_thermal.m`、`s55_energy.m`及`t76_iv.m`：其事件分段、分项计量和外包络思路可借鉴，但恒定基准／活动功率、固定RC特例及原浮点运算边界不能直接作为本版漏电传播保证。故新入口独立实现，旧MATLAB源码、53号参数和全部历史结果保持原样。当前实现没有安装新依赖。

后续只审阅本轮固定路径结果和实现范围，再决定V2持续安全检查的首版做法；本轮有限路径通过不替代那项工作。
