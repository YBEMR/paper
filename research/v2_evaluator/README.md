## 1．运行与结果

在项目根目录运行，输出目录必须不存在：

```powershell
python -B research/v2_evaluator/run_v2.py precheck --output research/v2_evaluator/results/new_run
```

`verify.py`是检查核心；`run_v2.py`是验收入口。入口先执行预检包静态核对及哈希门槛，然后分别检查B1—B4；四个调用完成后才读取独立预期。核心不读预期文件、历史答案或旧搜索结果。

| 文件 | 内容 |

## 2．怎样得到持续结论

**期限证书。** 先核每轮固定方案的依赖、资源、共享域及合法工作点。计算轮内完成跨度C_m，精确检查C_m≤D_m及每条允许转换C_m+C_n≤D_n。结合已给D≤P≤L、T1、Z0和初始无旧工作，从首轮归纳：转换首轮按期、下一周期不积压、下一允许转换前已经完成该首轮。该证明覆盖任意实数切换时刻和任意次数重复，不是采样若干相位。

**热证书。** 从固定方案和所有初始块独立推导每设备可能保持的工作点及活动功率，包括域内空闲单元同步后的工作点。核对提交片段集合是否覆盖这些状态的保守笛卡尔积。多出的合法参数组合即使不可达，检查它们也只增加保守性；不会变成新的调度选项。

输入有限小数转为精确有理数，核共同温度盒包含全部初态、位于有效温区且不超温限。对每片段，计算上下角点的净注热，逐节点要求下角点≥0、上角点≤0。热系统协作性与正热容使这些条件覆盖盒各面；温度在事件处连续，故全部允许执行都留在盒内。公共功率不注热。片段检查完毕前不得输出证书。

**反例。** 只处理输入提供的有限过程，不主动搜索违规。核对其初态属于声明集合、切换时刻和边合法，再调用原V1的精确时序展开；期限反例记录原释放、期限和完成时刻。热反例复用V1定向舍入Taylor传播及全过程峰值包络。一个真实违规过程足以否定这套固定方案；共同盒或期限上界不通过则仅为未决。

这是确定性L3模型内的充分保证，不包含实测参数误差。基础层可以独立完成，精细层始终单独标为`not_implemented`。

## 3．输出状态及中断

| 状态 | 必须具备的依据 |
|---|---|
| `sustained_safe` | 输入合法，期限充分证书和完整共同热范围证书均通过 |
| `violation` | 从声明入口出发的具体合法过程确实超期或超温 |
| `unresolved` | 证书不成立、覆盖不全、数值未分辨、预算／资源不足；没有有效反例 |
| `input_invalid` | 入口或执行语义缺失、非法／首版不支持的输入；不等于物理问题无解 |

期限、热证书、反例、覆盖、预算与精细层字段分别保存。给定温度盒没有包含全部入口时，不接受证书；不能截掉入口后继续称安全。重放内层的限额／不完整也上报，外层尚未耗尽墙钟不掩盖内层限额。已有违规见证遇到后续中断仍保留。单点安全结果只标`safe_point_only`，不升级为持续保证。

默认每次调用30 s、最多10000种证明片段，复用V1的传播段数／细分限额。这些是防失控的实现限额，不是论文公平比较预算。未完成运算不能补记预算内通过；保存限额原因和实际诊断计数。耗时为单次记录，短调用可能低于计时分辨率而显示0，不代表零计算成本。

## 4．首版适用范围

- 每模式一轮共用期限；T1整轮平移，Z0，无跨轮／跨模式重叠。
- 入口为若干离散块与温度盒的并集。当前仅接受相位和切换年龄均0、无待处理转换／旧工作、时刻0即将释放首轮的入口；**运行后允许任意合法切换相位**，并非把转换限制到周期边界。
- 每热节点对应一个已明确计量的执行单元，共享频率域映射须完整且唯一；同频并发可保留。不同期限、积压入口、其他热聚合口径需单独扩展。
- 共同范围作为待验证证书由输入提供；失败不证明没有其他证书。未实现范围搜索、精细闭合、MILP反馈或能耗优化。
- 有限反例重放中的能量只是V1诊断字段，本轮不进行U1汇总或能量比较。持续安全证书和能耗最优性是不同结论。
