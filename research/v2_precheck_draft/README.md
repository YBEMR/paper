## 1．这次验收什么

固定方案不作优化，检查它在声明入口及所有允许切换下是否满足期限与连续热安全。基础层验证给定的共同温度范围和期限充分条件；本包不要求搜索最佳温度范围，也不要求先实现精细相位传播。

| 编号 | 输入与用途 | 独立预期 |
|---|---|---|
| B1 安全正例 | V1的Stage时长／活动功率／平台不变，**另立测试方案**：两模式共同期限改为14 ms，入口范围显式给定 | 期限充分条件成立；共同温度范围[25,59]²支持持续热安全 |
| B2 期限反例 | 原V1方案与F3的41 ms切换，期限仍为12 ms | B在54 ms完成、原期限53 ms，真实超期1 ms；热证书不能补救期限 |
| B3 热反例 | 单CPU单节点解析部件，第一轮已能产生可证明超温 | 时刻200 ms温度严格大于38.636°C，超过35°C；期限充分条件仍成立 |
| B4 证明不足 | 与B1相同的系统、入口及方案，仅提交较窄的证书范围[25,35]² | 该范围向内条件失败，不能据此判方案违规；B1的范围事实上可认证同一方案 |

B4核的是**给定证书的验收接口**，不是要求所有分析方法都返回未决。若另有合法证书可认证，应保留其依据；首版不要求自行寻找该证书。B1与B2是独立夹具，期限差异仅用于检查通过／失败分支，不作能耗对照，不放宽原案例来覆盖历史失败。

文件：`inputs.json`给全部输入与状态探针；`expected.json`给手算预期；`check_static.py`复核静态与有理数代数；`SHA256SUMS.txt`绑定这四份文件。`static_result.json`只记录静态核对，不是V2运行结果。执行器以后只读inputs，预期文件由独立检查端使用。

## 2．入口和允许运行范围

每个入口是一个离散状态与温度盒的组合；各组合取并集，不任意拼接不相容字段。时刻0定义为处理首轮释放之前。

| 字段 | B1／B4 | B2 | B3 |
|---|---|---|---|
| 节点温度 | CPU、NPU分别[30,35]°C，盒内全部值 | [30,30]°C这一点 | CPU [30,31]°C |
| 初始模式 | A或B | A | A |
| 保持工作点 | CPU H或L，NPU H；与两种模式组成4个入口块 | CPU H、NPU H | CPU H |
| 待处理切换 | 无 | 无 | 无 |
| 周期相位／下一释放 | 0／0，首轮在当前时刻释放 | 同左 | 同左 |
| 距模式请求时间／饱和切换时钟 | 0／0，暂不允许立即切换 | 同左 | 同左 |
| 已释放未完成工作 | 无旧工作；不取消当前时刻的新释放 | 同左 | 同左 |

这组入口是本预检草案选择，不声称覆盖任意运行中入口。初温覆盖的是连续范围，并非抽取几组样本。后续允许A↔B，在最小切换间隔满足后的任意**实数时刻**请求切换；无限长不切换和任意次数合法转换都在保证目标内。整数微秒仅是文件数值单位，不是启动／切换网格。

沿用T1整轮平移、Z0零准备、同刻切换优先于旧轮释放、保持空闲工作点以及D≤P≤L。B1／B2／B4的P=20 ms、L=40 ms；B3的P=L=1 s、D=0.5 s。无运行时拒绝请求、调整相位或额外冷却。

## 3．B1／B2／B4的物理值与代数证书

两节点CPU／NPU，C均为0.02 J/K，G=[[0.12,-0.02],[-0.02,0.12]] W/K，环境／漏电参考25°C，模型有效温区[0,100]°C，上限均80°C。公共功率0.5 W只计能量、不注热，本包不计算平均能耗。

| 设备工作点 | 频率／电压 | 基准W | 漏电斜率W/K | 该方案可能的活动增量W |
|---|---|---:|---:|---|
| CPU H | 2 GHz／0.9 V | 0.2 | 0.002 | 0、2 |
| CPU L | 1 GHz／0.7 V | 0.15 | 0.001 | 0、1 |
| NPU H | 0.8 GHz／0.8 V | 0.3 | 0.002 | 0、3 |

A：CPU H执行2 ms，再由NPU H执行6 ms；B：CPU L执行1 ms，再由NPU H执行5 ms。因此C_A=8 ms、C_B=6 ms。B1自身完成偏移≤14 ms；两条转换的最坏完成界均为8+6=14 ms。初始无旧工作，且D≤P≤L，首轮按期后下一周期不积压，按转换次数归纳支持任意合法重复／切换。此处使用G.2充分证明，不通过采样切换时刻得出结论。B2的该界失败还不足以判违规；41 ms的具体过程才提供反例。

共同热范围在绝对温度下为[25,59]²。工作／空闲片段清单采用CPU的4种(工作点,活动量)与NPU的2种活动量的笛卡尔积，共8种，包含一些真实方案不会同时出现的并发组合。由于没有跨轮／跨模式重叠、每设备最多一个Stage，且工作点只能来自入口或固定方案，该清单覆盖全部可能片段及空闲保持状态。它是保守证明工具，不增添可调度动作。

令θ=T−25，净注热为p−Gθ。矩阵非对角元素非负，故检查下角点净注热≥0、上角点≤0即可检查各面的向内方向。

- 下角点θ=0：所有片段逐节点最小净注热为[0.15,0.3] W。
- 上角点θ=34：逐节点最大净注热为[−1.132,−0.032] W；CPU低频最大为−2.216 W，亦向内。
- 入口包含于该范围，范围位于模型有效温区且上界59<80。温度在事件处连续，因此无论合法片段怎样重复／切换，都留在范围内。除以正热容不改变符号。

B4改用上角点35°C，逐节点最大净注热变为[1.22,2.32] W，不能证该盒不变。此时盒上界仍低于温限，且真实方案另有B1证书；**向内条件失败不是热违规。**

## 4．B3的独立真实热反例

这是单节点部件预检，不把论文平台改为单CPU。取C=0.02 J/K、g=0.1 W/K，CPU H的基准0.2 W、活动增量2 W、漏电斜率0.002 W/K、环境／参考25°C、有效温区[0,100]°C，温限35°C。A、B均在释放时执行一个200 ms的Stage。两模式相同是为了单独核热判断，不制造节能差异。

自身跨度200 ms，转换充分界400 ms≤500 ms期限。选择允许入口T₀=30°C，首轮期间无需切换。解析解为

\[
\theta(t)=\frac{1100}{49}+
\left(5-\frac{1100}{49}\right)e^{-49t/10},\qquad T=25+\theta.
\]

在t=1/5 s，利用eˣ>1+x（x>0），有e⁻⁰·⁹⁸<50/99。系数5−1100/49为负，因此

\[
T(1/5)>25+\frac{1100}{49}
+\left(5-\frac{1100}{49}\right)\frac{50}{99}
=\frac{425}{11}>35.
\]

这个有理数严格下界就能证明真实超温，无需数值积分或依靠显示小数。该段温度位于30°C和约47.45°C的平衡温度之间，未越出参数有效温区。200 ms任务结束瞬间温度连续，不能借半开执行区间取消这个见证。未来还须用评价器从具体入口重放并核对，但本轮未运行。

## 5．误差、异常与分层验收

输入有限小数作为精确有理数；基础期限、包含与向内符号检查可以精确完成，不加任意保险量。未来连续反例重放采用V1可靠区间，点见证峰值精度目标仍为10⁻⁶°C；**入口范围自身5°C宽不是数值误差**。判断区间跨界、片段覆盖不完整或证明完成前中断均保留未决；已有合法违规证据则保留，同时记录其余覆盖未完成。缺入口字段／不相容工作点是输入问题。

`inputs.status_probes`保存这些未来控制流测试，`expected.event_obligations`保存同刻、切换间隔边界及长期重复要求。本轮只核清预期，不声称已执行注入测试。以后分别报告基础层的实际证明、反例复核、未决状态和耗时；精细层保持“未实现”，不影响本包验收。

静态复跑：`python -B research/v2_precheck_draft/check_static.py`；如需保存新记录，使用`--output`指定不存在的文件。输入纠错应另记版本与原因，原记录不覆盖。当前不安装工具、不运行V2、MILP或仿真，不从本包输出算法收益。
