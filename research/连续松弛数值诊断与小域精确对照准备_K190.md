## 1．本次只放宽整数性

K187原归档问题为

\[
\min c^Tx,\quad Ax\le b,\ A_{eq}x=b_{eq},\ \ell\le x\le u,
\quad x_j\in\mathbb Z\ (j\in I).
\]

本提案只删除最后的1681项整数性要求。**使用K187原始上下界，不能使用K189固定整数后的界。** 全部27971列、176953不等式、0等式、1983981非零系数和原目标保持；不做删行、消元、缩放或增广。原始MAT SHA256为`3e415a16cd517815d8594c4e66dfac8df5393cf7321f4b425e40b19cb4110b4a`。

若把存档系数按实数解释，固定配置域⊆原MILP域⊆连续松弛域；该包含关系不依赖求解器。当前两份向量只是原1e−9容差下的数值见证，**没有精确可行证书**。

## 2．独立LP接口与选项

采用本机同一R2023b的独立调用：

```matlab
[x,fval,exitflag,output,lambda] = linprog(c,A,b,Aeq,beq,lb,ub,options);
```

**该版本不支持传入`x0`。** 原`x0`与K189向量只作来源和残差核查，不注入LP，也不把K189结果当免费初始化。实际八参数接口和`X0NotAccepted`逻辑已核本机[`linprog.m`](F:/Matlab2023/Program_Files/MATLAB_R2023b/toolbox/optim/optim/linprog.m:92)。因此本提案应称“同原数组的独立LP诊断”，不能称“原初始化不变的完整MILP对照”。

| 拟设选项 | 取值与理由 |
|---|---|
| `Algorithm` | `dual-simplex`，与原`RootLPAlgorithm`名称对齐 |
| `Preprocess` | `none`；本机类明确支持的隐藏属性，对齐原`LPPreprocess=none` |
| `ConstraintTolerance` | 1e−9，保持原约束标准 |
| `OptimalityTolerance` | 1e−7，对齐原`LPOptimalityTolerance`数值 |
| `MaxIterations` | 2049240，由原根LP默认公式`max(30000,10×(行数+列数))`计算 |
| `MaxTime` | 仅取同一300秒根时钟在进入原生调用前的剩余时间 |
| `Display` | `off`；原样保存输出、警告及最终`output/lambda` |

整数容差、整数预处理、cuts、节点／整数启发式等不属于此LP接口，不伪装成保持了这些选项。`linprog`未提供本版可用的`OutputFcn`接口，不移植`intlinprog`回调或承诺连续进度事件。

静态依据：[`Linprog.m:550`](F:/Matlab2023/Program_Files/MATLAB_R2023b/toolbox/optim/+optim/+options/Linprog.m:550)的选项元数据／`Preprocess`枚举、[`Factory.m:174`](F:/Matlab2023/Program_Files/MATLAB_R2023b/toolbox/matlab/optimfun/+optim/+options/+meta/Factory.m:174)及相邻验证器的时间／迭代／容差规则，均已核对并登记hash。**本轮只验证静态接口依据，没有创建原生options对象。** 获批执行后，选项构造与逐项读回计入根预算，任一不符就在调用前停止，不换算法或采用默认值顶替。

独立入口使用`LinprogDualSimplex`，`intlinprog`使用`IntlinprogBranchAndCut`。名义算法与容差一致不保证两者采用相同的内部变换、根松弛状态、基、缩放或接受路径；底层受保护实现未核读。**独立LP成功或失败都不等于复现了K187内部根LP。**

## 3．待批准的一次调用预算与停止规则

建议：**最多1次独立LP请求、300秒方法总预算、480秒日历上限；0次热积分／热post。** 这些仍是提案，不沿用K189已结束的预算。

- 300秒从读取载荷及导入科学模块之前开始，包括来源hash、数组复制／逐项核对、两份已有向量静态核查、MATLAB启动、options构造与读回、数据交接、原生LP及返回数值检查。
- 原生`MaxTime`仅使用当时剩余时间。300秒后新形成或新完成检查的结果只留档，不补记预算内接纳。原生停止可能延迟，外部监督保持；清理最多40秒、worker返回监督420秒，全部受480秒日历限制。额外墙钟只用于停止和留证。
- 获批后实现一次性独立LP交接，完成纯生命周期检查并冻结新目录；启动前核同一R2023b精确版本／路径、接口源hash、宿主权限、内存和本次进程身份。资源不足或身份失配不发请求。
- 只执行一次`linprog`，不改目标、不做整数修复、不追加求解器，不因空返回、异常或超时重试；已发出的研究调用不补跑。
- 保存原始`x/fval/exitflag/output/lambda`、警告、原生和根时钟、实际选项、发出数组身份、原行／界残差及进程清理。返回的原整数距离仅用于描述松弛程度，不作为LP拒收条件。

当前纯检查模块没有执行入口；[机器提案](chapter3_experiments/results/k190_lp_preparation01/protocol_proposal.json)保持`authorized=false`、`execution_enabled=false`。实际运行须用户另行确认，不能由内部审查通过自动触发。

## 4．怎样解释结果

| 可能结果 | 可支持的判断 | 下一步讨论范围 |
|---|---|---|
| 预算内返回，原行／界通过，LP报告最优 | 同一原数组在独立连续求解路径可用；K187问题仍可能与`intlinprog`根处理或整数机制有关 | 再提出小范围整数释放或数值表达核查，不直接3600秒 |
| 只返回通过数值检查的可行向量，未报告最优 | 独立LP能找到数值可行点；收敛仍未决 | 保留状态，不拿其目标值充当下界 |
| 返回−2，已有数值见证仍通过 | 接纳／状态冲突也出现在独立LP接口，值得继续隔离原条件行的数值表达 | 单独评估等价增广版本；不宣称物理问题无解 |
| 超时、空返回或未完成检查 | 原连续系统在此接口与预算下未决 | 数值处理与连续规模仍无法分离 |
| 返回违规向量、选项漂移、技术异常或−3 | 保存具体接口／数值证据并停止 | 不放宽容差、不自动换算法或重试 |

分数解不对应合法离散调度，即使全部整数坐标碰巧接近整数，本次也不进行调度解码、热复核或生成新SAFE/U。

数学上有最优值关系`z*_LP≤z*_MILP`，但**一个可行LP原始目标值本身不是MILP的有效下界**。只有可信的最优／对偶界才能承担这一用途。本次仅归档求解器报告与`lambda`，不额外开发精确对偶认证；`exitflag=1`也不升级成独立最优证明，不替换现有独立L0。它首先是数值路径诊断，不是新的算法质量结果。

## 5．是否另建结构完整的小域精确对照

**值得。** 它服务于第三章完整链表达的正确性展示、第四章在同一有限域内的质量差距；与K190对原大矩阵的数值诊断分开。即使小域求解成功，也不能解释成原P0自由域已修复。

| 已有依据 | 已覆盖 | 缺少什么 |
|---|---|---|
| [旧Q1协议](chapter3_experiments/q1_quality_protocol.md)、[结果独立核查](chapter3_experiments/results/q1_quality01/independent_review.md) | AB/AC共享A.main、异构设备／工作点／起点；11520项遍历全覆盖，MILP与参照U一致 | main-only，删除pre/post，使用旧hold策略，不能覆盖当前完整链auto-L |
| auto-L小夹具 | 控制状态、合法投影、辅助变量与物理补全 | 没有完整研究实例的全联合最优值参照 |
| [four-open夹具](chapter3_experiments/test_anchor_four_open.py) | 完整链的局部搜索与预消元投影 | A部署及闭锚已固定、另一场景固定，使用mock热回执 |

建议只准备**一个明确命名的新受限实例**，从P0/R1派生，保留AB/AC、全部12次Stage执行、9个共享Stage身份、依赖与期限、四节点和原功热参数、auto-L、400 ms窗口及5 ms对齐。通过事先声明的少量合法模式与启动集合缩小域，保留A.main至少两个具体设备的跨场景共同选择、main的频率选择及可变时序；pre/post可以限制选项，但不能删去。

域构造依据原模式支持、依赖、期限和公开规范顺序，先做静态合法性／计数，不读取历史最优时间表或依据能耗、温度结果挑域。固定pre/post可能排除全部安排，模式与起点集合也可能使实例退化；这些应在后续输入设计时核清，当前没有声称已得到可运行小实例。硬件原支持与研究主动限制分列，模式限制要显式进入共同契约，不能仅改MILP而让其他方法搜索另一个域。

后续最低研究组合可讨论为“一次整体MILP＋一次独立全遍历”，预算须先按静态规模评估、单独授权。第四章方法比较随后在相同受限输入上进行；不能拿全域HEFT结果计算相对小域最优的差距。求解器gap=0、完整连续SAFE、遍历覆盖及独立最优值包络分别验收；保留区间误差，不把双精度显示相等称为精确相等。旧Q1虽已给出约1.36×10⁻²⁹ J的最优值包络，仍正确保留`independently_proven_optimal=false`，新参照沿用这一证据分级。
